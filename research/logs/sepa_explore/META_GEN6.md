# 메타 세대 6 — 한국 "박스피" 에 맞는 리밸런싱 규칙 (설계 고정 — 결과 보기 전 — 2026-10-10)

세대 4·5 결론: 코어 = 지수 매수보유 + 정적 비중, 낙폭은 비중으로. 그런데 `docs/individual-trader-method.md` 의 **리밸런싱 규칙(연 1회 또는 ±10%p)은 시험한 적이 없다.**
한국 지수는 긴 박스권(2011~16 등, 세대 5 에서 타이밍을 무너뜨린 구간)이 잦다 — 평균회귀가 강한 시장에서 고정 비중 리밸런싱은 **변동성 수확**(싸게 사고 비싸게 파는 기계적 효과,
기하 수익 ≈ w·r_s + (1−w)·r_c + ½·w(1−w)·σ²)으로 매수보유-표류보다 나을 수 있다. 이 세대는 그 규칙을 30년 두 구간에서 검증해 매매법의 리밸런싱 절을 확정한다.

## 자산·비용

- 주식: 1997-12 ~ 2016-12 = 코스피(Yahoo ^KS11, 세대 5 와 같은 파일), 2017-01 ~ 2026-09 = 코스피200(네이버). 현금: (i) 0%(보수), (ii) CD91 기억값(세대 5 러너 값 — 기억값 표기).
- 리밸런스 비용: 매매 금액의 편도 0.07%, ETF 보수 연 0.05%. 세금은 기술 줄(현금 이자 15.4%).

## 규칙 (전부 고정 — 결과 보기 전, 격자 = 7 규칙 × 3 목표 비중)

목표 주식 비중 w ∈ {0.4, 0.6, 0.8}. 시작일에 w 로 맞추고:

| 코드 | 리밸런스 |
|---|---|
| R0 | 안 함(표류) |
| R1 | 연 1회(매년 첫 거래일) — 매매법 현행 규칙 |
| R2 | 분기 1회(분기 첫 거래일) |
| R3 | 월 1회 |
| B5 | 실제 비중이 목표 ±5%p 벗어나면 그날 종가 기준 다음날 시가에 목표로 |
| B10 | ±10%p |
| B20 | ±20%p(상대) — w × 1.2 초과 또는 w × 0.8 미만 |

## 판정 (미리)

주 비교 = **각 규칙 vs R1(현행) 그리고 vs R0(표류)**, 같은 w 안에서. 지표 = 초과 Sharpe(현금 (ii) 기준; 현금 (i) 세계는 원 Sharpe), Calmar, CAGR, MDD.
**채택 조건(규칙 X 가 매매법의 리밸런싱 규칙이 되려면, 세 w 모두에서):**
1. 1997-12 ~ 2016-12(표본 밖)에서 X 의 초과 Sharpe 가 R1 보다 높을 짝지은 월 블록 부트스트랩 확률 ≥ 0.8, 그리고 R0 보다 높을 확률 ≥ 0.8.
2. 두 하위 창 1997-12 ~ 2006-12, 2007-01 ~ 2016-12 각각에서 X 의 Sharpe ≥ R1.
3. 2017-01 ~ 2026-09(코스피200)에서 X 의 Sharpe ≥ R1 − 0.02(크게 무너지지 않음).
4. **무작위 리밸런스 날짜 널**: X 와 같은 연평균 리밸런스 횟수로 날짜를 무작위로 고른 1,000벌의 Sharpe 95 백분위 위(밴드 규칙이 "언제" 를 잘 고르는지).
5. 현금 (i)·(ii) 두 세계 모두에서 1~3 성립.
통과가 여럿이면 **리밸런스 횟수가 가장 적은 것**. 없으면 R1(연 1회)을 유지하되 "다른 규칙보다 낫다는 근거는 없음" 으로 적는다.
다중검정: 21 칸 — 통과 규칙의 부트스트랩 확률을 칸 수로 Bonferroni 한 줄도 함께.

## 사전 예상

변동성 수확은 w = 0.6 근처에서 가장 크다. 밴드(B10·B20)가 달력(R1~R3)보다 나을 가능성이 높다(크게 움직였을 때만 산다/판다). 표류(R0)는 상승장에서 주식 비중이 불어나 MDD 가 커진다.
B10 또는 B20 통과 확률 45%, 아무것도 R1 을 못 이길 확률 40%.
