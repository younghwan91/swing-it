## 구현 메모 (모호했던 곳과 정한 것 — 실행 전 결정)

- **U_s:** `korea.universe_mask` 에 선택 인자 `adv_cap`(ADV20 < 상한, 기본 None = 기존 동작)을 더해 `adv_floor=5000, adv_cap=20000` 으로 만든다. 원종가 1,000원 규칙은 `Data` 와 같은 `daily_bars.close`. 실행 중 U_s ∪ main = (ADV ≥ 5,000 위생) ∧ U_s ∩ main = ∅ 를 assert 로 확인한다.
- **RS·breadth:** `sepa.skeleton_features` 그대로(가격 패널 전체·시장별 전 종목) — 유니버스와 무관.
- **rel:** 사전등록 문구대로 분모 창 끝을 t−11 로(`shift(11)` — s ∈ t−260..t−11, 250개, 유효 ≥ 120). 사후 분해 스크립트는 `shift(10)`(t−259..t−10)이었다 — 하루 차이, 사전등록을 따른다. 고저는 분할조정 패널. rel 이 NaN(이력 부족)이면 rel 조건을 통과하지 않는다(팔 D 는 rel 을 안 보므로 들어간다).
- **PEAD 순위 모집단:** 그날 위생 통과 ∧ ADV20 ≥ 5,000 (U_s ∪ main). **팔 R 도 같은 모집단**이다(사전등록 'A 와 같은 정의') — 그래서 R 의 PEAD 문은 이전 시험들(main 안 순위)과 다르다. 문턱 0.70, 실적 행 없음 → 통과 안 함(`e_pass`).
- **수급 F:** `Data.flow['F']`(flow_leg, 거래대금 가중), 사건일 값. F = NaN(수급 행 없음)이면 통과 안 함.
- **청산·체결:** `simulate_minervini` 사전등록 기본값(VCP 문 없음 — 이 시험은 rel 로 수렴을 본다). 같은 종목 보유 중 재진입 없음은 팔마다 따로 걸린다(팔마다 사건 집합이 달라 트레이드가 부분집합 관계가 아닐 수 있다).
- **비용:** 1배 = `korea.cost_rt(청산일, 시장)`, 2배 = 총수익 − 2×그 값. 기대값 R(순) = mean(1배 순수익 / d), 총 R = 시뮬레이터 `R`(비용 전).
- **바 3 손절 비율:** 마지막 청산 사유 = `stop` 의 비율(본전 `breakeven`·`time_stop` 은 손절 아님 — 사후 분해와 같다).
- **바 4 '최악 10% 구간':** 하위 10% 트레이드의 **평균**(`worst_decile_mean`, 최소 1건 — 미너비니 결과의 '하위10% 평균' 과 같은 정의). 10% 분위수는 참고로 함께 적는다.
- **바 5:** 사전등록이 비용 배수를 적지 않았다 — 1배(`cost_rt`)로 셈하고 2배도 나란히 적는다. 산술 충족 수는 1배 기준. 진입월 = `entry_day` 의 달, 양수 = 그 달 트레이드 순평균 > 0, 비율 > 50%(같으면 미달).
- **대조:** 풀 = 그 유니버스 팔들의 트레이드 사건일 합집합의 그날 유니버스 전 종목을 같은 프로토콜로 `control_minervini`(자기 수축 저점, 피벗 = 직전 50일 최고 고가, 겹침 허용). 층 = `STRATA_MOM`(날짜·시장·q_mom·adv2) — q_mom(10분위)·adv2(중앙값 2분위)는 **그 팔의 유니버스 안**(U_s 또는 main)에서 날짜×시장별로 자른다. alpha 는 비용 전 총수익(모멘텀 재측정·미너비니 청산과 같다). 정합 층이 비면 그 트레이드는 미정합으로 빠진다.
- **팔 E:** A 트레이드 중 사건 ≥ 2025-09-01 을 N 으로 나눈 부분집합(따로 시뮬하지 않는다), 원장 밖.
- **DSR:** 사전등록 바에 없다 — 기술용 N 만 적고 바에 쓰지 않는다.
