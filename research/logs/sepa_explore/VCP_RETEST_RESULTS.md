## 구현 메모 (모호했던 곳과 정한 것 — 실행 전 결정)

- **셋업 행:** 주문일 d 의 셋업 = 신호 행 s = d−1 의 추세·RS·breadth·H5 와 s 종가까지의 VCP. 창 260일이 다 차지 않거나 결측이면 셋업 없음. 사건 구간은 **주문일** 기준. 분할 제외 = 조정 종가 / 원 종가 비가 2% 넘게 바뀐 날(같은 날 ≥ 5건인 수집 배치일 제외)부터 60 거래일 + VCP 통과 셋업의 거래량 창 [ip−49, s] 안 개별 변화.
- **지그재그(정정 2 A-C1):** 봉마다 상태 전이 하나, 진행 방향 극값 먼저·반전 확인은 다음 봉부터(두 상태 대칭). 동률은 늦은 봉. 피벗 = 오름 상태면 마지막 확정 저점 뒤 진행 중 최고 고가, 내림 상태면 마지막 확정 고점. **저점 상승(정정 2 A-M3):** L_k ≥ L_{k−1}×0.99. H0 윗꼬리 = (H0 − max(시가, 종가)) / H0 ≥ 8% 표시(기술).
- **거래량 마름(정정 M7):** mean(vol[ip+1..s]) ≤ 0.8 × mean(vol[ip−49..ip]) — 비교 창은 피벗 봉을 포함한 50일.
- **매수정지·손절:** 주문가 = 피벗 + `tick_size_vec(피벗)`, 손절가 = L_last − `tick_size_vec(L_last)`(현행 호가표를 분할조정가에 — 리뷰 MINOR 3 한계). 진입가 = max(시가, 주문가) × 1.001, 손절·본전 매도가 × 0.999. 진입일 2R 익절 불인정, 진입일 종가 < 피벗 → 다음날 시가(정정 M8). 본전선 = 진입가(라이브 기본).
- **진입일 순서(정정 C3·정정 2 B-M1):** 진입일 종가 ≤ 손절가 = 확정 손절(두 경로 같음). 모호 = 시가 ≤ 피벗 ∧ 저가 ≤ 손절가 ∧ 종가 > 손절가. 한 시뮬에서 낙관 경로와 보수 경로(진입일 손절가 × 0.999, 비용은 진입일 세율)를 함께 내고, 바 숫자는 모호 거래를 가중 p·1−p 두 행으로 펼친 가중 통계. p 추정도 같은 식으로 모호 사건을 고르고 확정 손절은 분모 밖.
- **바 5(정정 C4·정정 2):** 1배 순수익으로 판정(손실 = 순 < 0, 손익비, 평균 손실 R = 손실 거래 순/그 거래 d, R 5백분위, 순 < −12%), 2배 값은 5′ 줄(기술). 바 2·3 = 2배. 3분류 본전 = |순| < 0.5%.
- **완결 거래만:** 가중 행 단위로 낙관 경로 `data_end` 행만 뺀다(모호 거래의 보수 행은 완결).
- **NXT(정정 2 B-M3):** 2026-09-14+ 미보정 행이 있는 종목은 보유 경로를 2026-09-11 종가에서 `data_end` 로 끊는다(트레이드·널·대조).
- **실적(정정 M2):** 최신 분기 = 그날 보이는 가장 늦은 분기(미루지 않음), Q4 단독 = 연간 − 같은 해 Q1~Q3(전년 동기도 당해 보고서 비교 수치끼리), yoy_prev 는 직전 분기 전년 동기 > 0 일 때만, 140일 문 없음. 이중 시간축은 사실상 `avail_date`(기한 고정값) 한 축이다 — 지연 공시자의 룩어헤드는 보정 불가(한계).
- **수급(정정 M3):** F_base 주 = 하루 (외국인+기관)/`acc_trde_qty` 의 거래대금 가중평균(i0+1..s, 알려진 날 ≥ 80%), 모름은 팔에서 빠진다(모름 수를 기반 길이별로 깔때기에). 널의 수급 창 = 그 셋업의 k일 피벗 창.
- **널(정정 M1):** 날짜 맞춤 단위 = 주문월, d 3분위 경계 = 그 V 팔 체결 d 의 1/3·2/3 분위, 널 피벗도 피벗 뒤 ≥ 3일. 널 풀은 VCP 셋업이 아닌 행이라 같은 (종목, 날짜)를 쓰지 않는다(러너 단언).
- **X1:** V0 셋업 행 d 에서 종가 > 피벗 ∧ 거래량 ≥ 1.5 × 직전 50일(d−50..d−1) 평균 → d+1 시가, 추격 5%·상한가·정지 버림, 손절 = 새 손절(2% 하한), d > 10% 면 안 산다, 피벗당 첫 신호 하나. **X2(정정 2 B-M2):** V0 와 같은 매수정지·주문 전 거르기, 손절만 min(low[d−10..d−1]) × 0.99 를 [3%, 10%] 로 자름. **X2L** = 문구판(진입일 저가 포함, 기술).
