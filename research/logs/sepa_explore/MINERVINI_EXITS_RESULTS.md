## 구현 메모 (모호했던 곳과 정한 것 — 실행 전 결정)

- **시뮬레이터:** `research/signals/minervini_exits.py`(6ce5b7c) 모듈 독스트링 1~11 그대로. 요점: VCP 거래량 비의 '직전 50일' = 수축 창 직전 t−60..t−11; 수축 저점 = min(low[t−10..t]) (돌파일 포함); d 를 [3%,10%] 로 자른 뒤 손절가 = 진입가×(1−d); 같은 날 손절·익절 → 손절; 익절 전엔 MA 추적 없음; 본전 손절은 익절 다음 거래일부터(갭 상승 시가 익절일만 그날); 시간 손절은 20일째 한 번.
- **실적 문:** PEAD 순위 = `Data.earn.pead_rank`(스윙 3호·탐색과 같은 유니버스 안 순위). E = 탐색 격자의 E(YoY ≥ 25%, 나이 ≤ 140일, `e_pass`).
- **손절 고정 8%:** 수축 저점 거르기(시가 ≤ 수축 저점 → 버림)는 그대로 — 칸끼리 진입 집합을 같게.
- **대조:** 풀 = 트레이드 사건일마다 그날 유니버스 전 종목을 **같은 칸 규칙**으로 `control_minervini`(자기 수축 저점·피벗 = 직전 50일 최고 고가, 겹침 허용). 층·추출은 `sepa_momentum.matched_on`(모멘텀 = `STRATA_MOM`, 기존 = `STRATA_OLD`) 그대로. alpha 는 비용 전 총수익(탐색·모멘텀 재측정과 같다).
- **비용:** `korea.cost_rt(청산일, 시장)` 1회(사전등록: 분할 청산도 총량 같음). 청산일 = 마지막(나머지 절반) 청산일.
- **바 3:** 평균 이익·손실은 비용 차감 순수익(> 0 / < 0), 비 = 평균 이익 / |평균 손실|. 기대값 R = mean(순수익 / d).
- **바 5 연도:** 사건 연도별 비용 차감 순평균 > 0 인 연도가 과반(탐색 '연도 양수' 와 같은 정의). 연도별 모멘텀 alpha 양수 연도 수도 함께 적는다.
- **바 6 DSR:** 건당 비용 차감 순수익, core `deflated_sharpe_from_sample`(시행별 Sharpe 표준편차 = 코어 기본), N = 원장에서 읽은 값.
- **지수 헤지:** 진입 ≥ 2024-01-26 트레이드의 (총수익 − 진입일 시가→마지막 청산일 종가 KOSPI/KOSDAQ 지수 수익) − 비용. 분할 청산의 절반은 더 일찍 나가므로 헤지 구간이 근사다.
- **손절 없음 + 120일 비교:** 같은 사건 표에 `sepa.simulate_sepa(stop=1.0, max_hold=120, MA 청산 없음)`. 겹침 규칙이 보유 기간에 따라 다르게 걸리고(프로토콜은 일찍 나가 재진입이 더 많다) 수축 저점 거르기는 프로토콜에만 있으므로 **공통 사건 키**에서만 나란히 놓는다.
