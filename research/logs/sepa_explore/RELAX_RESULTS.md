- **축소의 부호:** RELAX.md 3절은 효과를 '칸 alpha − 기준 alpha' 로 적고 같은 문단에서 P(효과 > 0) 을 '그 조건이 alpha 를 올린다' 의 확률이라 부른다. 칸 = 기준 − 조건이라 두 문장은 부호가 반대다. 판단 규칙('P < 0.5 → 표본만 깎는 조건')이 뜻을 갖는 쪽인 **δ = α(기준) − α(기준 − 조건)** 으로 셈한다(결과 보기 전 결정). 표의 '원값'도 이 부호다.
- **축소 모형:** δ_k ~ N(θ_k, s_k²), θ_k ~ N(0, τ²), τ² = 주변우도 최대(≥ 0). 사후 평균 B·δ, 사후 sd √B·s. τ̂² = 0 이면 사후가 0 한 점 → P = 0.5 로 적고 '퇴화' 표시(규칙 1 문턱 < 0.5 에 걸리지 않는다). 주 = F 없음판·전 구간·트레이드당. F 포함판·보유일당은 참고로 같은 식. **주의(감사 반영):** 층이 얇고(위 '층 얇기') 칸끼리 트레이드를 많이 공유해 δ 의 표준오차가 크면 τ̂² 가 0 으로 무너져 모든 조건이 P ≈ 0.5(퇴화)로 나올 수 있다 — 그때 규칙 1 은 아무 조건도 거르지 못하며, 그것은 '조건이 일하지 않는다' 가 아니라 '이 표본으로는 가를 수 없다' 이다. 조건이 8~9개뿐이라 τ² 추정 자체도 거칠다.
