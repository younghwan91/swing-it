# 하락 쐐기 바닥(D) 진입 — H0 = A (사전등록 — 결과 보기 전 — 2026-10-10 · 탐색 표시)

## 왜 · 무엇이 다른가

사용자(쐐기 시험 차트 12건을 본 뒤, 2026-10-10): **"대체적으로 잘했는데 H0 포함해서 A 로 카운팅하고 다시 해 봐. 그리고 매수는 D 에서 해 봐(바닥에서)."**

- **반전점:** A = 천장 H0(고점) → B(저점) → C(낮아진 고점) → D(낮아진 저점). 상단선 = A–C, 하단선 = B–D. 쐐기 시험(`WEDGE_TEST.md`)은 H0 를 쐐기 밖에 두고 A~E 다섯 점을 썼다.
- **매수:** 상단선 돌파가 아니라 **바닥 D 에서**. D 는 반등이 시작돼야 알 수 있으므로 → **D 봉(그때까지의 최저 저가 봉) 고가 + 1호가 매수정지**, 손절 = D − 1호가(좁다).

**오염 표시(결과 전 고정):** 이 정의는 사용자가 같은 KRX 데이터의 쐐기 진입 차트를 본 뒤 나왔다. 쐐기 시험 판정문의 "이 데이터에서 정의를 바꿔 다시 돌리지 않는다" 를 **사용자 지시로 예외** 처리하며,
그래서 이 시험의 결과는 판정이 아니라 **탐색**이다 — 통과 바를 넘어도 "전진 페이퍼·독립 표본(미국 등) 확인 후보" 까지만. 원장에 사슬(VCP → 쐐기 → 쐐기 D) 한 줄.

## 정의 (고정)

셋업은 d−1 종가까지, 주문은 d 일 장중 매수정지. 데이터·유니버스·비용·NXT·분할 규칙은 쐐기 시험과 같다.

### 1. 맥락 (쐐기 시험과 같다)
천장 A = H0 = d−1 까지 260일 창 최고 고가(동률 늦은 봉), 위치 d−1 보다 15 ~ 250 거래일 앞. H0 일 추세 템플릿 ∧ RS ≥ 70. d−1 MA50 > MA150 > MA200 ∧ MA200 상승. breadth > 0.5.

### 2. 쐐기 A–B–C–D
지그재그(θ = 5%, 극값 먼저)로 H0 부터 반전점.
- **B** = H0 뒤 첫 확정 저점, **C** = B 뒤 확정 고점(H0 뒤 **마지막** 확정 고점), **D** = C 이후 d−1 까지 최저 저가(진행 중 — 확정 불필요).
  H0 와 B 사이·B 와 C 사이에 다른 반전점이 있으면(지그재그가 더 출렁였으면) 셋업 없음 — 쐐기는 A·B·C·D 네 점이 연속이어야 한다.
- 고점 하락: C ≤ A × 0.99. 저점 하락: D < B.
- 수렴: c_1 = (A − B)/A ∈ [8%, 40%], c_2 = (C − D)/C < c_1, c_2 ≤ 15%.
- 기울기(로그가격, %/일): 상단 A–C < 0, 하단 B–D < 0, **상단 < 하단**(좁아진다).
- 간격: A→B, B→C, C→D 각 ≥ 3 거래일, A → d−1 ≥ 15 거래일.
- 무결성: A ~ d−1 의 종가가 상단선 × 1.005 위로 나간 날이 없다(쐐기 안 — 이미 돌파한 경우 제외), 하단선 × 0.97 아래로 마감한 날이 없다.
- 거래량 마름: C 다음날 ~ d−1 평균 거래량 ≤ H0 이전 50일 평균 × 0.9.

### 3. 진입 — 바닥 반전 매수정지
- D 봉 = C 이후 최저 저가를 찍은 봉(iD ≤ d−1). 주문가 = D 봉 고가 + 1호가. 조건: d − iD ≤ 5 거래일(바닥 근처만), d−1 종가 < 주문가.
- d 일 고가 ≥ 주문가면 체결 = max(시가, 주문가), 시가가 주문가 × 1.03 초과면 안 산다. d 일 저가가 D 아래로 먼저 갔는지 모르는 모호성 = 분봉 p 혼합(같은 정의로 다시 잰다), 보수·낙관 경계.
- 새 최저가가 나오면 D 가 옮겨 간다(같은 쐐기 = 같은 A·B·C, 첫 체결 하나).
- 손절 = D − 1호가. (주문가 − 손절)/주문가 > 9.5% 면 주문 없음, < 2% 면 체결가 × 0.98.

### 4. 청산
- 2R 전: 손절만(장중, 시가가 손절가 아래면 시가). 돌파 실패 규칙 없음(피벗 위에서 산 게 아니다).
- 2R 절반 익절 → 나머지 본전 + MA50 추적(종가 < MA50 → 다음날 시가). 120 거래일 상한. 진입일 2R 익절 불인정.
