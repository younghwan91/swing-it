# 유전 알고리즘(GA) 문턱 최적화 — numba 가속 (설계 고정 — 결과 보기 전 — 2026-10-10)

사용자 지시(2026-10-10): "넘바나 뭘로 가속화해서 GA 방식으로 최적화해 보던가."
`RELAX.md`(BO 40회)와 같은 질문을 더 넓게 판다. 평가가 수천 번이 되므로 **과최적 장치를 더 세게** 건다.

## 가속 구조

1. **사전 계산(한 번):** 청산 규칙(미너비니 원전 프로토콜)은 고정 → 추세 템플릿을 통과한 모든 (종목, 날짜) 후보에 대해
   진입 체결 여부·트레이드 수익·청산일·보유일·모멘텀 정합 초과(대조 풀도 고정)를 미리 시뮬해 배열로 둔다. 피처(rs, vol_mult, pead_rank, rel,
   breadth, 피벗 창 20/30/40/50/60 별 돌파 여부, F)도 같은 배열에. 가격은 `krx_session` 보정판.
2. **numba 적합도:** config → 마스크 → 같은 종목 겹침 제거(진입일 순 탐욕, 보유 중 신호 버림 — `sepa` 규칙과 동일) → TRAIN 트레이드의
   정합 초과 부트스트랩 2.5% 하단. **패리티 테스트:** 사전 계산 + 겹침 제거 결과 = `simulate_minervini` 직접 실행 결과(같은 config 몇 개, 트레이드 단위 일치).

## GA

- 유전자(RELAX 와 같은 공간): rs_min [40, 90], vol_mult [0.8, 2.0], pead_min [0.0, 0.9], rel_max [0.6, 3.0], breadth_min [0.0, 0.6],
  pivot_window ∈ {20, 30, 40, 50, 60}.
- 개체 60, 세대 30, 토너먼트 3, 블렌드 교차(α 0.5), 가우시안 변이(범위의 10%, 확률 0.2), 엘리트 2. **시드 5개**(0~4)로 따로 돌린다.
- 적합도 = TRAIN(진입 < 2022-01-01) 정합 초과의 부트스트랩 2.5% 하단(500회), 거래수 < 150 이면 하한 페널티(`make_objective` 와 같은 모양).
  OOS 는 적합도에 **절대** 안 들어간다.

## 과최적 장치 (전부 보고)

1. 시드 5개의 최적 config 가 서로 가까운가(유전자별 범위) — 흩어지면 평평한 노이즈 지형.
2. 평가된 모든 고유 config 의 TRAIN 적합도 순위 vs OOS(2022-01-01 ~ 2026-04-01) 정합 alpha 순위 스피어만.
3. PBO(CSCV, 월별 정합 초과) — 마지막 세대 전체 개체 × 5 시드.
4. DSR — N = 평가한 고유 config 수 + 이 계열 원장 누적.
5. 시드별 최적 config 를 OOS 유동(ADV ≥ 200억)·OOS 중소형(50~200억)에 **한 번** 적용, 트레이드당·보유 1일당 alpha, n, 손절 비율, 이익/손실.
6. 기준(사전등록 A − F)과 RELAX 의 BO 최적과 나란히.
7. F 추가: 시드별 최적 ∧ F=1, 2024-02-19+.

## 판단 규칙 (미리 적음 — 판정 아님, 다음 사전등록 후보 선정)

시드 5개 중 **4개 이상**의 최적 config 가 OOS 유동·중소형 **둘 다**에서 모멘텀 alpha 점추정 > 0 이고, TRAIN→OOS 순위 상관 > 0.2, PBO < 0.5 이면
시드 최적들의 유전자 중앙값 config 를 다음 사전등록 + 전진 페이퍼 후보로 올린다. 아니면 "GA 로도 표본 밖에서 살아남는 문턱 없음" 으로 적는다.
