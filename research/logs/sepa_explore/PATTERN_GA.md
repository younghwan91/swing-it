# 패턴 GA — 수렴 모양·천장·돌파·청산 구조를 유전자로 (사전등록 — 결과 보기 전 — 2026-10-10)

## 왜

사용자(2026-10-10): **"이렇게 새로운 걸 시도해 보라고 GA 를 하라고 했던 건데."**
앞선 GA·GA2(CMA-ES, 124만 설정)는 **고정된 진입 틀 하나**(신호일 종가 돌파 → 다음날 시가, 수축 저점 손절)의 문턱 숫자만 바꿨다. 수렴의 **모양**(상승 쐐기·하락 쐐기·평평한 천장·대칭 삼각),
천장과의 거리, 추세선 돌파 매수정지, 돌파 실패 여유, 본전 이동 같은 **구조**는 유전자에 없었다 — 그래서 GA 는 사용자가 차트로 찾은 것(VCP 진입이 전부 상승 쐐기였다, `VCP_RETEST.md` 이후 대화)을 찾을 수 없었다.
이 GA 는 구조를 연속 유전자로 열어 **모양 선택 자체를 탐색**한다. 수동 정의 시험(`WEDGE_TEST.md`, 기술 전용)은 이 GA 공간의 한 점이다.

## 정정 0 — "이길 때 더 먹는다" 청산 유전자 (2026-10-10, 결과 전 · 설계 리뷰 중, 사용자 지시)

사용자: "손실 케이스가 더 많은 건 괜찮다 — 승률이 낮은 건 먹을 때 더 먹으면 되니까." 동기(사후 기술, 증거 아님): VCP 재시험 V0 이익 거래 7건의 실현 이익은 보유 중 최고 상승폭의 약 1/3
(테이팩스 +18.0% vs 최고 +49.5%, KG케미칼 +11.8% vs +47.4%, 골프존 +14.3% vs +40.8%) — 2R 절반 익절이 위를 자르고 MA50 추적이 꼭대기에서 많이 돌려줬다.
청산 무리를 넓힌다(진입·모양 유전자는 그대로):

| 유전자 | 범위 |
|---|---|
| `take_r` 부분 익절 배수 | {끔, 2, 3, 4} R |
| `take_frac` 부분 익절 비율 | {1/3, 1/2} |
| `trail` 추적 방식 | {MA20, MA50, 최고가 − k×ATR20(샹들리에)} |
| `trail_k` 샹들리에 배수 | 2 ~ 5 (`trail` = 샹들리에일 때) |
| `trail_tighten` 수익 구간 조임 | {끔, +3R 이상이면 k 를 절반} |
| `pyramid` 불타기 | {끔, +1R 도달 다음날 시가 1 단위 추가, 진입 뒤 첫 신고가(H0 돌파) 다음날 시가 1 단위 추가} |

- 불타기: 추가분은 같은 슬롯 안(슬롯 자본 10% 를 처음 2/3·추가 1/3 로 나눈다 — 불타기 끔이면 처음 100%), 추가분 손절 = 그 시점 손절선(본전 이상), 같은 날 우선순위 손절 > 익절 > 추가.
- 샹들리에 = 진입 뒤 최고 고가 − k × ATR20(진입일 값 고정 아님, 매일 갱신), 종가 < 선 → 다음날 시가.
- 보고에 **이익 거래의 포착률**(실현 이익 / 보유 중 최고 상승폭) 분포를 GA 최적·널·기준(라이브 청산) 각각.

## 정정 1 — 설계 리뷰 반영 (2026-10-10, `REVIEW_PATTERN_GA.md` 1단계, 결과 전)

리뷰의 "사전등록 정정 요구(정정 1 초안)" 12항목과 MINOR 1~12 를 **전부 그대로 채택**한다(그 문서가 이 절의 정본 — 아래는 요약과 결정).
- **바 2 교체(C1):** (2a) 실현 가능 조건부 같은 메뉴 **무최적화** 무작위 설정 300벌 p95 · (2b) **모양 서술자를 같은 달 안에서 섞은** 데이터에서 GA 절차 전체 50벌 p95 — 둘 다 넘어야. 같은 예산 무작위 탐색은 기술.
- **주장 범위(C2):** 리뷰 "입증할 수 있는 것 / 없는 것" 문구를 결과 문서에 그대로 옮긴다. GA 결과로 VCP·쐐기 판정을 되살리지 않는다. **이 정정 커밋 해시가 쐐기 시험 전체 실행보다 앞선다**(쐐기 결과 미관측 — 깔때기 건수만 봄).
  사용자 착상 영역(정규화 좌표, 결과 전 고정): 하락 쐐기 = ŝ_up < 0 ∧ ŝ_lo < 0 ∧ ŝ_up < ŝ_lo, 기준선 = 상단 추세선, `fb_days` = 2. GA 최적이 이 영역 안이면 "착상과 같은 데이터" 표시.
- **모양 부호화(C3):** 정규화 기울기 ŝ = s × L / h(L 패턴 길이, h 패턴 높이), 폭 비 ρ = 끝 폭/시작 폭, (중심, 반폭) 부호화, `conv` → ρ 상한. 모양 위생 고정(간격 ≥ 3, 길이 ≥ 15, 진행 중 저점, 첫 관통, 무결성, 상단선 H0 제외 — 쐐기 정정 0·1·2 와 같은 위생), 적합도 −∞ 대신 연속 벌점, 실현 가능 초기점.
- **적합도 대조(C4):** 종목별 모멘텀 정합 바스켓(같은 날·시장·12-1 10분위·ADV 2분위) — 코스피 TVW × 노출은 기술.
- **청산 확장(M1):** 불타기 추가분 손절 = 그 시점 손절선과 본전 중 높은 것, H0 기준선에서 신고가 불타기 금지, 추적은 진입 다음날부터, 조건 청산 상존(무기한 보유 방지 — 120일 안전 상한 유지), 샹들리에 = 진입 뒤 최고 고가 − k × ATR20(d−1 값), 같은 날 우선순위 표. 보고: 노출당 초과, 불타기 짝, MFE 구간별 포착·되돌림·"+1R → 손실" 비율, 기준 청산 짝, 상위 5거래·2021 제외.
- **출력·바(M2·M3):** 절차 출력 = 시드 최적들을 새 RNG 로 재평가한 1등(중앙값 config 는 조건부 기술), PBO = 폴드 내 CSCV 기술, WFE 삭제, 바 4 = 2022~24 조각 > 0 ∧ 두 상승 묶음(2020~21·2025~26) 뺀 값 > 0, 체결 < 20 폴드는 판단 불가. DSR N = 보고 변형·검증 구조 수.
- **최적화(M4·M5):** 시드 10 × 런당 10,000 평가, θ ∈ {3, 4, 5, 6, 8, 10}% · `ceil_win` ∈ {60, 120, 260} 격자, 필터는 첫 관통일 d−1 에서만(실패 = 패턴 끝, `gap_max` 초과도 소진), 사건 표 사전계산·memmap.
- **분해·용량(M6·M7):** 모양 비활성 짝 config·모양 선택도, 연도별 체결 ≥ 4, 10억~50억 분봉 커버리지 건수, 미끄러짐 +0.3·+0.5% 민감도, 개인 계좌(1~3억) ADV 비율.
- **차트(MINOR 10):** OOS 트레이드 차트 = seed 20261011 로 무작위 12건. **차트를 본 뒤의 정의 수정은 새 사전등록 · 이 데이터 재시험 금지**. 원장에 "차트 열람 → 정의 수정 → 같은 데이터 재시험" 사슬(VCP → 쐐기 → 패턴 GA) 한 줄.
- 다음: 실현 가능 비율·사건 표 건수·분봉 커버리지(건수만)를 결과 전에 세어 붙이고, 구현 → 코드 리뷰(리뷰 2단계 체크 항목) → 실행.

## 정정 2 — "상승하다가 쉬어가는 것" 맥락 유전자 (2026-10-10, 결과 전, 사용자 지시)

사용자: "상승하다가 쉬어가는 게 하락 쐐기." 하락 쐐기(그리고 일반 수렴)는 **급등 → 쉼 → 상단 돌파** 의 지속형이다. 쉼의 맥락을 유전자로 연다:
| 유전자 | 범위 | 정의 |
|---|---|---|
| `runup_win` | {20, 40, 60} 거래일 | H0 까지의 상승 측정 창 |
| `runup_min` | 0% ~ 100% | H0 / min(low[H0 − runup_win .. H0]) − 1 ≥ runup_min |
| `rest_gap_max` | 3 ~ 120 거래일 | H0 → 패턴 첫 저점(A) 거리 상한 — 짧을수록 "고점 직후 쉼" |
- 둘 다 d−1 이전 자료(H0·A 는 d−1 이전)라 룩어헤드 없음. 사용자 착상 영역(정정 1 C2)에 "runup_min ≥ 30% ∧ rest_gap_max ≤ 20" 을 더한다(좌표 고정).
- 쐐기 시험(`WEDGE_TEST.md`)은 이미 실행 중 — 정의를 바꾸지 않고 결과 문서에 H0→A 거리·H0 전 상승률 구간별 기술 표만 더한다.

## 정정 3 — 천장 종류·H0 = 첫 점·바닥 진입 (2026-10-10, 결과 전)

- `ceil_kind` {단일 고점 H0, 수평 저항(창 안 고점 2개 이상이 ±3% 안)}.
- `h0_in_pattern` {H0 = 패턴 첫 고점(상단선 H0–C), H0 는 패턴 밖(상단선 = 마지막 두 고점)}.
