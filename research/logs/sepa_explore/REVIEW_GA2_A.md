## 2. 학습창 끝 시가평가 — 시험 구간 가격이 적합도에 안 들어가는가 (`leak_test.py`)

방법: 폴드 1·4·5 각각, 절단 행(`Win.cut` = test_lo 첫 거래일) 이후의 **O·C 를 [0.5, 1.5] 무작위 배수, H·L 도 무작위(H ≥ max(O,C), L ≤ min(O,C) 유지), MA10/20/50 무작위, 비용표 ×3**, 그리고 학습창 밖(신호일 ∉ [d_lo, d_hi)) 쌍의 진입 피처 18종(tt·rs·breadth·pead·rel·brk_bits·vol·vavg·nh·al·stack·slope_bits·eps 3·chase_bits·entry_open·clow)을 서로 섞은 사전계산 사본으로 두 번째 `Engine` 을 만들고, 폴드당 config 8개(무작위 6 + 120일·추적50 + 익절 ∞·추적20·돌파실패)에 대해 `fitness(port/trade/day)`·`is_point`(연환산·월별·트레이드 서술)·시험 창 포트폴리오 조각·트레이드 초과를 비교. 시험 창 쪽은 시험 절단(다음 폴드 test_lo) 뒤를 같은 식으로 바꿔 따로 비교.

| 학습 적합도 3종 × 24 config | 최대 차 **port 2.4e−9 · trade 9.4e−11 · day 1.5e−11**, 17/24 config 는 전 항목 정확히 0 |

앞 리뷰 K-C1/K2-C1 의 정정 확인: `purge` 는 주석에만 남았고(grep), `fit_trade`→`excess(…, cut)`→`trade_excess(sel, cutv, …)`→`_mark`, `portfolio(…, cut)`→`cutv`, `is_point`·`stitched`·`landscape_task`·`pbo_of`·수급 창 전부 같은 절단을 받는다. K2-M1(처리량 하한 → 주문 60), K-M3(짝 없는 포지션 손익·비용 0), D-M9(연속 포트폴리오·경계 시가평가)도 코드에 있다.

## 4. 대조 풀·층·캐시 키 (`strata_port.py`)

- 풀 = 체결(`status == OK`) ∧ 그 창·추격 단계 통과(`chase_bits`), 같은 층, **자기 제외**, 5개 복원 추출(쌍·추출 해시). 세 (창, 추격) 조합에서 대조 쌍의 층 == 트레이드 층 **전부 참**, 자기 번호 없음, 대조 전부 풀 안. 체결 쌍 중 짝 없음 3.5%(34k/1M).
- **캐시 키:** 대조 *번호* 는 `(w_idx, c_idx)` 로만 캐시되고(청산과 무관 — 맞다, 번호는 체결·추격에만 의존), 대조 *수익* 은 평가 때 그 config 의 `ek` 청산 배열(`e["x"], e["ret"], e["r2"], e["pab"]`)에서 `_mark` 로 읽는다. 검증: 같은 트레이드 집합에 ek1·ek2 를 번갈아 평가 → 대조 수익이 97.6% 에서 다르고, ek1 을 다시 평가하면 처음과 **비트 일치**; ek1 의 대조 평균을 청산 배열에서 손으로 다시 계산해 엔진 값과 일치(1e−12). → "다른 청산 규칙의 대조" 가 섞이는 경로는 없다.
- 돌파 실패 켬이면 `ek` 에 그 config 의 피벗 창이 들어가(`ek[6]`) 창이 다른 두 config 는 다른 시뮬을 쓴다 ✓. 대조 종목도 같은 프로토콜(자기 창 피벗) ✓.
- `Engine.exit` 의 연도 덩어리 캐시는 신호일 연도 기준이라 대조(같은 날)는 항상 같은 덩어리 ✓.

- **현금**: 빈 슬롯 0, 진입 비중 10% 고정·복리 없음 ✓. **비용은 매도일**(`cost_tab[청산 행, 시장]`, 절단 시 절단 전날) ✓ 30개 표본 불일치 0. **대조 일할**: `Σ대조/5/(xe−pd)` 를 보유일(xe−pd 일) 마다 뺌 → 합 = 대조 평균 ✓(수평 불일치 D-M3/K-M2 는 설계대로 남아 있다). **짝 없음**: 손익·비용 0, 슬롯만 ✓(합성·실데이터 둘 다).
- **합 항등식(실데이터·절단 포함)**: 일별 합 = 0.1 × Σ(초과 − 비용 | 짝 있음), 차 2.8e−8(= A-m1 의 float32 경로; 합성 테스트는 1e−9 통과).
- **블록 부트스트랩**: 이동 블록(블록 3, nb = ⌈M/3⌉ 개 시작점 균등, M 에서 자름, Σ/M×12) — 설계 "3개월 블록 500회 2.5% 하단" 대로; 원형 아님(D-M7 그대로). 36개월이면 시작점 34개 × 12블록. 연환산 = 월합 평균 × 12(가산 회계와 정합).
- 적합도 하한: 처리량은 **주문 수 ≥ 60**(`n_ord`, 체결 무관), 트레이드당·1일당은 짝 있는 트레이드 ≥ 150 — 설계 정정 절과 같다.
- 부트스트랩·대조 난수는 (seed 0) 고정 해시 — CMA 시드·스레드 수와 무관하게 결정적(`prange` 안에 교차 스레드 축약 없음, 아래 8 과 재현성 테스트).

## 6. CMAwM 부호화·BIPOP·메모 (`encode_bipop.py`, 합성)

- 유전자 19 = 연속 9 + 이산 10(러너 모듈 docstring 의 "16 = 7 + 9" 는 **구판 문구** — A-m7).
- **복호 → 부호 → 복호** 를 연속 유전자마다 u ∈ [0,1] 200,001 점에서: 끔/켬 상태와 값이 보존된다 — 단 **끔 경계 바로 위 폭 ≈ 1.5e−5 의 띠**에서 4자리 반올림이 값을 경계로 내려 끔으로 뒤집힌다(vol_mult 3점·breadth_min 14·pead_min 10·eps_yoy_min 9·rel_max 2 / 200,001; 예 `eps_yoy_min` u=0.020005 → 0.02 → 끔). `g2_median`·`landscape_task` 가 encode→decode 를 쓰므로 확률 ~5e−5 로 "켬" 시드 최적이 중앙값에서 "끔" 이 될 수 있다(A-m3, 무시 가능).
- 이산: 반올림(0.5 는 짝수 쪽)·범위 밖 클립, 끝 단계 = ∞/없음(chase·take_r ∞, trail 0, failed_breakout 1, max_hold 120, pivot 60) ✓. CMAwM 의 `x_eval` 이산 축은 **항상 정수·범위 안**, 연속 축 [0,1] 안(1,600 ask 전부) ✓. `ask()` 의 (평가용, tell 용) 두 벡터 사용 ✓(앞 리뷰와 같음).
- `g2_spec`: 창 0 → `w_idx = W50`·`g[5] = −1`, 돌파 실패 켬 → `ek[6]` = 그 창(창 0 이면 50) ✓.
- **메모 키**: `g2_key`(복호된 값 튜플) — 같은 유전자로 복호되는 두 x 는 같은 적합도이므로 올바른 키. `_key_hash`(blake2b 64비트) 200,000 키에서 충돌 0.
- **시드 결정성**: 같은 시드 두 번 → 1,600 이력 전부 동일, 다른 시드 → 다름 ✓.
- **BIPOP**: Hansen(2009) 규칙대로 첫 런 λ₀ = 4+⌊3 ln 19⌋ = 12, 작은 체제 λ = ⌊λ₀(½λ_L/λ₀)^{U²}⌋·σ = σ₀10^{−2U}, 큰 체제 λ_L ×2; `small_used < large_used` 교대; 정체 재시작 `10 + ⌈30·19/λ⌉` 세대(λ 12 → 58세대 = 696 평가). 내 잡음 지형(1,600 예산)에서는 재시작 0(개선이 계속 나와 정체 안 됨); 실제 4차 로그는 6,400 예산에서 런마다 재시작 3 — 작동한다.
- **끔 구역 탐색률(A-m6)**: 1,600 ask 중 연속 유전자가 끔 구역(2%)에 떨어진 비율 0.3~0.6%, rel_max 0.0%. CMAwM 은 범위 밖 표본을 100회 **재추출**한 뒤에야 자르므로 경계 띠가 과대 표집되지 않는다 — "끔" 은 분포가 경계에 몰려야만 나온다. 최적이 안쪽일 때 낮은 것은 당연하므로 결함이라 하진 않겠다; 결과 문서의 유전자별 "끔 비율"(시드 최적 기준)과 `landscape.csv` 의 u=0 격자로 끔의 적합도를 확인할 것. NaN 절벽(K-M4)은 그대로다.

## 7. 폴드·절단·이어 붙이기 (`strata_port.py`)

- `FOLDS` = `rolling_folds()` 6개(2017→2020 … 2022~2024→2025-01-01~2027-01-01) 그대로, 러너가 새로 만들지 않음 ✓.
- 학습 창: 진입 ∈ [train_lo, train_hi), 절단 = test_lo 첫 거래일 — 6폴드 전부 **최대 진입 행 < 절단 행** ✓ (예: 폴드 1 진입 2018-01-02..2020-12-30, 절단 2021-01-04).
- 시험 창: 진입 ∈ [test_lo, test_hi), 절단 = 다음 폴드 test_lo(연속·경계 시가평가) — 폴드 0~4 ✓, 폴드 5 는 절단 = `EVENT_HI_NEXT`(2026-04-02) 인데 **진입 행 == 절단 행인 쌍 597개**가 창 안에 있다(신호 2026-04-01) → A-M1.
- 이어 붙인 OOS: `composite` 가 창마다 그 config 의 신호·체결·청산·대조 번호·절단 행을 채우고 `portfolio` 를 한 번 돈다 — 열린 포지션은 자기 폴드 절단에서 시가평가, 다음 폴드는 신규 진입만 새 config, 슬롯 공유 ✓. `fold_port` 조각은 [d_first, end) 월합 평균 × 12(12개월, 폴드 5 는 16개월).
- 분기 재적합: `quarters()` = 2020Q1 ~ 2026Q1 25개 + **스텁 (2026-04-01, 2026-04-02)** 1개 = 26 "분기". 스텁은 신호일 1일(2026-03-31)·쌍 605 — 학습 3년 CMA-ES 를 시드 5 × 6,400 평가 돌려 **하루짜리 OOS 조각**을 만들고 `qps["dec"]` 의 `n_folds`·`folds_pos` 에 1 로 들어간다(A-m4).
- 월 시계열의 첫 달은 첫 진입일부터(부분 달) — IS·OOS 모두 같은 규칙이라 WFE 에는 중립, 연환산은 미세하게 부풀 수 있다.

## 8. 수치 — float32 · NaN · numba vs 파이썬

- **float32**: `Engine.exit` 캐시의 `r2`(float32)와 `composite` 의 `r2`(float32). 포트폴리오 전체 수익 = 0.5·(2·ret − r2) + 0.5·r2 = ret 로 **합은 정확**하지만 절반 분할·절단 시가평가(`0.5·(r1 + m)`)에 ≈ 6e−8×|r2| 오차 → 2 의 잔차와 5 의 합 항등식 차 2.8e−8 의 원인. `dd` float32·`nh/al` float32 는 적합도에 영향 없음(문턱 비교의 7자리 반올림).
- **NaN**: 마스크 — 켠 조건은 NaN 탈락, 끔은 통과; `vavg > 0` 필요; 우선순위 rel NaN 은 뒤, RS NaN 은 앞에 못 섬 ✓. 시뮬 — NaN 가격 비교 False, 정지일 TR False ✓. `_block_boot_py` 는 M < 3 이면 음수 시작점(numba 는 경계 검사 없음) → `len(mo) ≥ 4/6` 가드가 막는다 ✓. `boot_lower_ratio` 는 nanpercentile ✓.
- **numba vs 파이썬(같은 프로세스, `numba_vs_py.py`)**: sim_pairs 6조합 × 40,000쌍(돌파 실패·익절 ∞·추적 없음 포함), mask_ga2 4벡터 × 144k, greedy, trade_excess(절단 포함), portfolio(폴드 3 학습창 743일), block_boot·boot_means·boot_ratio, draw_idx 120k — 전부 비트 일치. **그러나** 이것은 A-M2 의 이유로 `_sim_one`·`_mark`·`_h32`·`_first_tr` 자체는 양쪽 다 jit 판이다.
- **진짜 순수 파이썬 vs numba(`numba_vs_py2.py`)**: numba 커널을 먼저 전부 돌려 컴파일한 뒤 `gf._sim_one = _sim_one_py`, `gf._mark = _mark_py`, `gf._h32 = _h32_py`, `gf._first_tr = _first_tr.py_func` 로 되감고 같은 입력을 다시 계산 — sim_pairs 6조합 × 6,000쌍(돌파 실패·익절 ∞·전량 추적·추적 없음), trade_excess(절단), portfolio(폴드 3 학습창), block_boot·boot_means·boot_ratio, draw_idx 60k, greedy **13/13 비트 일치**. → A-M2 는 테스트 주장의 문제이지 결과의 문제가 아니다.
- **재현성**: 같은 입력 2회 → 동일(위), CMA 시드 결정성(6) ✓, `prange` 커널은 쓰기 위치가 분리돼 스레드 수에 무관 ✓.
