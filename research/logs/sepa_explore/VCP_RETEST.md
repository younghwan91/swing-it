# VCP 재시험 — 수렴 피벗 매수정지 진입 × 실적 가속 × 수급 (사전등록 — 결과 보기 전 — 2026-10-10)

## 왜 다시 하나 — 앞선 시험의 실수(사용자 지적, 2026-10-10)

사용자 가설: **"수렴에서 들어가야 손익비가 가장 좋다", "미너비니 + 실적 + 수급이 받치면 손실이 클 수 없다".**
앞선 시험들(`CONVERGENCE.md`, `MINERVINI_EXITS*.md`, 스윙 3호, GA·GA2, 라이브 백테스트)은 이 가설을 **시험하지 못했다**:

| # | 실수 | 증거 | 이번 수정 |
|---|---|---|---|
| M1 | 진입이 수렴점이 아니었다 — 신호일 **종가** 돌파 후 **다음날 시가** | 진입 시 MA50 위 평균 18%, 손절의 93~98% 가 상한 10% 에 붙음 | 피벗 **매수정지(buy-stop)** — 장중 피벗 도달 시 체결 |
| M2 | "수렴" = 직전 10일 고저폭 ≤ 12% 하나(또는 rel) | 사후 경계 rel ≤ 1.33 은 "덜 확대된 돌파" | 기반 안의 **연속 축소 수축**(VCP) 알고리즘 |
| M3 | 손절 = 돌파일 포함 10일 저점, 폭이 10% 를 넘으면 **10% 로 잘라** 들어감 | 구조와 무관한 손절, R 이 작음 | 손절 = **마지막 수축 저점**, 10% 넘으면 **안 산다** |
| M4 | 실적 = 순이익 YoY 순위(Q4 는 연간값), 적자 기저효과 포함 | 상위가 기저효과·흑자전환 바구니(YoY 중앙 16배, 전년 적자 42%) | 분기 단독 Q4(연간 − 9M), 전년 흑자 필수, **가속** |
| M5 | 수급 = 20일 F 이진 플래그 | — | **기반 기간** 외국인+기관 누적 순매수 / 거래량 |

## 정의 (고정)

모든 셋업 조건은 **d−1 종가까지의 자료**로 계산하고, 주문은 d 일 장중 매수정지다(룩어헤드 없음).

### 1. 추세·강도 (기존 그대로)
추세 템플릿(`minervini.trend_template`) ∧ RS ≥ 70(`rs_rating`, 모집단 = 가격 패널 보통주 전체) ∧ 시장 breadth > 0.5 — 모두 d−1 값.

### 2. VCP (새 정의 — M2)
d−1 까지 120 거래일 창에서:
1. **좌측 고점 H0** = 창 안 최고 고가, 그 위치 i0 는 d−1 보다 **15 거래일 이상 앞**(기반 길이 ≥ 15일), 65 거래일 이하 앞(기반 ≤ 13주).
2. **지그재그(θ = 5%)** 로 i0 부터 d−1 까지 고가/저가 반전점을 찾는다: 고점 후보에서 저가가 5% 이상 내려오면 고점 확정, 저점 후보에서 고가가 5% 이상 올라오면 저점 확정.
   수축 k 의 깊이 c_k = (H_{k−1} − L_k) / H_{k−1}. **마지막 수축**은 마지막 확정 고점 H_last(= 피벗) 이후 d−1 까지의 최저 저가 L_last 로 잰다(진행 중 수축, 5% 미만이어도 된다).
3. 조건:
   - 수축 수 T ≥ 2(마지막 수축 포함), T ≤ 6.
   - 첫 수축 깊이 c_1 ∈ [10%, 40%].
   - **각 수축이 직전보다 작다**: c_k < c_{k−1} (모든 k).
   - **마지막 수축 c_last ≤ 10%**.
   - 피벗 H_last ≥ 0.85 × H0 (오른쪽이 고점 근처).
   - d−1 종가 < 피벗 (아직 돌파 전), d−1 종가 ≥ 피벗 × 0.90.
   - **거래량 마름**: 마지막 수축 기간(H_last 다음날 ~ d−1, 최소 3일) 평균 거래량 ≤ 0.8 × d−1 기준 직전 50일 평균 거래량.
4. 셋업이 여러 날 이어지면(돌파 전 대기) 매일 주문이 살아 있다 — 같은 피벗의 셋업은 **첫 체결 하나만**, 체결 후 보유 중엔 새 셋업 무시(no_overlap).

### 3. 진입 — 피벗 매수정지 (M1)
- 주문가 = 피벗 + 1호가(`korea.tick_size_vec`). d 일 고가 ≥ 주문가면 체결.
- 체결가 = max(d 일 시가, 주문가). **시가가 피벗 × 1.03 초과로 갭 상승하면 안 산다**(추격 금지, 원전의 "피벗 위 5% 이내" 보다 보수).
- 시가 상한가·거래정지(거래량 0)면 안 산다. 슬리피지는 비용 모델에 더해 **매수정지 체결가 +0.1%**.

### 4. 손절 (M3)
- 손절가 = 마지막 수축 저점 L_last − 1호가. 손절폭 d = (체결가 − 손절가) / 체결가.
- **d > 10% 면 체결하지 않은 것으로 본다**(주문 전에 피벗 기준으로 판단: (피벗 − 손절가)/피벗 > 9.5% 면 주문 없음; 갭 체결로 10% 를 넘으면 그날 시가 체결 후 손절가 그대로 — 기록).
- d < 2% 면 손절가 = 체결가 × 0.98(노이즈 하한).

### 5. 청산 — 라이브 프로토콜 그대로 (탐색 안 함)
수축 저점 손절(장중, 시가가 손절가 아래면 시가), 2R 절반 익절 + 본전, 나머지 MA50 추적(종가 < MA50 → 다음날 시가),
**돌파 실패** = 익절 전 종가 < 피벗 → 다음날 시가 전량, 시간 손절 없음, 120 거래일 안전 상한.

**진입일 같은 날 손절 모호성:** 일봉으로는 진입(피벗 도달) 전 저가인지 후 저가인지 모른다.
- **주(보수):** 진입일 저가 ≤ 손절가면 손절가에 손절(시가 < 손절가인 경우 포함).
- 기술(낙관): 진입일 저가가 시가 쪽에서 먼저 났다고 보고(시가 ≤ 피벗이고 저가 ≤ 손절가면 손절 없음) 종가 규칙만.
- 분봉 구간(2025-08+)에서 실제 순서를 세어 보수 가정의 오차를 적는다.

### 6. 실적 (M4)
- 분기 단독 순이익: Q1~Q3 그대로, **Q4 = 연간 − (Q1+Q2+Q3)**(같은 회계연도 세 분기가 그날 알려져 있을 때만, 아니면 Q4 모름). 전년 동기도 같은 방식. 이중 시간축(그날 알던 버전).
- **E 가속** = 최신 분기 순이익 > 0 ∧ 전년 동기 순이익 > 0(기저효과·흑자전환 제외) ∧ YoY ≥ 25% ∧ 직전 분기 YoY 유한 ∧ **최신 YoY > 직전 분기 YoY** ∧ 최신 분기 매출 YoY ≥ 10% ∧ 최신 분기 `avail_date` 후 ≤ 140일.
- 순이익은 EPS 대용(주식수 변화 무시 — 기술).

### 7. 수급 (M5)
- **F_base** = Σ(외국인 + 기관 순매수 수량, i0+1 ~ d−1) / Σ(거래량, 같은 기간). 기반 기간 행이 80% 미만이면 모름.
- **수급 받침** = F_base > 0.

## 대조와 널

- **같은 메뉴 무작위 셋업 널(주 널, 300벌):** 같은 날 추세 ∧ RS ∧ breadth 통과 종목 중 **VCP 가 아닌** 종목을 V 팔의 날짜별 사건 수만큼 무작위로 뽑아,
  피벗 = 직전 k 일 최고 고가(k ~ U{10..40}), 손절 = 직전 j 일 최저 저가(j ~ U{5..15}), 같은 매수정지·10% 거르기·청산. (E·수급 조건이 있는 팔은 널 표본도 같은 조건 통과 종목에서.)
  "VCP 라서 낫다" 를 "추세 종목의 아무 돌파 매수정지" 와 분리한다.
- **모멘텀 정합 대조:** 같은 날 × 시장 × 12-1 모멘텀 10분위 × ADV 2분위(자기 제외, 5배, seed 0), 대조 종목은 d 일 시가 진입·같은 손절폭 %·같은 청산(돌파 실패 피벗 = 진입가).
  날짜군집 부트스트랩 2,000회. (리뷰 C1 의 단위 문제: 대조는 진입가 기준 돌파 실패라 이틀 보유가 많다 — 결과에 대조 보유일을 함께 적는다.)
- **팩터 회귀:** 10 슬롯 포트폴리오(슬롯당 자산 10%, 진입 순서 = 그날 사건을 ADV 큰 순, 놀고 있는 현금 0% 수익) 일 초과수익 ~ 시총가중 KOSPI 초과 + KOSDAQ + UMD + SMB_ADV + LOWVOL,
  Newey-West 5, 리뷰어 `factors.pkl`(GA2 리뷰) 그대로.

## 합격 바 (미리 — V1, V2 각각)

1. 표본: V1 n ≥ 80, V2 n ≥ 40. 미달이면 **VOID**(기술만).
2. 거래당 순수익(비용 **2배**, 주 = 보수 같은 날 가정) > 0, 그리고 **2017-09 ~ 2024-12 하위 구간**에서도 > 0 (V2 는 2025 제외 > 0).
3. 거래당 순수익이 같은 메뉴 무작위 셋업 널 **95 백분위 위**.
4. 모멘텀 정합 alpha 날짜군집 95% CI 하단 > 0.
5. **사용자 가설 바:** 손절 비율(stop + 진입일 손절) < 50% ∧ 실현 손익비(평균 이익/|평균 손실|) ≥ 2.
6. 10 슬롯 포트폴리오 팩터 alpha HAC t > 2.

- **V1 이 1~6 모두 통과:** VCP + 실적 가속 매수정지를 위성 P1 진입의 대체 후보로 **전진 페이퍼 사전등록**(실자금 아님).
- **V2 만 통과(V1 실패):** "수급이 받칠 때만" — 2.6년 표본이므로 전진 페이퍼로만 확인.
- **둘 다 실패:** "수렴 피벗 매수정지 + 실적 가속 + 수급도 지수 + 팩터를 이기지 못한다" — 사용자 가설의 **제대로 된** 기각. 어떤 바에서 막혔는지 그대로 적는다.
- 다중검정: 판정 팔 2개 — 바 4·6 을 Bonferroni(α 0.025, t > 2.24) 로 본 줄도 함께. 이 연구 계열의 누적 시행 수와 DSR 은 기술.

## 사전 예상

- 진입 확장률이 18% → 5% 안팎으로, 손절폭 중앙이 10% → 5~7% 로 줄어 **R 손익비는 오르고 거래당 순수익(%)은 비슷하거나 약간 오를 것**.

## 정정 — 설계 리뷰 반영 (2026-10-10, `REVIEW_VCP_RETEST.md` 1단계, 결과 보기 전)

리뷰어는 **건수만** 셌다(셋업·체결·E 통과 수 — 수익·청산은 계산하지 않음). 아래 정정은 전부 그 건수와 정의 문제에서 왔다.

- **C1 판정 팔 재지정(표본):** V0 체결 57~101건(9년), V1 4~10건, V2 0~3건 → V1·V2 바는 도달 불가. 가설을 둘로 나눈다.
  - **(H-a) 진입 역학 — 판정 팔 V0:** "수렴 피벗 매수정지 + 구조 손절이면 손익비가 좋고 손실이 작다". 표본 바 **n ≥ 50**, 하위 구간(2017-09 ~ 2024-12) n ≥ 30.
  - **(H-b) 실적·수급 층 — V1·V2·V3 은 기술만:** 통계 판정 불가를 미리 적는다. 확인은 전진 페이퍼로만. (V1 n ≥ 40 이면 바 숫자를 기술로 적되 판정하지 않는다.)
  - 기반 길이 상한 13주 → **15 ~ 250 거래일**(원전의 3~65주 기반 중 데이터가 허락하는 만큼; 리뷰 MINOR — 긴 기반 누락). H0 창 = d−1 까지 260 거래일. 사건 시작 2017-09 는 그대로(가격 2016-09+ — 초기 사건은 창이 짧다, 기술).
- **C2 피벗:** 지그재그가 상승 구간(마지막 확정점이 저점)에서 끝나면 **피벗 = 마지막 확정 저점 이후 진행 중 최고 고가**, 마지막 수축 = 그 고점 이후 d−1 까지 최저 저가. 피벗 고점 뒤 3거래일 미만이면 셋업 없음.
  하강 구간(마지막 확정점이 고점)에서 끝나면 그 고점이 피벗. 수축은 이중으로 세지 않는다. 같은 값 동률은 늦은 봉, 한 봉 안 반전(고가 반전·저가 반전 동시)은 고점 먼저.
- **C3 진입일 손절 순서:** 주 가정 = **분봉 보정 기대값** — 분봉 구간(2025-08+)에서 유니버스 전체의 합성 매수정지 돌파(같은 근접 띠·손절 정의)로
  "시가 ≤ 피벗 ∧ 그날 저가 ≤ 손절가" 일 때 저가가 돌파 **뒤**에 온 비율 p 를 잰다. 모호한 거래의 순수익 = p × (손절) + (1−p) × (낙관 경로). 보수(p=1)·낙관(p=0)을 상·하한으로 함께 적고,
  판정이 두 경계에서 갈리면 기각이 아니라 **"가정 의존"** 으로 적는다.
- **C4 사용자 가설 바(바 5) 재정의:** 사유 무관 **손실 청산 비율**(순수익 < 0, 돌파 실패 포함) < 50% ∧ 실현 손익비 ≥ 2 ∧ **손실 크기**: 평균 손실 ≥ −1.0R(고정 분모 아닌 그 거래 d 기준) ∧ R 5 백분위 ≥ −1.3R ∧ 순수익 −12% 미만 손실 비율 ≤ 5%.
  승·본전(|순| < 0.5%)·패 3분류를 함께 적는다.
- **M1 널 맞추기:** 널 사건도 근접 띠·9.5% 거르기·2% 하한·3% 갭·상한가·정지 규칙을 똑같이; V 팔의 **월별 체결 수**만큼 체결된 널 사건을 뽑는다; 손절폭 d 3분위 층화 추출; 비교는 % 와 고정 분모 R(d = 0.07) 둘 다.

- **M2 실적:** 최신 분기 YoY 가 계산 불가면 앞 분기로 밀리지 않고 **모름**; 직전 분기 YoY 도 전년 동기 흑자일 때만 유효; Q4 단독 = 당해 사업보고서 연간 − 같은 해 Q1~Q3 (전년 동기 Q4 도 같은 방식);

## 정정 2 — 코드 리뷰 A·B 반영 (2026-10-10, `REVIEW_VCP_RETEST.md` 2단계, 결과 보기 전)

리뷰어 A·B 는 건수만 셌다(수익·청산 미계산). 원칙: **아래 선택은 VCP 정의의 충실도와 건수로만 정했고, 성과 숫자는 아무도 보지 않았다.**

- **A-C1 봉 안 처리:** 한 봉이 반등(+θ)과 새 극값을 함께 만들면 **극값 먼저, 반전 확인은 다음 봉부터**(오름 구간 처리와 같은 가정). 정정 1 C2 의 "고점 먼저" 문구를 이것으로 바꾼다.
  방식별 V0 체결 상한(리뷰 A, 보유 거르기 전): 현 코드 43 · 고점 먼저 27 · 극값 먼저 54 — 정의상 일관성으로 고르고 건수는 기록으로만.
