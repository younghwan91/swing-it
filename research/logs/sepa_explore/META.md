# 메타 진화(GA 의 GA) — 설계 초안 (2026-10-10, GA2 결과 보기 전)

사용자 목표: "결과를 지속적으로 관측하고 GA 의 문제 또한 GA 방식으로 계속 변형해 나가 최종적으로 시장에 가장 맞는 방식을 찾아내 — 개인 트레이더에게 적합한 매매법."
GA2 는 **고정된 절차**(적합도 3종·폴드 6·유전자 19·청산 5·유니버스 1) 안에서 파라미터를 고른다. 메타 진화는 그 절차 자체를 개체로 본다.

## 1. 메타 개체 = 절차 한 벌

| 메타 유전자 | 선택지 |
|---|---|
| 적합도 | 처리량 / 거래당 / 1일당 / **처리량 − 무작위 설정 95 백분위(노이즈 보정)** / 처리량 ÷ MDD |
| 검증 구조 | 학습창 {2, 3, 4년} × 재최적화 주기 {연, 반기, 분기} × 임베딩 {0, 5, 20일} |
| 유전자 메뉴 | GA2 19 / 진입만 / 청산만 / + 적응 층(국면 게이트·노출 스케일러·척도 적응, `ADAPTIVE.md`) / + 수급 3 |
| 유니버스 | ADV ≥ 50억 / 50~200억 / ≥ 200억 / 코스닥만 / 코스피만 |
| 청산 가족 | 미너비니 원전 / 돌파 실패 포함 / 추적만 / 고정 보유 |
| 국면 신호 | 없음 / A 계량 / B 기사 기분 / C 푸리에 / A+B+C |
| 최적화기 | CMAwM+BIPOP / 단순 GA / 무작위 탐색(기준선) |
| 예산 | 1,600 / 3,200 / 6,400 평가 |

## 2. 메타 목적 (노이즈 보정, 개인 트레이더 제약 포함)

메타 점수 = 이어 붙인 OOS 포트폴리오 연환산 초과 − (같은 절차에 **셔플 피처**로 얻은 OOS 분포의 95 백분위)
 − λ·max(0, 회전율 − 3) − μ·max(0, −MDD − 0.25), 그리고 팩터 알파 t < 2 이면 0 으로 자른다.
용량 제약: 시가 체결 가정은 자산 1~3억에서 깨진다 → 슬롯 10 × 10% 고정, 유니버스 ADV 하한 50억 아래로는 안 내린다.

## 3. 탐색

- 메타 평가 1회 = GA2 한 벌(12코어 ≈ 35~60분) + 노이즈 5회(같은 절차) → 하루 10~15회. **메타 CMA-ES 는 사치** — 메타 선택지는 이산 수십 개라
  **베이지안(TPE) 또는 축별 하나씩 바꾸기 + 승자 보존**으로 간다. 세대 1 = GA2 기준선 ± 한 축 변경 8개.
- 각 메타 평가는 사전등록 형식(절차·합격 바 고정 → 실행 → 리뷰어 1명 전담)을 그대로 따른다. 메타 원장 `meta/TRIALS.jsonl`.
- 메타 수준 다중검정: 메타 평가 수 N_meta 로 최종 후보의 메타 점수를 깎는다(무작위 절차 변형 분포의 95 백분위를 널로).

## 4. 멈춤 규칙

- 3세대 연속 메타 점수 개선이 노이즈 분포 95 백분위 안이면 "이 데이터로는 더 못 찾는다" 로 적고, 남은 것은 전진 페이퍼에 맡긴다.
- 통과한 절차는 라이브 재최적화 작업(`sw-live refit` — 라이브 후보 JSON 생성)에 그대로 들어간다.

## 5. 순서
