# 제약 완화 — 하나씩 빼기 · 베이지안 최적화(TRAIN 전용) · 베이지안 축소 (설계 고정 — 결과 보기 전 — 2026-10-10)

사용자 지시(2026-10-10): "너무 꽉 쪼아서 그럴 수도 있어. 제약을 하나씩 빼 보거나 느슨하게 베이즈 해 봐."
수렴 시험 A 는 조건 9개 교집합이라 12건 → VOID 였다. 이 실험은 **어느 조건이 일하고 어느 조건이 표본만 깎는지**를 재고,
문턱을 TRAIN 에서만 찾아 표본 밖에서 확인한다. 탐색이므로 결과는 후보를 만들 뿐이고 확인은 OOS·중소형·전진 페이퍼다.

## 공통

- 유니버스: 위생 통과 ∧ ADV20 ≥ 5,000(50억, 라이브 유니버스). 결과는 **유동(≥ 200억)** 과 **중소형(50~200억)** 으로 나눠서도 적는다.
- 가격: `krx_session.patch_prices` 로 2026-09-14 이후 NXT 오염 보정(감사 C1).
- 청산: 미너비니 원전 프로토콜 고정(`minervini_exits` 기본값).
- 지표: 모멘텀 정합 alpha — 감사 M2 에 따라 층에 **5일 수익 3분위를 다시 넣는다**(날짜 × 시장 × 12-1 모멘텀 5분위 × ADV 2분위 × 5일 수익 3분위 —
  층이 얇아지면 모멘텀 10→5분위로 줄인 것을 적는다). 트레이드당 alpha 와 **보유 1일당 alpha**(감사 C2)를 함께. n, 손절 비율, 이익/손실, 기대값 R, 비용 1×·2×.
- TRAIN = 진입 < 2022-01-01, OOS = 2022-01-01 ~ 2026-04-01 사건. 수급 F 는 2024-02-19 부터만 있다 → BO 에 못 넣고 켬/끔으로 따로.

## 1. 하나씩 빼기 (leave-one-out)

기준 = CONVERGENCE A 의 전체 조건(F 제외판으로 전 구간, F 포함판으로 2024-02+). 조건 목록:
추세 템플릿 · RS ≥ 70 · 피벗 돌파 · 거래량 1.5× · breadth > 0.5 · PEAD ≥ 0.70 · rel ≤ 1.0 · 추격 금지 5% · (F).
칸 = 기준, 기준 − 각 조건(9칸, F 판 10칸). 각 칸 TRAIN·OOS·전체.

## 2. 베이지안 최적화 (TRAIN 전용)

- 탐색 공간: rs_min [40, 90], vol_mult [0.8, 2.0], pead_min [0.0, 0.9], rel_max [0.6, 3.0](3.0 ≈ 조건 없음), breadth_min [0.0, 0.6], pivot_window [20, 60](int).
  추세 템플릿·청산은 고정.
- 목적: `swing_it.validation.optimization.make_objective` — **TRAIN 트레이드 정합 초과의 부트스트랩 2.5% 하단**(원시 평균 금지), 거래수 하한 150.
  `mini_bo` 40회, seed 0(optuna 는 `uv run --with optuna` 로만, 의존성 추가 없음).
- 평가: TRAIN 최적 config 하나를 OOS(유동·중소형 각각)에 **한 번** 적용. 같은 OOS 에서 기준(사전등록 A − F)과 나란히.
- 과최적 측정: BO 가 평가한 40 config 의 TRAIN 순위 vs OOS 순위 스피어만, PBO(CSCV, 월별 정합 초과), 최적 config 의 DSR(N = 원장 누적 + 40).
- F 는 BO 최적 config ∧ F=1 을 2024-02-19+ 에 추가 1칸.

## 3. 베이지안 축소 (empirical Bayes)

하나씩 빼기의 조건별 효과(칸 alpha − 기준 alpha, 날짜 군집 부트스트랩 표준오차)를 정규-정규 모형으로 0 쪽으로 축소한 사후 평균·90% 구간.
"그 조건이 alpha 를 올린다" 의 사후 확률 P(효과 > 0) 를 조건마다 적는다.

## 판단 규칙 (미리 적음 — 판정이 아니라 다음 사전등록 후보 선정)

- 조건 중 축소 후 P(효과 > 0) < 0.5 인 것은 "표본만 깎는 조건" 으로 다음 후보에서 뺀다.
- BO 최적 config 가 OOS 유동 **그리고** OOS 중소형 둘 다에서 모멘텀 alpha 점추정 > 0 이고 TRAIN→OOS 순위 상관 > 0 이면,
  그 config(± F)를 다음 사전등록 + 전진 페이퍼 후보로 올린다. 아니면 "느슨하게 해도 엣지가 나타나지 않음" 으로 적는다.

## 감사 반영 (2026-10-10, 실행 전 — `AUDIT.md` X1·relax 절)

- **"OOS" 는 표본 밖이 아니다.** 유동주 2022~26 은 이 계열의 모든 시험에서 봤고, 중소형도 수렴 시험 B·D 에서 봤다. 이 실험의 OOS 는
  **"BO 목적함수가 보지 않은 구간"** 일 뿐이며, 진짜 표본 밖은 전진 페이퍼뿐이다. 결과 문서에 그렇게 적는다.
- purge 없음(2021 말 진입이 2022 수익을 TRAIN 에 실어 나른다) → 러너는 TRAIN 트레이드를 **청산 < 2022-01-01** 로도 자른다(GA2 와 같은 규칙).
- 다중검정: 이 연구 계열의 계획 평가 수는 약 145,000(GA 9,000 · CMA-ES 49,350 · 워크포워드 86,400). 원장 N(수백) 기준 DSR 은 탐색을 크게 과소평가한다 —
  BO 40 의 DSR 은 "원장 N" 과 "계획 평가 수" 두 가지로 적는다.
