## 1. 판단 규칙의 거짓 양성률

규칙(`ga2_run.py` `dec`, 처리량 · 시드 중앙값 config · 연 폴드 · H5): (1) 6 폴드 중 ≥ 4 OOS 조각 연환산 > 0, (2) 이어 붙인 OOS 연환산 초과의 3개월 블록 부트스트랩 2.5% 하단 > 0,
(3) WFE = ΣOOS/ΣIS > 0.3 (IS 합 ≤ 0 → NaN → 불통과), (4) PBO(폴드×시드 최적, 전 구간 월별, Sharpe) < 0.5.

### 1.1 해석적 분해 — (2) 가 전부다

- (2) 는 "이어 붙인 연환산 ≳ 1.96 × SE". 무작위 config 의 (연환산 − 하단) 중앙값 = 0.10(짧은 청산) ~ 0.23(120일 무익절)/년 → (2) ≡ **이어 붙인 연환산 > +10 ~ +23%/년**(청산에 따라).
- (3) 은 ΣOOS > 0.3·ΣIS. 선택 뒤 IS 는 노이즈 바닥이 +17%/년(리뷰어 A, 피처 섞음·GA1 공간·1,600 평가), 실제 피처에선 내 800 평가 CMA-ES 최적이 IS +18 ~ +28%/년(`pbo_fold.csv` `is_ann_best`) → (3) ≡ 이어 붙인 OOS > +5 ~ +8%/년. **(2) 가 참이면 (3) 은 IS < ~40%/년 인 한 자동으로 참.** IS 가 그보다 크면 (3) 이 추가로 거르지만 그것은 "더 심한 과적합" 만 거른다.
- (1) 은 무작위 config 의 45% 가 통과(아래) — 2020·2021·2023·2025 조각이 양수일 확률이 각각 0.80·0.61·0.63·0.74 라 ≥ 4/6 은 싸다. (1)∧(2) 통과율 = (2) 통과율(0.102 vs 0.105).
- (4) 는 설계 정의대로면 모든 폴드 최적이 같은 기울기(긴 보유·같은 국면 노출)를 공유할수록 **낮아진다**(IS 최고가 OOS 반쪽에서도 잘 됨 — 기울기의 지속성) → 가족 기울기 귀무에서 오히려 잘 통과. 순수 노이즈에선 ≈ 0.5 → 50% 통과.
- 따라서 결합 거짓 양성률 ≈ P(2) × P(4 | 2). 노이즈 귀무: ≈ 0.02 × 0.5 ≈ **1~2%**. 가족 기울기 귀무: ≈ P(2) ≈ **10~27%**(§1.2), (4) 가 거의 안 거른다.

## 2. 다중 검정 — 유효 시행 수와 정직한 DSR

- 이번 실행 평가 수(로그: 예산 3,200 · 시드 5): 연 폴드 6×3×5 + 분기 25×5 + 라이브 5 = 220 런 × 3,200 = **704,000** + 수급 1,350 + 민감도 ~1,000 + 노이즈 30×6×5×3,200 = 2,880,000. "고유 config" N 은 수십만.
- **유효 차원(`sim_pbo_fold.py`, `pbo_fold.csv`):** 폴드별 CMA-ES(2 시드 × 400 평가, 처리량 적합도, test_lo 시가평가 절단)가 평가한 고유 config 766~800 개의 학습창 월별 초과 행렬 → 상관 고유값 참여비 N_eff = **1.86 / 2.86 / 2.66 / 2.45 / 2.22 / 2.17**(Nyholt M_eff 356~520 — 알려진 과대), 근사 중복(|ρ| > 0.95) 1~4%. config 는 서로 다르지만 수익 경로는 2~3 차원이다: 사용률(보유·느슨함)과 국면 노출(breadth) 축 위에서의 선택이다.
- **DSR 두 층:**
  (a) **학습 적합도의 선택 편향**(config 수준) — 워크포워드가 흡수한다. 따로 보고할 것은 DSR 이 아니라 러너가 이미 하는 **노이즈 바닥 대비 IS 백분위**(피처 섞음 CMA-ES 의 IS 분포). 이것이 유효 N 을 묻지 않고 E[max] 를 경험적으로 주는 유일하게 정직한 방법이다.
  (b) **이어 붙인 OOS 의 설계 수준 다중성** — 워크포워드가 흡수 못 한다. 보고 가능한 이어 붙인 시계열 = 적합도 3 × (중앙값 + 시드 5) × 띠 3 × 주기 2 ≈ **108**, 앞선 검증 구조 6개(AUDIT §5). 월 T = 75, sr_std = 1/√74 = 0.116 일 때 Bailey–LdP SR₀(월) → 연환산: N = 10 → **0.63**, N = 108 → **1.03**, N = 10⁵(원시) → 1.76. 즉 이어 붙인 OOS 는 연 Sharpe ≈ 0.6~1.0 을 넘어야 "변형 중 고르기" 로 설명되지 않는다.
- 러너의 `dsr[kind]["prob"]` 는 N = 원장 전체(수십만) → 항상 ≈ 0 → 정보 없음. `_alt`(이산 칸 + 런 수 ≈ 220+) 쪽이 (b) 에 가깝다. **권고:** N = 108(보고 변형 수)과 N = 10(검증 구조 수) 두 값으로 적고, 원시 N 은 각주로.
- "고유 config 수" 를 N 으로 쓰는 것은 두 방향으로 틀린다: 시행 간 상관(PR ≈ 2~3)을 무시해 E[max] 를 과대, 동시에 그 config 들이 *OOS* 를 고르는 데 쓰이지 않았으므로 OOS 에 거는 것 자체가 범주 오류.

- 수치로: 19 유전자 중 5개(청산)의 **메뉴**, 1개(rs_min)의 **범위**, 그리고 **가족**(추세 템플릿 + 돌파 + 정합 대조 정의)이 전 구간 의존. 남는 표본 밖 요소는 "그 메뉴·범위 안에서 어느 값인가" 뿐이다. §1.2 가 보여주듯 메뉴 안 무작위 값으로도 10~27% 가 통과한다 — **표본 밖이 보호하는 부분(값)이 아니라 보호하지 않는 부분(가족·청산 메뉴·기간)이 통과를 만든다.**

- 결과 문서의 "의사-OOS" 문구(`render` 머리말)는 적절하다. 다만 "워크포워드는 문턱 선택의 과적합만 막는다" 뒤에 "문턱 선택 없이도 가족은 10~27% 로 (2) 를 통과한다" 를 붙여야 읽는 사람이 끌리지 않는다.

## 4. WFE 정의 점검

`wfe()` = Σ폴드 OOS 연환산 / Σ폴드 IS 연환산(점추정, 시드 **중앙값** config 의 학습창 포트폴리오), IS 합 ≤ 0 → NaN → 불통과. 폴드 1 의 빈 달 희석은 `d_first` 로 고쳤다(K2-m1 해소).

- IS ≈ 0 근처 폭발은 NaN 규칙으로 막았지만 **단조성이 깨진다:** IS 합이 +1% 면 OOS +0.5% 로 통과, IS 합 +40% 면 OOS +12% 가 있어야 한다. 과적합이 덜한(IS 가 낮은) 절차가 유리하다는 점에선 방향이 맞지만, IS 는 선택 뒤 값이라 노이즈 바닥(+17%/년 · 폴드 6개 합 ≈ +100%)이 분모에 깔려 있다. 그 바닥 위에서 WFE 0.3 ≡ 이어 붙인 OOS ≈ +5%/년 — (2) 보다 느슨해 **중복**.
- 분모가 중앙값 config 의 IS 라는 점: 중앙값 config 는 어느 시드도 최적화하지 않은 config 라 IS 가 시드 최적보다 체계적으로 낮다(평평한 지형에선 많이). 분모가 낮아 WFE 가 **부풀려진다**. 반대로 중앙값 IS ≤ 0 이면 절차가 좋아도 NaN.
- Σ 비율은 IS 가 큰 폴드(2020~21 학습창)가 지배한다.
- **권고:** (3) 을 폐지하거나 "WFE > 노이즈 WFE 분포의 95% 분위" 로 바꾼다(러너는 이미 노이즈 백분위를 낸다 — 문턱 0.3 대신 그 백분위를 규칙으로). 분모는 시드 최적 IS 의 평균(선택 뒤 값임을 명시)으로, 분자는 중앙값 config 의 OOS 로 — "선택된 것의 IS 대비 절차 산출물의 OOS".

## 5. 블록 부트스트랩 점검 (코드 `_block_boot_py` · `port_point`)

- **코드 확인:** 월합(일별 포트폴리오 초과 → `monthly` = 월 bincount) 위 **이동 블록 3개월, 비원형**, 블록 수 ⌈M/3⌉, 시작점 균등 [0, M−3], 마지막 블록은 M 에서 자름, 통계 = 평균 × 12, CI = 백분위(보정 없음). 2,000회(보고) / 500회(적합도). 이어 붙인 OOS 는 `end = tests[-1].end` = 2026-04-02 절단이라 청산 꼬리 희석(K2-M2)은 없다 — M ≈ 75 개월. **CI 는 일별 포트폴리오 초과의 월합에 걸린다 — 맞다.**
- **블록 길이 vs 보유:** 월별 초과의 ACF(무작위 config 중앙, lag 1~6): 원전 −0.03 · **−0.18** · +0.07 · +0.08 · −0.11 · −0.09; 120일 무익절 −0.03 · −0.18 · +0.05 · +0.10 · −0.12 · −0.06; 20일 2R −0.07 · −0.11 · +0.08 · +0.04 · −0.10 · −0.01. 노이즈 시계열도 −0.05 · −0.08 · +0.03. **양의 자기상관이 없다**(lag 2 가 음 — 좋은 달 뒤 청산·현금화). 보유 120일이어도 월합의 의존은 3개월 블록이 충분히 덮는다. 겹치는 포지션은 같은 달 안에서 상쇄된다.
- **피복(시뮬):** 각 시계열을 평균 제거 후 12개월 원형 블록으로 재표본해 만든 영평균 가짜 시계열 4,000개 × 청산 6종에 같은 CI → P(하단 > 0) = 1.85% / 2.20% / 1.55% / 1.70% / **4.45%**(20일 무익절) / 1.60%; 노이즈 시계열 2.27%. 참고: iid 정규 75개월 3.45%, AR(1) ρ 0.2 → 5.0%, ρ 0.4 → 5.9%. → 실제 의존 구조에선 CI 가 약간 **보수적~명목**이다. 피복은 문제가 아니다.
- **남는 문제 두 가지:** (a) 국면 집중 — config 간 조각 연환산 표준편차 2020 0.22 · 2021 0.26 · **2022 0.075** · 2023 0.17 · 2024 0.17 · 2025~ 0.19: 상승 국면 두 묶음이 평균과 분산을 정한다. 75개월이지만 독립 국면은 3~4개(2020~21 · 2022 · 2023~24 · 2025~26)다. 3개월 블록은 국면 안 의존은 덮지만 "국면 2개의 운" 은 덮지 못한다. (b) `port_point` 의 CI 는 `seed=0` 고정 — 적합도(`N_BOOT_FIT=500`, seed 0)와 **같은 난수열**이라 D-M7(최적화기가 특정 리샘플에 맞춤)이 보고 CI 에도 전해진다. 보고용 CI 는 다른 seed 로(한 줄 수정).
- **권고:** CI 옆에 "조각별 연환산(6개) 과 2022~24 조각" 을 판정 보조가 아니라 **(1′) 2022~24 조각 > 0** 으로 규칙화할 것(무작위 config 통과율 43% — 약하지만 (2) 와 결합하면 10.5% → 9.4%; 가족 기울기 귀무에서 (2′) 만큼 세지는 않다).

하는 일: `runs.csv` 의 `wf/<fold>/<kind>/<seed>` 최적 유전자 → `g2_median` 으로 폴드별 중앙값(러너 `proc_stats` 와 같은 절차) → `ga2_run.stitched` 로 이어 붙인 OOS 일별 **초과**(판정 시계열) + 시드별 3~5개, 그리고 열린 포지션에서 **원시**(대조·비용 없음, 청산일에 시가평가 수익으로 정합) 일별 시계열을 만들고(`stitched_series_<kind>.pkl` 저장), 각각을 회귀한다.

**판정에 쓰는 법:** (2) 옆에 초과 시계열의 **α HAC t** 를 적고, t < 2 이면 "CI 하단 > 0 은 가족/국면 프리미엄" 으로 읽는다(§1.3 의 (2″)). 리뷰어 A 의 사전 점검(느슨 config: 정합 초과 +10.9% → 절편 +8.1%, t 1.27)이 기준선이다.

- **B-M1. PBO (4) 정의가 가족 기울기 귀무에서 *통과 쪽* 으로 기운다**(폴드 최적이 공유하는 기울기의 지속성을 잰다). 바른 폴드 내 CSCV 추정 중앙 0.51, 상위 50% 0.77, IS↔OOS 상관 6/6 음(§6). (4) 를 폴드 내 CSCV 로 바꾸거나 판정에서 뺀다.
- **B-M2. DSR N.** 평가 config 의 수익은 유효 차원 2~3(§2) → "고유 config 수" 는 E[max] 와 무관. OOS 에 거는 N 은 보고 변형 수(≈ 108)·검증 구조 수(≈ 10) → 연 Sharpe 문턱 0.6~1.0. 현재 `dsr[...]["prob"]`(N 수십만) 은 항상 ≈ 0 이라 정보가 없다.
- **B-M3. 의사-OOS 의 보호 범위.** 청산 메뉴·rs_min 범위(상자 끝을 본 뒤 확장)·가족·대조 정의가 전 구간 의존(§3). 무작위 값으로도 통과율 10~27% 이므로 표본 밖이 지키는 부분(값)은 통과를 만드는 부분이 아니다. 결과 문서에 §3 표를 싣고 분기 변형은 판정에 쓰지 않음을 첫 줄에.
- **B-M4. WFE (3) 은 (2) 와 중복이고 비단조**(§4): 노이즈 바닥 IS 위에서 0.3 ≡ OOS +5~8%/년; 분모가 최적화되지 않은 중앙값 config 의 IS 라 부풀려지거나 NaN. 노이즈 95% 분위 규칙으로 대체.
- **B-M5. 국면 2묶음.** 조각 양수 확률 2020 0.80 · 2025~ 0.74 · 2022 0.07; (1) 은 무작위 config 45% 통과. 독립 국면 3~4개. (1′) 2022~24 조각 > 0 을 규칙에 추가(약하지만 비용 없음).
