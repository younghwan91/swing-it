# KOSPI200 야간선물 — 자료 조사·수집기·피쳐 설계 (구현 전, 2026-10-11)

사용자 요청: "사이드로 야간선물도 준비해 그게 좋은 정보를 준다고 들었다". 이 문서는 **조사와 설계만** 담는다.
키움·증권사 API 호출, 로그인, 회원가입, DB 쓰기는 하지 않았다. 결과(성적)는 보지 않았다.

## 0. 결론 먼저

- **무료로 확실히 구할 수 있는 이력은 KRX 자체 야간시장(2025-06-09~)뿐이다.** 약 16개월, 330 거래일 남짓이다. 이 구간은
  **전부 봉인 구간(2024-01+) 안에 있다.** 설계 선택 구간(2020–2023)에는 야간선물 가격이 우리 손에 없다.
- 2017–2025-06 야간 이력은 CME(2020-04까지) → Eurex 미니(공백기) → Eurex 정규(2021-03~) 로 시장이 세 번 바뀐다.
  KRX 정보데이터시스템에 이 연계시장 이력이 남아 있는지는 **확인하지 못했다.** 로그인이 필요해서다(2026-08부터 MDCSTAT 계열에
  회원 로그인 필요, `~/git/krx-fundamentals-client/docs/krx-blocked.md`). 없으면 유료(Eurex DataShop, CME DataMine, PortaraCQG)뿐이다.
- 기존 코드에 선물 수집기는 없다. DB `kr_quant` 에도 선물 테이블이 없다(28개 테이블 확인). `sector_index` 는 001·101(KOSPI·KOSDAQ)만
  있고 2024-01-26부터다. 키움 REST(우리 `kiwoom-client`)는 국내주식 전용이라 선물 시세를 주지 않는다.
- **승인이 필요한 첫 단계:** 사용자가 본인 계정으로 KRX 정보데이터시스템에 로그인해 파생상품 시세 화면의 시장구분에
  `야간`(그리고 있다면 `유렉스 연계`·`CME 연계`)이 있는지, 몇 년부터 조회되는지 확인한다(§2.1). 그 결과로 경로 A/B 를 고른다.
- 문헌상 야간선물 정보는 **다음날 시가에 거의 다 반영된다**(Lee 2015). 우리 진입은 장전 동시호가 지정가(preopen 08:35)라 갭 자체는
  이미 값에 들어 있다. 기대할 것은 "시가 이후 일중·며칠 보유에 남는 정보"와 "미국 선물 대용이 놓치는 한국 고유 충격"이다. 크지 않을 수 있다.

KRX 자체 야간시장 규칙(KRX 글로벌 페이지 기준):
- **거래일 귀속:** T 18:00 ~ T+1 06:00 세션은 **T+1 거래일**로 본다. 청산도 T+1 정규장 체결과 합산한다.
- 월~금 개장. 시작일(T)이 정규장 휴장일이면 그날 야간은 열리지 않는다. 내일이 휴장이어도 오늘 정규장이 열리면 야간은 연다.
  장기 연휴 직전에는 야간을 쉰다(예: 2025-10-02, 2026-09-23 추석 직전).
- 만기일: 최종거래일이 지난 종목은 정규장까지만 거래하고, 그날 야간부터 다음 월물이 거래된다(근월물이 바뀐다).
- Eurex 연계 시절: 데일리 퓨처스는 다음 KRX 개장 전에 KRX 동일 종목 포지션으로 넘어갔다. **Eurex 의 "일일정산가격"은 KRX 정규장 정산가와
  같다** — 야간 가격이 아니다. 야간 종가는 Eurex 세션의 마지막 체결가로 따로 받아야 한다.

### 2.1 첫 단계(사용자 승인 필요)

사용자가 본인 KRX 계정으로 data.krx.co.kr 에 로그인해 다음만 확인한다(우리는 로그인하지 않는다):
1. 파생상품 › (전종목 시세 / 개별종목 시세 추이)에서 상품 `코스피200 선물`, 시장구분 선택지에 `야간`·`유렉스 연계`·`CME 연계`가 있는가.
2. `야간` 일별 추이가 2025-06-09 이전으로 조회되는가(조회되면 Eurex/CME 연계분이 KRX 에 남아 있는 것).
3. 컬럼: 시가·고가·저가·종가·거래량·미결제약정·**정규/야간 구분** 여부. CSV 다운로드 버튼이 있는가.
4. 결과에 따라: (A) 2017~ 있으면 수동 CSV export 1회 → 파일로 넘겨받음. (B) 2025-06~ 만 있으면 그 구간만 받고, 설계 구간은 §5 대용 + 유료 구매 여부를 사용자가 결정.

대안 첫 단계: KRX Open API 키 신청(무료, 사용자 명의) 후 2025-06-10 하루치를 받아 야간 분리 여부를 본다.

## 4. 피쳐 정의와 시각 정렬

표기: d = 주문일(KRX 정규장, 주문은 d 장전 동시호가~장중), p = d 직전 KRX 정규장 거래일. 모든 피쳐는 **d 07:30 KST 이전에 확정**돼야 한다
(라이브 `signal` 07:35, `preopen` 08:35).

### 4.1 저장 단위(원자료)

`kospi200_night.csv`(먼저 파일, DB 테이블은 승인 후) 한 행 = 한 야간 세션:

| 컬럼 | 뜻 |
|---|---|
| `attr_date` | **우리가 다시 계산한** 귀속 KRX 거래일 = 세션 시작 이후 첫 KRX 정규장 거래일. 출처의 날짜 라벨을 믿지 않는다(CME trade date, Eurex 날짜, KRX T+1 귀속이 서로 다르다) |
| `session_start_kst`, `session_end_kst` | 실제 세션 시각(05:00/06:00, 서머타임 차이 포함) |
| `venue` | CME / EUREX_FMK2 / EUREX_FBK2 / KRX |
| `contract` | 기초 KRX 월물(예: 202612). 만기일 야간은 차월물 |
| `n_open, n_high, n_low, n_close, n_volume, n_oi` | 야간 세션 값. **n_close = 마지막 체결가/종가 단일가, 정산가 금지** |
| `base_close` | **같은 월물**의 직전 KRX 정규장 종가(15:45) |
| `avail_ts` | 값이 확정·입수 가능한 시각(= session_end + 공표 지연; KRX 지연시세 20분이면 06:20) |
| `fetched_at`, `source` | 수집 감사용 |

### 4.2 피쳐(주문일 d 에 붙는 값)

- **F1 `night_ret`** = ln(n_close / base_close), 같은 월물, `attr_date == d` 행. 같은 월물로 재야 롤오버·베이시스 잡음이 없다.
  만기일 다음날 d 는 차월물의 정규장 종가를 base 로 쓴다.
- **F2 `night_z`** = night_ret / σ(night_ret, 직전 60세션). 시장 교체(CME→Eurex→KRX)·변동성 국면 차이를 흡수한다. 문턱은 절대값이 아니라 분위수로(§6).
- **F3 `night_resid`** = night_ret − β·us_win_ret − γ·usdkrw_win_ret, β·γ 는 d 이전 120세션 롤링. 미국 선물로 설명 안 되는 한국 고유분.
- **F4 `night_range`** = (n_high − n_low)/base_close, **F5 `night_vol_rel`** = n_volume / 직전 20세션 평균(세션 유동성이 얇으면 F1 신뢰 낮음 표시용).
- **결측 규칙:** 세션 없음(연휴 직전·휴장일 시작)·`avail_ts` > d 07:30·거래량 0 → NaN. NaN 은 "정보 없음"으로 처리하고 백테스트·라이브가 같은 규칙을 쓴다.
- **다일 공백:** p 와 d 사이에 야간 세션이 여럿이면(휴장 사이에 연 세션) 마지막 세션의 n_close 대 p 의 base_close 로 잰다 — 한 세션 수익이 아니라 **p 종가 이후 누적**이어야 한다.
- **장 시작 후 전용(장전 피쳐 아님):** `gap_surprise` = ln(KOSPI200 d 시가 / p 종가) − night_ret. d 09:00 이후에만 알 수 있으므로 `open_check`(09:02) 이후 판단에만 쓴다. 신호·장전 주문에 넣으면 미래 누출.

### 4.3 시각 함정 목록

1. KRX 일별 파생 통계의 d 행은 (p 18:00 ~ d 06:00 야간) + (d 정규장) 합산일 수 있다 — NXT 일봉 오염과 같은 구조. d 행을 d 장전 피쳐로 쓰면 누출이다. 야간 분리 행만 쓴다.
2. Eurex 일일정산가 = KRX 정규장 정산가. 야간 피쳐로 쓰면 정보가 0 이거나 d 정규장 값이 섞인다.
3. 종료 시각 변화: CME·Eurex 05:00(유럽 서머타임에 따라 04:00 가능), KRX 06:00. 미국 정규장 마감은 서머타임 05:00 / 표준시 06:00 KST →
   **Eurex 시절 겨울에는 미국 마지막 1시간이 야간 종가에 없다.** venue 더미 또는 F2 로 흡수하고, 시대별 분해를 반드시 본다.
4. 월요일 d: 금요일 밤 세션(토 06:00 종료)이 귀속된다. 주말 뉴스는 없다(E-mini 는 월 07:00/08:00 KST 재개 — 라이브 스냅샷이면 더 최신).

## 5. 미국 선물 대용은 얼마나 대신하나

- 문헌: Lee(2012) — CME Globex KOSPI200 야간 수익은 KRX 선물의 **오버나이트(종가→시가)** 로 전이되고 일중으로는 전이되지 않는다. 정규장 참가자는
  미국 시장 변동성보다 Globex 가격을 더 유용한 정보로 쓴다. Lee(2015) — 야간 정보는 개별 종목 시가에 다 반영된다(시가 매수→종가 매도 전략은 이득 없음).
  Han·Hwang·Ryu(2015) — 2000–2009 의 S&P500 과잉반응(시가→종가 반전)은 2009 야간선물 도입 뒤 사라졌다. 야간 대 E-mini 상관 수치를 직접 잰 자료는 찾지 못했다.
- **현재 대용의 정렬 문제:** `us_overnight.csv` 의 E-mini 일봉 종가→종가 수익은 (p−1 미국 마감 ≈ p 05/06시) → (p 미국 마감 ≈ d 05/06시) 이다.
  앞 구간 p 07:00~15:30 은 이미 KRX p 정규장이 반영했다. 그래서 대용은 **겹친 창**을 잰다. 야간선물은 p 15:45 → d 06:00 으로 정확히 맞는다.
  E-mini 로 같은 창을 재려면 장중 시세가 필요하다(Yahoo 1h 는 최근 730일뿐 — 설계 구간 불가).
  또 `pattern_ga_view.py` 는 d 직전 미국 하루치만 쓴다 — 한국 연휴로 미국이 여러 날 열렸으면 누적해야 한다(작은 버그 후보, 이번엔 고치지 않음).
- **야간선물이 더 주는 것(예상):** 한국 고유 충격(2024-12-03 22:27 비상계엄 선포 — 미국 선물은 거의 안 움직였고 KOSPI200 야간은 급락),
  장 마감 후 15:30~18:00 공시·실적(삼성전자·SK하이닉스), 원달러 야간, 18:00~22:30 아시아·유럽 시간 정보, 반도체 비중(삼성·하이닉스) — SOX 가 일부 대신한다.
- **잴 것(시장 수준, 전략 성적 아님):** 2025-06-09~ 에서 night_ret ~ es/nq/sox 같은 창(가능하면 1h) + usdkrw 회귀의 R²·잔차 σ, 잔차의 꼬리 사건 목록.
  사전 예상(측정 전, 근거는 약함): R² 0.5~0.7, 잔차는 소수 사건에 몰린다. 이 측정은 봉인 구간의 **시장 자료**를 본다 — 전략 성적은 보지 않으므로
  봉인을 깨지 않는다고 보지만, 리뷰어 판단을 받는다.

## 6. 정직한 평가 계획(패턴 GA 틀)

전제: 설계 선택 2020–2023, 2024-01+ 봉인. 고정은 절차·합격 바만, 파라미터는 롤링(사용자 원칙). 널은 같은 메뉴 무작위 설정.

1. **자료 판정(결과 전):** §2.1 결과로 경로 결정.
   - 경로 A(2017~ 야간 이력 확보): 설계 구간에서 직접 쓴다.
   - 경로 B(2025-06~ 만): 설계 구간은 **정렬을 고친 미국 대용**(누적, 가능한 한 같은 창)으로 F2·F3 분위수 규칙을 만든다. 야간선물은 봉인 해제 시점에 같은 규칙으로 대입만 한다(조정 없음).
2. **사전 등록 기술 분해(판정 아님):** 기존 GA 원장(G4 등)의 설계 구간 체결을 d 의 F2(또는 대용) 하위 10%/중간/상위 10% 로 나눠 승률·거래당 순·d 시가→종가·보유 수익을 본다.
   결과 보기 전에 가설(예: 하위 10% 날 진입은 거래당 순이 낮다)과 문턱(롤링 분위수)을 문서에 고정한다. 시대별(CME/Eurex 미니/Eurex/KRX)·계절(서머타임) 분해 필수.
3. **다음 세대 유전자 `night_veto`:** 메뉴 {off, q5, q10, q20}(롤링 250세션 분위수, F2 또는 F3 중 하나는 사전 고정). 진입만 막고 청산은 막지 않는다.
   **널:** 같은 메뉴를 무작위로 뽑고, 같은 비율의 **무작위 날짜**를 막는 널을 함께 돌린다 — 막는 날 수가 줄어든 것만으로 좋아지는 효과(거래 수·노출 감소)를 걸러낸다.
   바: 기존 바 전부 + 무작위 날짜 차단 널 95 백분위 초과, 팩터 알파 t > 2.
4. **봉인 해제 1회:** 2024-01+ 에서 고정된 규칙 그대로. 2024-01~2025-06 은 Eurex 시대라 경로 B 면 대용, 2025-06~ 은 실제 야간 — 두 구간을 따로 보고한다.
5. 리뷰 에이전트(전문 퀀트 관점)가 2·3·4 각각을 비판한 뒤에 결론을 보고한다.

## 7. 수집기 설계

- **백필(1회):** §2.1 결과 CSV → `research/experiments/night_futures_ingest.py`(가칭)가 `attr_date` 재계산·월물 매칭·base_close 결합·검증 후
  `research/logs/sepa_explore/regime/kospi200_night.csv` 로 떨군다. 검증 바: 행마다 n_low ≤ n_open,n_close ≤ n_high, |night_ret| < 15%,
  2025-06-09~ 세션 수 = 기대 세션 수(연휴 직전 휴장 제외), 같은 날 KOSPI200 시가 갭과의 상관 > 0.8(아니면 정렬 오류로 간주하고 멈춘다).
- **라이브(일 1회):** quant-airflow DAG `daily_night_futures`(가칭), **월~토 06:20 KST**(토요일 = 금요일 밤 세션). 키움을 쓰지 않으므로 키움 충돌 창(06:30–07:30 등)과
  무관하지만, 06:30 전에 끝내도록 타임아웃 8분. 출처 우선순위: KRX(승인된 경로) → KIS Open API(사용자 계좌·키가 생기면) → 없음.
  07:20 까지 값이 없으면 NaN + 경보(`collectors/alert.py`). 0행을 초록불로 넘기지 않는다(krx_shares 의 'LOGOUT' 교훈).
- **DB:** 초기엔 파일. 라이브 연결 단계에서 `deriv_night_bars`(위 컬럼 그대로) 테이블 생성 — DB 쓰기 권한이 필요하므로 사용자 승인 사항.
- **swing-it 연결:** `swing_it.features` 에 `night_features(d)` 하나, 백테스트·라이브 같은 함수. `avail_ts ≤ d 07:30` 가드는 함수 안에 둔다.

## 8. 위험

- **자료:** 설계 구간 이력이 없을 수 있다(가장 큰 위험). 시장 세 번 교체·유동성 차이(CME 얇음, 2020 공백기 미니만). 유료 구매 시 약관상 재배포 금지.
- **약관:** KRX 자료는 개인 이용 범위, 로그인 세션 자동 수집은 회색지대 — 수동 export 또는 Open API 가 깨끗하다. 포털 스크래핑 쓰지 않는다.
- **누출:** T+1 귀속 일별 행, Eurex 정산가, 출처 날짜 라벨, 다일 공백, 시가 갭 피쳐를 장전에 쓰는 실수 — §4.3·§4.2 규칙으로 막는다.
- **효과 크기:** 정보가 시가에 이미 반영된다(문헌). 우리 진입은 시가 단일가라 이득이 작거나 없을 수 있다. veto 는 거래 수를 줄여 분산만 키울 수 있다 — 무작위 날짜 널로 확인.
- **다중검정:** F1~F5·문턱 메뉴를 늘리면 통과가 쉬워진다 — 사전에 하나(F2 또는 F3)만 고정해 판정에 쓰고 나머지는 기술 분해로만.
- **운영:** 장기 연휴 직전 야간 휴장, 만기일 월물 교체, 06:00 종가 공표 지연, 출처 장애.
