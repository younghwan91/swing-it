## 4. 시장 구분 (PIT 아님)

DB 에 상장시장 이력이 없다. `market_of_code` 는 현재(폐지는 폐지 시점) 시장이라, 이전상장(코스닥→유가증권) 종목은 이전
**전** 날짜도 KOSPI 로 분류된다. 영향 범위: 시장별 breadth 국면, 시장 정합 대조. **비용에는 영향 없음** — 아래 표처럼
거래세+농특세 합계가 모든 구간에서 두 시장이 같다.

## 5. 과거 MULTI_ALPHA 미너비니 슬리브의 "breadth > 0.5" 정의 (git 에서 복원)

출처: `git show 2966e1f:research/operator_flow/minervini/scanner_final.py`(2026-07-11, 최종판은 `4913afa^:research/signals/operator_flow/minervini/scanner_final.py`,
`4913afa` 에서 삭제). 슬리브 백테스트 루프 코드는 커밋된 적이 없다(README·HONEST_VERDICT 만 커밋) — 남은 정의는 이 스캐너뿐이고,
제거된 `minervini_scan` 테이블 스키마(`ea9a032^:src/kr_quant/storage.py`)의 주석도 `breadth REAL -- 유동주 close>MA50 비율` 로 같다.

즉 과거 정의 = **두 시장 통합** 모집단, ADV = **당일 제외** 직전 20일 평균 거래대금 ≥ 30억(3,000 백만원),
`close_t > MA50`(당일 포함, `nanmean` — 결측 허용), 비율 > 0.5. 모집단은 `daily_bars ⋈ supply_demand` 내부조인(당시 현재 상장 종목만).

설계서 §3 의 국면("그 종목 시장의 MA50 위 종목 비율 > 50%")은 이와 **다른 정의**다 — 시장별 분리, ADV 하한 없음.
병렬로 만든 `swing_it.features.minervini.market_breadth` 도 설계서 쪽(시장별, 패널 전 종목, MA 창이 꽉 찬 종목만)을 따른다.
과거 슬리브의 "레짐 필터가 하방 방어의 원천" 이라는 결과를 근거로 삼으려면 이 차이를 사전등록에 적어야 한다.

## 7. 상한가 시가

`is_limit_up_open(open, prev_close)` 기본 판정 = `open/prev_close ≥ 1.30 − 0.007`. 상한가는 1.3배를 호가로 내림한 값이라
최대 한 호가(1,000원 이상에서 전일종가의 ≤0.65%) 낮다 — 분할조정가(호가 격자가 깨짐)와 2023-01-25 이전 호가표에서도 잡힌다.
`exact=True` 는 `krx_quant_core.market.limits.limit_up_price` 와 같은 식의 벡터판(현행 호가표, 일치 테스트 있음)으로 비교한다.
±30% 제한폭은 2015-06-15 부터라 패널 전 구간에 해당한다. 참고: 피벗 돌파 종가 다음날 +29% 이상 시가는 이미 추격 금지(피벗×1.05)에
걸리므로 상한가 규칙이 따로 버리는 건은 드물 것이다(건수는 사건 표가 만들어진 뒤 센다).

```bash
export $(grep -v '^#' ~/git/quant-airflow/.env | xargs)
uv run --extra pg python - <<'EOF'
import os, pandas as pd
from swing_it.storage import connect, read_prices
from swing_it.features.korea import load_listing_meta, universe_mask, sector_leadership
con = connect(os.environ["KR_QUANT_DB"]); meta = load_listing_meta(con)
adj = read_prices(con, cols=("code", "date", "close", "trade_value"))
raw = read_prices(con, cols=("code", "date", "close"), table="daily_bars")
piv = lambda df, v: df.assign(date=pd.to_datetime(df["date"])).pivot(index="date", columns="code", values=v).sort_index().astype(float)
close, tv = piv(adj, "close"), piv(adj, "trade_value")
u = universe_mask(close, tv, meta, raw_close=piv(raw, "close").reindex_like(close))
k = sector_leadership(close, meta["sector"].reindex(close.columns), universe=u)
EOF
```
