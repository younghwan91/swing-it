## 읽을 거리 (기술)

- **국면 필터가 가장 세게 거른다.** `tt_rs_brk` → `S` 에서 절반(23,049 → 11,798)이 빠지고, 2024 는 breadth>0.5 인 날이
  KOSDAQ 5% · KOSPI 12% 뿐이라 `S_liq` 69건이다. 연도별 표본이 2020·2021·2025·2026 에 몰린다(`S_liq` 의 80%) —
  판정 때 레짐 분해(GUARDRAILS §1-12)가 이 쏠림을 그대로 드러내야 한다.
- **유동성이 두 번째로 거른다**(`S` 11,798 → `S_liq` 3,052, 26%). 여기에 실적 다리 E(YoY ≥ 25% ∧ 흑자 ∧ 공시 후 ≤ 90일)와
  보유 중 재진입 금지·추격/상한가 버림이 더 붙는다. 판정 config `S ∧ E` 의 트레이드 수는 **수백 건 규모로 예상**되므로
  사전등록에 최소 표본 기준을 적어 둘 것.
- 돌파 자체는 연 7~11천 건으로 고르게 있다 — 표본 쏠림은 추세·국면 쪽에서 온다.

## 데이터 주의

- **2026-09-14 이후 일봉 종가(NXT 오염 의심).** 2026-10-05 점검에서 `daily_bars.close` 가 이날부터 NXT 야간 마지막 체결가로
  들어온다는 결함이 보고됐다(quant-airflow, 미수정). 조정 테이블 종가가 [저가, 고가] 밖인 행은 0건(41,989행 중)이지만
  고·저가도 NXT 를 포함한다면 이 검사로는 못 잡는다. 판정 구간 상한(`event_hi`)을 2026-09-11 이전으로 두거나
  수정 여부를 먼저 확인할 것.
- 거래정지일은 거래량 0 · OHLC 이월(205,149행, 3.5%)이다. 피처는 이월 종가를 그대로 쓰고(그날 알 수 있는 값),
  시뮬레이터는 `volume=` 을 넘기면 정지일을 체결 불가로 처리한다 — **실데이터에선 반드시 넘긴다.**
- RS·breadth 모집단은 패널 전 종목(우선주·스팩 등 포함 가능)이다 — 설계 선택은 `minervini.py` 독스트링.

## 재현

```bash
export $(grep -v '^#' ~/git/quant-airflow/.env | xargs)
PYTHONPATH=. uv run --extra pg python -c "
import os; from swing_it.storage import connect
from swing_it.features.technical import average_trade_value
from research.signals.sepa import load_panels, skeleton_features, skeleton_coverage
p = load_panels(connect(os.environ['KR_QUANT_DB'])); f = skeleton_features(p)
counts, frac = skeleton_coverage(p, f)
proxy = (average_trade_value(p.trade_value, 20) >= 20000) & (p.close >= 1000)
counts['S_liq'] = skeleton_coverage(p, f, universe=proxy)[0]['S']
print(counts.to_string()); print((frac * 100).round(1).to_string())"
```
