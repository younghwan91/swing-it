## 4. judge 단절 위험 — 2026-03 경계

두 구간은 **모델·프롬프트·표본 설계가 모두 다르다**:

| | v2r3-haiku55 (2025-09~2026-02) | v2-haiku45 (2026-03~09) |
|---|---|---|
| 모델 | claude-haiku-5-5, 생각 끔 | claude-haiku-4-5, temperature 0 |
| 프롬프트 | 운영 v2 + r3 보충 | 운영 v2 |
| 쌍 설계 | top-300 STAGE1 쌍의 22% 층화 표본(월·업종·세션) | top-300 쌍 — 약 62일은 층화 ~30%, 63일은 거의 전량(98~99%) |
| 판정 커버리지(ADV 유니버스 cov_60 중앙값) | 0.18 | 0.51 |
| N 기사 / 판정 | 8.6% | 12.3% |
| pos / 판정 | 18.5% | 31.8% |
| 원장 전체 주변분포 (필터 전) | dir +1 19.5% · persistence multi/struct 23.5% · new 55.6% | dir +1 37.9% · multi/struct 57.8% · new 27.8% |

같은 쌍을 두 모델이 판정한 유일한 자료 = 2026-04 파일럿 496쌍(v2 프롬프트 그대로, Haiku 4.5 vs 5.5 — **모델 효과만**,
r3 효과는 별도): N 기사 Haiku 4.5 **60** vs Haiku 5.5 **33**, 둘 다 22 (Jaccard 0.31). pos 144 vs 105, 둘 다 88.
persistence 는 4.5 의 multi_quarter 210 중 143 을 5.5 가 one_off 로, freshness 는 4.5 의 repeat 211 중 70 을 5.5 가 new 로 본다.
즉 **같은 기사여도 judge 를 바꾸면 N 기사 수가 대략 절반~두 배로 움직이고, 겹치는 건 1/3 이다.**

단절의 크기: ADV 유니버스의 N1 비율이 2026-02 0.51 → 2026-05 0.74, 기사당 N 비율이 8.6% → 12.3%. 이 점프는
(1) 커버리지 3배(표본 22% → 거의 전량), (2) 모델 4.5 의 관대함(파일럿에서 N 1.8배), (3) r3 보충의 효과가 겹친 것이고
세 가지를 이 자료로 분리할 수 없다. **N 효과를 두 구간을 이어 붙여 추정하면 시기 효과(2026 후반 대형주 장세)와
judge 효과가 완전히 교락된다.** 구간 안에서만 비교하고, 구간을 judge 더미로 두는 것이 최소한이다.

추가 비대칭(정량 불가, 기록만): Haiku 5.5(2026-10 출시)가 **2025-09~2026-02 기사를 사후에** 판정했다 — 학습 자료가 그
기간 사건을 담았다면 "여러 분기 지속" 판정에 사후 지식이 섞일 수 있다(앞을 본 판정). Haiku 4.5 는 2026-03~09 기사보다
먼저 학습이 끝났다. 판정 시각(judged_at)은 전부 2026-09-15 이후라 실시간 가용 판정은 하나도 없다.

## 5. 통계 검정력 — 독립 ~60거래일 창

| | 신호일(거래일) | 60일 창이 judge 안에 꽉 찬 신호일 | 비고 |
|---|---|---|---|
| v2r3 | 119 (2025-09-01~2026-02-27) | 83 (2025-10-28~) | N=0 이 거의 전부 모름 |
| 공백 | 9 | 0 | |
| v2-haiku45 | 126 (2026-03-16~09-15) | 84 (2026-05-15~) | 최대 보유 60거래일이면 2026-07-09 이후 진입은 2026-10-08 현재 **우측 절단** — 끝까지 본 진입일 79 |

- 두 judge 합쳐 신호일 245 거래일 = **독립 60거래일 창 약 4개**(judge 당 2개), 창이 꽉 찬 날만 치면 167일 ≈ **2.8개**.
  보유가 최대 60거래일이라 진입 창과 보유 창이 겹친다 — 시장 국면 단위의 독립 표본은 **4개 이하**다.
- 게다가 그 4개가 2+2 로 judge 와 정확히 겹친다(§4) — judge 간 비교는 사실상 n=1 대 n=1.
- 결론: 설계서대로 **N 은 판정에 쓰지 않고 기술(記述)만** 한다. 단조성 표에 N 을 넣는다면 judge 별로 따로, known 행만,
  "independent windows ≈ 2 per judge" 를 함께 적는다. N 을 판정에 쓰려면 2023-03~2025-08 전량을 한 judge 로 판정해야
  하고(스윙 2호 2~6구간), 그건 돈이 드는 사용자 승인 사항이다.

## 6. 남은 주의

- 토스 createdAt 은 기사 정정 시 바뀔 수 있고 아카이브는 2026-09 백필 때 본 판이다 — 정정된 기사는 시각이 늦게(보수적) 잡히지만
  제목·요약도 정정본이다(판정 입력이 당시 독자가 본 것과 다를 수 있다).
- 대형주 일부(005930·000660·005380)는 피드가 토스 페이지 상한에 걸려 이른 구간 기사가 빠졌다(A6 문서) — 피드 0건이 "없음" 이
  아니라 "못 받음" 일 수 있다. `nofeed` 는 ADV 유니버스에서 1.7~3.7% 라 영향은 작다.
- v2r3 쌍은 장중 순회기 도달 재현(sweep)을 거쳤다 — 15:20 전에 순회기가 못 찾은 기사는 판정 안 됨(분모에만 있음).
- `MIN_COVERAGE = 0.5` 는 위 표만 보고 정했다(후반 ADV 유니버스 cov 중앙값 0.51). 0.2/0.5/0.9 에서 전 종목 known 비율은
  전반 ≈ 0.21/0.20/0.20, 후반 ≈ 0.38/0.34/0.32 — 임계값보다 커버리지 자체가 지배한다.
