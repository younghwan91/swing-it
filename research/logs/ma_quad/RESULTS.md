## 판정 (검증 반영 2026-11-14) — 관문 0 기각, 백테스트 없음, 이 정의 종결

**검증:** 하이쿠 스웜 12입자 96사건(원 DB, 사건 조건·5봉 뒤 라벨) 96/96 일치. quant-reviewer 재계산: 라벨 2,000건 불일치 0, 사전 후보 상태 500건 위반 0, 외삽 가중치 오차 ≤ 2e-7, 판정문 숫자 전부 일치, M=200 대 1000 |Δp| 중앙 0.005(Brier 부풀림 ≤ 0.0003, 차이 0.018 대비 무시). CRITICAL 없음.

**판정:** q=2(신호)는 칸 합격 0/20 — 보정 0/20, 기술 0/20, 연도 0/7(140 칸-해 BSS 최대 −0.208). 관문 0 불합격 → 사전등록대로 관문 1 백테스트를 하지 않는다. q=1(직선)도 관문 1 메뉴에 있었지만 관문 0 불합격으로 **백테스트가 전혀 없다**(PREREG). 이 정의(q차식 외삽 + 무조건 경험 오차 라이브러리)는 종결.

**결론의 범위 (정정 G-MQ-1, 리뷰 M2·M3):**
- 보인 것: "원 외삽 + 무조건 오차 라이브러리는 무작위 기준(q=0)보다 k봉 뒤 정배열을 못 맞힌다." 순위 매김(AUC)에서도 진다 — N20 k5 q0 0.930 · q1 0.871 · q2 0.881, N10 k10 0.863 · 0.804 · 0.691. 로지스틱 재보정 q2 도 원 q0 대비 BSS −0.24 ~ −0.54.
- 보이지 않은 것: "곡률 정보가 정확히 0". 사후 진단(같은 자료, 기술이지 판정 아님): 2017~19 적합 → 2020~23 적용 쌓기 모형(q0 + q2)의 OOS BSS(재보정 q0 대비) −0.004 ~ +0.003, 원 q0 대비 최대 +0.0045 — 등록 바 0.01 미만, 쓸 만한 증분 없음. 재보정·수축·쌓기 q2 는 다른 예측기라 2017~23 에서 다시 돌리면 낚시다 — 이 숫자를 그 문을 닫는 근거로 기록한다.
- q0 의 높은 보정·AUC(0.93~0.97)는 사용자 가설 절반("장기선은 이미 알려진 과거")이 맞다는 뜻이지만, 그것은 **추세 0 무작위보행 산수 = 널**이다. "확률이 좁게 나온다" = 사실(기술), "곡률이 크로스 전 자리를 보여 준다" = 기각.

**실패 원인 (정정 G-MQ-2, 리뷰 M1 — 앞선 설명 철회):** "한국 단기 반전 때문"이라는 설명(설계서 §5 사전 예상 문구, 세션 중 보고)은 **틀렸다**. 실현 k봉 수익(σ 단위)을 외삽 추세에 회귀한 기울기 β = −0.009 ~ +0.039(0 근처), 외삽 추세의 퍼짐은 순수 무작위보행 시뮬레이션과 거의 같다(q2 N20 k5 관측 3.16σ 대 무작위보행 3.55σ). q0·q2 를 함께 넣은 로지스틱의 logit p2 계수는 −0.027 ~ +0.126, 유의한 칸은 모두 양수. 즉 외삽은 반대로 가는 것이 아니라 **아무것도 더하지 않는다**(무작위보행 위의 잡음). q≥1 의 과신은 정보 없는 중심 이동에 무조건 오차를 더한 구조적 결과다. 정배열까지의 거리로 나눠도(사후 진단, 격차 < 0.5% 자리 BSS −0.33) 같다.

**정정 G-MQ-3 (MINOR):** "q=2 가 N≥20 에서 q=1 을 이긴다"는 과장 — 2v1 양수는 N20 k3·k5, N30 k3~k7, N40 전부이고, 이는 q1 이 긴 N 에서 더 과신한 데서 온 "덜 나쁨"이지 기술이 아니다. 사전 예상 "보정 통과 85%"는 빗나갔다(q2 보정 0/20) — 교훈: 경험 라이브러리는 무조건적으로만 보정되고 조건 건 상태에서 외삽기는 깨진다(설계서 §5 가 위험으로 적었다).
