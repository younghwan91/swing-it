# 이평선 2차식 외삽 정배열 예측 — 사전등록 (결과 보기 전 확정 — 2026-11-14)

**정본 사양:** `docs/superpowers/specs/2026-11-14-ma-quad-forecast-design.md`(이 커밋의 판). 결과를 본 뒤 그 문서와 이 문단은 고치지 않는다 —
고칠 일이 생기면 아래에 `정정 MQ-<n>` 문단을 덧붙이고, 결과를 이미 봤는지 공개한다.

- **상태:** 데이터·결과 미조회. 이 등록 시점까지 본 것은 `minute_bars` 피복 메타데이터(월별 종목 수, 리뷰어 조회)뿐이다.
- **가설 & 근거:** 최근 N일 로그 종가의 q차식(q=2 신호, q=1 직선) 외삽 + 자기 예측 오차 경험 라이브러리로 만든 이평선 경로가,
  같은 절차의 0차(무작위 기준)보다 k일 뒤 정배열(MA5>20>60>120)을 더 잘 예측한다. 이평선 장기선의 대부분이 이미 알려진 과거라 확률이 좁게 나오고,
  곡률이 크로스 전 자리를 미리 보여 준다는 것이 사용자 가설이다.
- **유니버스:** `korea.universe_mask` 위생 ∧ 20일 거래대금 ≥ 10억, 폐지 포함 `daily_bars_adj_v2`, 정규장 종가 정문(`session="regular"`, `unpatched="nan"`).
- **관문 0 (확률 보정, 매매 없음):** 2017-01-02 ~ 2023-12-31 사전 후보(유니버스 ∧ EPS↑ ∧ 정배열 아님 ∧ 0 < d ≤ 10%), q=2 의 N{10,15,20,30,40} × k{3,5,7,10} 20칸.
  칸 합격 = 보정(P ≥ 0.5 구간 n ≥ 300 마다 ≤ 5pp, ECE ≤ 2pp ∧ ≤ 기준율 20%) ∧ BSS(대 B0) ≥ 0.01 ∧ 월 군집 95% 하한 > 0 ∧ 연도 ≥ 5/7 양수.
  관문 합격 = ≥ 12/20 칸 ∧ 이웃으로 이어진 합격 덩어리 ≥ 8칸. 통과/기각만 정하고 관문 1 메뉴는 좁히지 않는다. 불합격 → 백테스트 없음, 다른 함수꼴로 다시 돌리지 않음.
- **관문 1 (백테스트, 관문 0 통과 시):** 설계서 §6 — t 종가 판정·t+1 시가 체결, 청산 ① 묶음 하단 종가 이탈(고정) ③ 예측 붕괴 즉시 ② 정배열 뒤 X-dead / X-mnv(시도 2건).
  워크포워드 폴드 2020~23(폴드 경계 끊기), 메뉴 q{1,2} × N × k × θ_in × θ_out × o_min (+ X-dead 쌍·θ_dead). 바 6개(널 ① 같은 메뉴 무작위 300 ∧ 널 ② 같은 후보 풀 무작위 솎기 300 의 95 백분위,
  R 평균 하한 > 0, 상위 5 제거 기대값 > 0, 팩터 알파 t > 2 OLS·NW, 노출 맞춘 시장·KOSPI, 폴드 ≥ 3/4). 비용 2배 판정. 체결 < 100 → VOID.
- **관문 2 (준독립 2009 ~ 2016-08, 1회):** 설계서 §7. **관문 3 (전진):** 별도 사전등록.
- **시도 수:** 관문 0 = 1(20칸은 고원 조건 — 선택 아님). 관문 1 = 2(X-dead·X-mnv). 원장 누적 N 으로 DSR 병기.
- **사전 예상:** 관문 0 보정 통과 85%, B0 대비 기술 통과 40%(관문 합격 ≈ 35%), B1 대비 기술 25%(보고). 관문 1 까지 통과 ≈ 10%.
- **사용자 결정(2026-11-14):** 청산 ③ = 예측 붕괴 즉시 청산(유예 없음), 첫 관문 = 확률 보정, 직선 대 2차식 = (나), 설계서 승인.
