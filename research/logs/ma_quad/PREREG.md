# 이평선 2차식 외삽 정배열 예측 — 사전등록 (결과 보기 전 확정 — 2026-11-14)

**정본 사양:** `docs/superpowers/specs/2026-11-14-ma-quad-forecast-design.md`(이 커밋의 판). 결과를 본 뒤 그 문서와 이 문단은 고치지 않는다 —
고칠 일이 생기면 아래에 `정정 MQ-<n>` 문단을 덧붙이고, 결과를 이미 봤는지 공개한다.

- **상태:** 데이터·결과 미조회. 이 등록 시점까지 본 것은 `minute_bars` 피복 메타데이터(월별 종목 수, 리뷰어 조회)뿐이다.
- **가설 & 근거:** 최근 N일 로그 종가의 q차식(q=2 신호, q=1 직선) 외삽 + 자기 예측 오차 경험 라이브러리로 만든 이평선 경로가,
  같은 절차의 0차(무작위 기준)보다 k일 뒤 정배열(MA5>20>60>120)을 더 잘 예측한다. 이평선 장기선의 대부분이 이미 알려진 과거라 확률이 좁게 나오고,
  곡률이 크로스 전 자리를 미리 보여 준다는 것이 사용자 가설이다.
- **유니버스:** `korea.universe_mask` 위생 ∧ 20일 거래대금 ≥ 10억, 폐지 포함 `daily_bars_adj_v2`, 정규장 종가 정문(`session="regular"`, `unpatched="nan"`).
- **관문 0 (확률 보정, 매매 없음):** 2017-01-02 ~ 2023-12-31 사전 후보(유니버스 ∧ EPS↑ ∧ 정배열 아님 ∧ 0 < d ≤ 10%), q=2 의 N{10,15,20,30,40} × k{3,5,7,10} 20칸.
  칸 합격 = 보정(P ≥ 0.5 구간 n ≥ 300 마다 ≤ 5pp, ECE ≤ 2pp ∧ ≤ 기준율 20%) ∧ BSS(대 B0) ≥ 0.01 ∧ 월 군집 95% 하한 > 0 ∧ 연도 ≥ 5/7 양수.
  관문 합격 = ≥ 12/20 칸 ∧ 이웃으로 이어진 합격 덩어리 ≥ 8칸. 통과/기각만 정하고 관문 1 메뉴는 좁히지 않는다. 불합격 → 백테스트 없음, 다른 함수꼴로 다시 돌리지 않음.
- **관문 1 (백테스트, 관문 0 통과 시):** 설계서 §6 — t 종가 판정·t+1 시가 체결, 청산 ① 묶음 하단 종가 이탈(고정) ③ 예측 붕괴 즉시 ② 정배열 뒤 X-dead / X-mnv(시도 2건).
  워크포워드 폴드 2020~23(폴드 경계 끊기), 메뉴 q{1,2} × N × k × θ_in × θ_out × o_min (+ X-dead 쌍·θ_dead). 바 6개(널 ① 같은 메뉴 무작위 300 ∧ 널 ② 같은 후보 풀 무작위 솎기 300 의 95 백분위,
  R 평균 하한 > 0, 상위 5 제거 기대값 > 0, 팩터 알파 t > 2 OLS·NW, 노출 맞춘 시장·KOSPI, 폴드 ≥ 3/4). 비용 2배 판정. 체결 < 100 → VOID.
- **관문 2 (준독립 2009 ~ 2016-08, 1회):** 설계서 §7. **관문 3 (전진):** 별도 사전등록.
- **시도 수:** 관문 0 = 1(20칸은 고원 조건 — 선택 아님). 관문 1 = 2(X-dead·X-mnv). 원장 누적 N 으로 DSR 병기.
- **사전 예상:** 관문 0 보정 통과 85%, B0 대비 기술 통과 40%(관문 합격 ≈ 35%), B1 대비 기술 25%(보고). 관문 1 까지 통과 ≈ 10%.
- **사용자 결정(2026-11-14):** 청산 ③ = 예측 붕괴 즉시 청산(유예 없음), 첫 관문 = 확률 보정, 직선 대 2차식 = (나), 설계서 승인.

## 정정 MQ-1 (결과 전, 2026-11-14 — 데이터·결과 미조회, 구현 과제 2/6 진행 중)
- **계기:** 사용자 "보통 미너비니가 50, 150, 200 안보나?" → "200은 꼭 있어야 할거 같긴한데 너가 알아서 가장 좋은것로 매칭해봐".
- **판단:** k ≤ 10 에서 MA200 은 97.5% 이상, MA150 96.7%, MA50 90% 가 이미 확정이라 50·150·200 순서는 예측 대상이 될 수 없다(외삽이 더할 정보 없음) — 상태 거름망으로만 쓴다(미너비니 원전도 추세 템플릿을 국면 판정으로 쓴다, MINERVINI_RULES.md:8).
- **바뀌는 것:**
  1. **필수 200일선 거름(항상 켬):** 종가 > MA200 ∧ MA200(t) > MA200(t − 20 거래일). 사전 후보 정의에 더한다 → 관문 0 판정 모집단·관문 1·2 후보 모두.
  2. **미너비니 추세 템플릿 전체(선택):** 종가 > MA150 ∧ MA150 > MA200 ∧ MA50 > MA150 ∧ 종가 > MA50 ∧ 종가 ≥ 52주(250일) 최저 × 1.30 ∧ 종가 ≥ 52주 최고 × 0.75 (RS ≥ 70 은 넣지 않는다 — 이 정의의 순위 기준이 아니다). 관문 0 = 보고 열(템플릿 충족 부분집합의 같은 표), 관문 1 = 메뉴 유전자 tmpl ∈ {끔, 켬}.
  3. **보고 열 추가:** 200일선 거름 없는 원래 사전 후보의 같은 표(비교용, 판정 무관).
- **그대로:** 예측 대상(5/20/60/120 정배열), 손절선 min(MA20, MA60, MA120), 문턱·칸·고원 조건 전부.
- **위험(미리 적음):** 템플릿이 들어간 leader_P·M 은 2009~2016 에서 실패했다 — tmpl=켬 이 뽑혀도 관문 1 의 같은 후보 풀 무작위 솎기 널이 이 뼈대 대비 증분을 잰다. 200일선 거름은 후보 수를 줄인다 → 관문 0 칸의 n·체결 하한(100) 미달 위험이 늘었다.

## 정정 MQ-2 (결과 전, 2026-11-14 — 실행기 스모크(모양·시간만) 뒤, 지표 미조회)
- **정지일:** `daily_bars_adj_v2` 의 정지일은 NaN 이 아니라 거래량 0 · 직전 종가 그대로다(2013-06~2024-01 210,991칸). 설계 의도("결측 창이면 신호 없음")대로 **거래량 0 또는 결측인 날의 종가를 NaN** 으로 둔다
  → 그 날이 적합 창 · σ 창 · 이평선 창 · 라벨 창에 끼면 그 사건은 없다(판정 사건의 약 2% — 스모크 계수). 원래 정의(평평한 종가 유지)로는 보고 열도 내지 않는다(하나만).
- **1,000원 규칙 가격:** 폐지 종목 729개는 `raw_close` 가 전부 없다 → 원 종가가 없으면 수정 종가로 판정한다(indep30 보충 5 선례). 분할 뒤 종목이 잘못 빠지거나 남을 수 있다 — 공개.
- **판정 경계:** 부동소수 오차 때문에 등호 비교에 1e-12 여유를 둔다(문턱 값 자체는 그대로).

## 정정 MQ-3 (결과 전, 2026-11-14 — 관문 0 미실행, 어떤 지표·수익도 미조회) — 관문 1 단순화(사용자 "최대한 심플하게 시작해")
- **시도 순서:** 시도 1 = X-dead 를 먼저 구현·판정한다. 시도 2(X-mnv)는 시도 1 판정 뒤 같은 엔진에 청산 규칙만 더해 돌린다(둘 다 등록된 시도 — 순서만 정함, 다중 비교 표시는 2건 그대로).
- **겹침:** 시도 1 의 겹침은 **일봉 3쌍만**(P_up ≥ 0.5 인 쌍 수 0~3, o_min ∈ {0, 1, 2} 그대로). 주봉 2쌍 겹침은 뒤 시도로 미룬다(새 시도로 등록).
- **폴드 시뮬:** 폴드마다 빈 장부로 Y 첫 거래일에 시작, 진입은 Y 안에서만, 보유 포지션은 진입 설정의 청산 규칙으로 끝까지(폴드를 넘어도) — 다음 폴드 장부와 슬롯을 나누지 않는다(단순화 — 연속 장부보다 슬롯 경쟁이 약하다, 공개).
  설계 구간 끝 평가 = 2023-12-28 종가(라벨 끝과 같다 — 2024 가격 미사용). 학습 창 성적은 Y−1 말까지 끝난 거래 + 보유분 Y−1 마지막 종가 평가(C2 그대로).
- **널 ②(같은 후보 풀 무작위 솎기):** 날짜별 진입 수를 선택 설정과 맞춰 사전 후보 풀에서 무작위로 고르고, 손절 ① 은 그대로, 그 밖의 청산은 선택 설정의 비손절 청산 보유 기간 분포에서 뽑은 기간 뒤 시가로(③·② 의 P 가 없으므로).
- **팩터 회귀:** `research/autoresearch/prepare.factor_months`(MOM·SMB·LV) + KOSPI·KOSDAQ 월 수익, `factor_t` 의 OLS·NW(lag 3) — 기존 구현 재사용.
- **그대로:** 진입·청산 ① ③ · X-dead 규칙, 체결 규약(t 종가 판정 → t+1 시가), 비중, 메뉴(겹침 정의만 위), 선택 기준, 널 ① 300, 바 1~6, VOID < 100, 비용 2배 판정.

## 정정 MQ-4 (결과 전, 2026-11-14 — 실행기 리뷰 뒤, 관문 0 미실행) — 실행 규약 기록
- **라이브러리 모집단:** q ≥ 1 은 위생 ∧ ADV20 ≥ 10억 ∧ 상장 ≥ N + 60일, q = 0 은 상장 ≥ 70일(가장 작은 N + 60). 설계서 §3 "세 예측기는 라이브러리 모집단이 같다" 와 상장 70~100일 신규 종목만 다르다 — 영향 작음, 공개.
- **짝짓기:** 칸마다 q=2·q=1·q=0 확률과 라벨이 모두 유한한 사건만 판정·보고에 쓴다(세 예측기 같은 사건 집합). 빠진 사건은 사유별(라벨·풀 없음·NaN)로 센다.
- **보고 모집단 R3**(정배열 아닌 전체 종목-일)는 결정적 20% 표본(blake2b(code|date) mod 5 = 0) — 판정 무관.
- **가격 읽기:** `daily_bars_adj_v2` 는 정규장 보정 모드를 받지 않는다 → `session="raw"`(구간 끝 2024-01-31 < 오염 시작 2026-09-14, 내용 같음). 상장 전 시세 칸은 NaN.
- **실행 출처:** 실제 실행은 깨끗한 작업 트리(커밋된 코드)에서만, 정본 `research/logs/ma_quad/` 로만 한 번.
