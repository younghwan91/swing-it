→ 고침 제안: `half` 단계에서도 `last ≤ stop_px` 면 즉시 전량 청산(원래 손절), 본전은 규칙대로 다음날부터. 백테스트 `on_bar` 는 바꾸지 말 것(패리티·비관성 유지).

- **백테스트 기계(독립 리플레이).** 규칙 문서에서 다시 쓴 시뮬레이터로 (a) 33 + (b) 192 = **225/225 일치**(진입일·청산일·사유·`ret` 1e-9·d·진입가). 현금 장부를 따로 세워(매수 시가, 매도 부분마다 `cost_rt`, stop/breakeven 50bp, 종가 평가·마지막 종가 이월) 일자산 곡선 **두 변형 전 일자 |차이| 0 원**, 최종 자산 일치. Σpnl = 최종 − 1억 (a·b).
  같은 날 손절·익절 → 손절 먼저, 갭 익절 시가, 본전 다음날부터(갭 익절일 예외), MA50 추적 다음 거래 가능일 시가, 20일 시간 손절 1회, 120일, 정지일 날짜만 셈 — 전부 연구와 같다.
- **패리티 테스트는 동어반복이 아니다.** 연구 `_simulate_one` 은 벡터 첫-인덱스 탐색, 라이브는 스트리밍 상태기계 — 구조가 다른 두 구현이고 내 세 번째 구현이 둘과 일치한다. 실데이터 35/35·48/48 은 **같은 패널** 위 시뮬레이터 패리티다(피처 패리티는 사건 집합 235/235·502/502 가 맡는다 — 둘 다 `swing_it.features` 공유라 "조립" 검증이다).
  빈틈은 §M1: 라이브 이벤트 경로는 일봉 패리티 밖이고, 그 테스트는 차이 사례를 제외한다.
- **Sharpe·CAGR·MDD·노출·회전율** 정의 재계산 일치. 노출 = 평균(보유/자산), 회전율 = (매수+매도)/2/평균자산/년.
- **사이징·현금.** 시작 1억, 10 슬롯 × 10% = 100%; 현금 예약 = 수량 × 지정가(피벗×1.05 ≥ 체결가) 라 음수 현금 불가능. 후보 > 빈 슬롯이면 rel 오름차순(하루 최대 (a) 3건·(b) 4건 진입). 신호일 종가 사이징 vs 체결가: 체결 ≤ 피벗×1.05 < 종가×1.05 → 비중 ≤ 10.5%(실측 최대 10.3%).
- **용량.** 1억에서 슬롯 = ADV20 의 0.04~0.06%(중앙). 5억 0.2~0.4%, 10억 0.3~0.7%, **30억 1.0~2.2%**(ADV 5% 초과 트레이드 (a) 3% · (b) 10%). 묶이는 곳은 **시가 동시호가 참여율**(하루 거래량의 5~10%) — 30억이면 체결 종목의 동시호가 물량 20~40% 를 먹는다. 50~200억 구간의 실용 상한은 **5~10억** 으로 본다.

## 6. 설정·결정 (체크리스트 6) 와 권고

**사실:** `StrategyConfig()` = CONVERGENCE A(VOID) + 유니버스 변경(50~200억 → ≥50억). 사전등록 A 는 판정이 안 났고, 변경된 유니버스에서의 (a) 는 A ∪ R 의 재제시다. **라이브 후보 설정은 미검증이다.**
**체결률:** (a) 33건/2.63년 = **연 12.5건**. n ≥ 40(사전등록 하한)까지 페이퍼 **≈ 3.2년**. 이것이 이 설계의 진짜 비용이다 — 숫자를 보기 전에 받아들여야 한다.

**권고(한 문단):** 백테스트 (a)/(b) 의 성과 숫자는 go/no-go 근거로 쓰지 말고, 기계 검증(패리티·장부·룩어헤드 통과)의 근거로만 쓸 것. 페이퍼는 **설정 하나를 지금 얼려서** 사전등록한다 —
`StrategyConfig()` 그대로(ADV20 ≥ 5,000, F 필수, rel ≤ 1.0, PEAD ≥ 0.70, 미너비니 청산, 10% 고정 사이징·10 슬롯), 단 시작 전에 (i) M1 의 라이브 절반 손절을 닫고(패리티 테스트에 그 사례를 *제외* 가 아니라 *기대 차이* 로 명시),
(ii) M4 의 낙폭 킬 재개 규칙을 적고, (iii) M5 대로 문서 문장을 코드에 맞추고, (iv) M2 의 대용 지수를 고치거나 (b) 의 지수 비교를 2024-01-26 이후로 한정한다. 합격 바는 CONVERGENCE A 의 5개를 그대로(모멘텀 정합 alpha CI 하단 > 0,
비용 2배 평균 > 0, 이익/손실 ≥ 2 ∧ 손절 < 50%, 최악 10% ≥ −11%, 월별 양수 > 50%) + **n ≥ 40 또는 36개월 중 먼저 오는 것**을 정지 규칙으로, 중간에 설정·유니버스·순위 규칙을 바꾸면 시험 무효로 둔다.
기간이 길다는 이유로 ADV 하한을 낮추거나 rel 을 풀어 체결을 늘리고 싶어질 텐데, 그것이 곧 다중검정이다 — 바꾸려면 **새 사전등록**으로.
