### 0. 질문 — 그리고 왜 ML 인가

- **질문.** 시점이 맞는 피처 15개를 비선형 모델(LightGBM)로 묶으면 다음 20거래일 잔차수익을 예측할 수 있는가? 그 예측이
  기존 최적화기에 들어가 정가 비용 2배를 내고도 기대값을 남기는가? 잔차는 위험모델 v4 의 시장·업종·스타일을 뺀 값이다.
  결정은 **전진 모의 팔을 열지 말지** 하나뿐이다.
- **왜 선형 결합이 아니라 ML 인가(사전 근거).** 문헌의 엣지는 대부분 **조건부**다.
  - PEAD 드리프트는 관심이 적을 때·적은 종목에서 크다(Hirshleifer–Lim–Teoh 2009; DellaVigna–Pollet 2009).
  - 모멘텀은 커버리지가 낮은 작은 종목에서 크다(Hong–Lim–Stein 2000).
  - 단기 반전은 비유동 종목에서 크다(Avramov–Chordia–Goyal 2006).
  - 모멘텀은 고변동 국면에서 무너진다(Daniel–Moskowitz 2016).

  선형 동일가중 결합은 이런 상호작용을 표현하지 못한다. 트리 모델은 표현한다. 그래서 질문을 셋으로 나눈다.
  ① 예측력이 있는가. ② 그것이 스타일·반전의 모양에서 오는 것 이상인가. ③ 선형 결합보다 많은가. ③이 아니면 단순한 쪽(EW)을 쓴다.
- **사전 확률은 낮다.** 이 레포에서 ML 은 한 번 기각됐다(`MULTI_ALPHA.md` "ML-강화 버전"·"로버스트니스 경고", 러너 삭제 2026-08-16).
  그때는 LightGBM 을 피처 yoy·age·r20·r60·r120·accum·logmc 로 썼다. IC 를 목표로 학습하니 예측력이 사이즈·반전 팩터로 샜고,
  매매 목표로 학습하니 표본을 넓혔을 때 plain PEAD 와 같아졌다.
  - 이번에 다른 점:
    - (a) 타깃이 v4 잔차다. 다만 잔차가 빼는 것은 **시총가중 WLS 로 본 선형 스타일 노출뿐**이다. v4 에는 단기 반전 스타일이 없다.
      스타일의 비선형 모양(극단 십분위 등)도 잔차에 남는다. 그래서 옛 ML-PEAD 가 샌 길이 구조적으로 막히지는 않는다.
      남는 몫은 진단 S·R, 바 I-5, 널 N3 로 잰다(§7).
    - (b) 봉인 구간을 쓰지 않는다. (c) 비용·위험 제약이 걸린 최적화기 북으로 판정한다. (d) 원장 N 을 라벨로 남긴다.
  - 직전 연구(`pead_optimizer/B_verified.md`)에서 PEAD 순위 신호 단독은 2020~23 무작위 널의 88 백분위였다(바 95%). 그 기대값의 약 45% 는
    한 종목(086520)이었다. 이 연구는 그 판정을 다시 열지 않는다. PEAD 는 여기서 피처 하나이자 비교 기준선일 뿐이다.

### 2. 데이터·유니버스·시점

- **로더:** krx-quant-core `load_risk_inputs("2019-01-02", "2023-12-28")`. 준비 기간 400일은 자동이고, 폐지 종목을 포함하지 않으면
  assert 로 멈춘다. 수익은 `daily_bars_adjusted` 의 **수리된 표**를 쓴다(swing-it PR #12·#14, quant-airflow PR #24 `ADJUSTED_STRICT=True`.
  옛 표는 `legacy.daily_bars_adjusted_pre_seamfix_20261102`). 실행할 때 표 지문(B 와 같은 4-튜플)을 기록한다.
  이음매 가드는 B 와 같은 PO-3.3 규칙이고, 가드가 걸린 셀 수를 보고한다.
- **데이터 끝(END) = 2023-12-28**, 코드에서 강제한다. 마지막 결정일은 t+21 ≤ END 인 격자일이다.
- **유니버스 U(t)** — 아래를 모두 만족하는 종목:
  - v4 추정 유니버스에 든다(WICS 라벨 있음, 스타일 6개 유한, 시총 유한).
  - 20일 평균 거래대금 ≥ 50억원(core `adv_value` ≥ 5e9 원).
  - 시총 상위 400위 안이다.
  - 예상 크기는 약 300종목이다. B 의 80종목(21~100위·ADV 200억)은 일별 IC 의 SE 가 너무 크다(§12).
  - 3억 원 북에서 ADV 50억의 5% 참여 한도는 묶이지 않는다.
  - U* = ∪_{OOS t} U(t) 는 N2 널의 순열 대상이다.
- **시점:** 결정은 t 종가까지의 정보로 하고 **체결은 t+1 종가**에 한다(B 규약).
  - **북 격자** t_k 는 2019-08-01 이후 첫 거래일에서 시작해 20거래일 간격이다(B 와 같다). OOS 는 약 49회다.
  - **IC 격자**는 같은 기준일에서 시작해 5거래일 간격이다. 북 격자는 그 부분집합이다. OOS 는 약 195회다.
    20일 라벨이 겹치므로 I-1·I-2 는 같은 격자의 널과만 비교한다(HAC 불요). 시계열 t 검정(I-4·I-5)은 Newey–West lag 6 이다.

### 3. 피처 — 15개 고정

- 날짜마다 U(t) 안에서 rank-gauss Φ⁻¹((순위−0.5)/n) 로 바꾼다. NaN 은 그대로 남긴다(LightGBM 은 결측을 그대로 받고, 선형 모델은 0 으로 채운다).
- **"알게 된 날"** 열의 날짜 **다음 거래일**부터 그 값을 쓴다. 그 열에 "t 종가" 라고 적힌 것은 t 마감 뒤 확정되는 값이다.
  t+1 종가 체결 전에 알 수 있으므로 t 결정에 쓴다. 이 정의는 바꾸지 않는다.
- 생존자 전용 원천은 **쓰지 않는다**: `credit_balance`·`short_selling`·`program_trading` 백필은 상장 생존 종목만 있다.
  기관 세부(투신·연기금)도 폐지 종목은 NULL 이다. 결측이 미래 폐지와 상관되면 누출이 된다.
  컨센서스 EPS 이력과 뉴스(2023-03~)는 원천이 없거나 짧다.
- **수급은 원천 하나에서만 읽는다(MINOR a).** F5·F8 은 `naver_investor_trend` 의 `foreign_net`·`institution_net` 만 쓴다.
  `supply_demand` 는 상장=키움, 폐지=네이버로 원천이 갈려서, 정의 차이가 폐지 여부와 상관된다.
  네이버 순매수는 네이버 정의(합 0 맞춤)라 키움 값과 다르다. 이 연구 안에서는 전 종목이 같은 정의다.

  - 부호표는 코드 상수다. 해시 회귀 테스트로 고정한다.

### 4. 타깃

- u_{i,s} = core `factor_returns(R, X_style, WICS, cap, mask_y)` 의 특이수익이다(s 수익을 s−1 노출로 회귀, 제약 WLS).
  - 팩터 구조는 v3·v4 가 같다(시장 + WICS 10 + 스타일 6). v4 = `vraoff_s0.1`(PO-3.5)은 특이분산 D 만 다르다.
    그래서 잔차는 "v4 잔차" 그대로다. D 는 §7 의 α 크기와 위험에 쓴다.
  - **타깃 전용 추정 마스크 mask_y(MAJOR-5):** core 는 s 회귀 행을 `mask[:, s−1]` 로 고른다. 그래서 mask_y[:, s−1] = v4 마스크 ∧ (거래량_s > 0) 로 둔다.
    거래정지일(거래량 0, 종가 고정)이 팩터 수익 추정에 들어가지 않는다. 이 마스크는 라벨에만 쓰고, 피처·북의 위험모델에는 쓰지 않는다.
- **y_{i,t} = Σ_{s=t+2}^{t+21} u_{i,s}** — t+1 종가에 사서 20거래일 들고 있는 동안의 잔차다.
  - **거래정지일 처리:** 거래량_s = 0 인 날은 u_s = NaN 으로 두고 합에서 0 으로 친다. 가짜 평탄 잔차(−f 만 남는 값)를 지운다.
    재개일 수익(정지 전 종가 → 재개일 종가)은 거래량 > 0 이므로 그대로 들어간다.
  - **진입 불가 제외:** 거래량_{t+1} = 0 인 종목은 IC 에서 뺀다(북의 `no_trade` 와 같은 규칙). 학습에서도 뺀다.
  - **유효 조건:** 창 안에서 가격 행이 있는 날(정지일 포함)이 15일 미만이면 NaN 이다.
  - 예외는 창 안에서 폐지된 종목이다. 관측된 날까지 합하고 나머지는 0(현금)으로 두어 **남긴다**.
  - 보고: 정지일 수, 정지일이 있는 라벨 행 수, 진입 불가로 뺀 수, 폐지 보존 행 수.
- 학습할 때는 날짜마다 y 를 rank-gauss 로 바꾼다(꼬리 한 종목이 학습을 끌고 가지 않게 — 에코프로 교훈).
  평가는 원래 y 로 한다(Spearman 이라 같다).

### 7. 판정

**1단계 — 예측력(IC, 비용 없음, 5거래일 격자).** 2020~23 의 OOS IC 격자일마다 Spearman(예측, y)을 낸다.
U(t) 안에서 예측과 y 가 유한하고 t+1 거래량 > 0 인 종목만 쓴다. 100종목 미만인 날은 빼서 센다.

| # | 바 | 대상 |
|---|---|---|
| I-1 | 평균 IC > N2 널의 95 백분위. **E 는 N3 널의 95 백분위도** 넘어야 한다 | M·E |
| I-2 | ICIR = mean/sd(격자일 IC) > N2 널의 95 백분위 | M·E |
| I-3 | 연도별 평균 IC > 0 이 4년 중 ≥ 3 | M·E |
| I-4 | ΔIC(M − E) 격자일 시계열: 평균 > 0, NW(lag 6) t ≥ 2.0 — "ML 이 선형보다 많다" | M 선택용 |
| I-5 | ΔIC(M − S) 격자일 시계열: 평균 > 0, NW(lag 6) t ≥ 2.0 — "스타일·거래량 모양 이상이다" | M |

- **N2 널 — 같은 메뉴의 무작위 신호(MAJOR-1 반영).**
  - 반복 r 마다 U* 위의 순열 π 하나를 `keyed_rng("ML-N2", r)` 로 뽑는다.
  - 날짜 t 에서 종목 i ∈ U(t) 는 예측 p_{π(i), t} 를 받는다.
  - π(i) ∉ U(t) 이거나 그 값이 NaN 이면, 그날 아직 배정되지 않은 실제 예측 중에서 비복원으로 채운다(`keyed_rng("ML-N2-fill", r, t)`).
  - 그래서 널의 유한 개수와 값 집합이 실제와 같다. 같은 π 를 모든 날짜에 쓰므로, 채워지지 않은 종목은 예측 시계열이 그대로 남는다.
  - 1,000회. 날짜별·전체 채움 비율을 보고한다.
- **N3 널 — 같은 메뉴의 무작위 결합(MAJOR-2).** 300회, `keyed_rng("ML-N3", r)`.
  - 피처 15개에 무작위 부호 ±1 과 Dirichlet(1,…,1) 가중을 준 rank-gauss 가중 평균이다(결측 처리는 E 와 같다).
  - "이 메뉴로 아무렇게나 섞어도 나오는 IC" 다. E 의 문헌 부호가 그것을 넘는지 본다. M 은 S 대비 I-5 로 같은 역할을 한다.
- **2단계 진입:** E 는 I-1~I-3 을, M 은 I-1~I-3 과 I-5 를 통과해야 한다. 아무도 통과하지 못하면 "**채택 불가(예측력 없음)**"으로 끝낸다. 북은 돌리지 않는다.
- 주장 라벨: M 이 I-4 를 통과하면 "선형 결합보다 많다" 이다. **"상호작용·비선형 이득"이라고 쓰려면 ΔIC(M − L) NW(lag 6) t ≥ 2.0 도** 필요하다(MINOR c).
  못 넘으면 "학습된 결합 이득" 이라고만 쓴다.

**2단계 — 비용 반영 북(기존 최적화기, 20거래일 격자).** B 하네스(`pead_optimizer_b`)의 O 북에 유니버스를 U(t) 로, 신호를 각 예측으로 넣는다.
- 최적화기: core `portfolio.optimize`. α_i = IC₀·√(20·D_i)·z_i 이고 z = 예측의 rank-gauss 다. **IC₀ = 0.03, 모든 북에 같은 상수다.**
  학습 IC 를 쓰지 않는다 — 표본 안 IC 는 부풀어 과매매를 부른다.
- 벤치 b = U(t) 동일가중. λ 는 사전 능동위험 **0.020/20거래일**(연 약 7.1%)에 맞춘다(B 의 `match_lambda`, ±2%). 모든 북에 같다.
- 제약:
  - 롱온리, `budget=1`.
  - `max_weight` 0.05, 섹터 밴드 0.10, 회전 ≤ 2/3.
  - 참여 ≤ 5%·ADV20, t+1 거래 불가는 `no_trade`. AUM 3억.
  - 첫 리밸런스(구축)는 회전 상한 없이 풀고, 그 비용은 평가에서 뺀다.
  - 폐지는 마지막 종가로 청산하고 현금으로 둔다(B 와 같다).
- 비용(정가, B 와 같다):
  - 수수료 0.015% 양쪽, 매도세(날짜·시장별), 반스프레드 KOSPI 5bp·KOSDAQ 15bp.
  - 제곱근 충격 y=1(σ 63일, ADV20).
  - 최적화는 1배로 풀고, 회계는 1배·2배로 한다. **판정은 2배다.**
- a_k = 북 순수익 − b 수익(스텝, 2배). 지표 정의는 B(`pead_optimizer_b`·`_report`)와 같다.

| # | 바 (2단계 진입 후보마다, 전부 비용 2배) |
|---|---|
| P-1 | 순 IR = mean(a)/sd(a)·√(252/20) > 그 후보 O 북 N2 널의 95 백분위(300회, 위와 같은 π·채움 생성기를 북 격자일에 적용) |
| P-2 | 스텝 순 EV = mean(a) > 0 |
| P-3 | 보유 구간 손익비(이익 구간 평균 / 손실 구간 평균의 절댓값, 순기여) ≥ 1.0 |
| P-4 | 상위 5 보유 구간 기여를 뺀 EV > 0, **그리고** 상위 20 을 뺀 EV > 0 |
| P-5 | 순기여 1위 종목을 통째로 뺀 EV > 0 **이고** ≥ 0.5 × EV(MINOR b. B 에서 086520 을 빼면 EV 가 0.30~0.38 배였다) |
| P-6 | 순 IR(후보) > 순 IR(PEAD 단독 P 북, 같은 하네스) — 점추정 |

- **라벨만(판정에 쓰지 않는다):**
  - 팩터 회귀 알파 HAC t 와 원장 N 두 개(§9)의 문턱 max(2.0, z_{1−0.05/(2N)}), Deflated Sharpe.
  - 회귀식은 B 와 같다: 스텝 순수익 ~ 1 + KOSPI + KOSDAQ + UMD + SMB + LOWVOL, NW lag 2.
    단 UMD·SMB·LOWVOL 은 **U(t) 안에서** 만든다(MINOR g, 같은 유니버스의 팩터로 깎는다).
  - 결과와 무관하게 판정문에 "재사용 창 — 알파 주장 불가" 를 붙인다(MAJOR-3).
- M 이 E 보다 낫다고 말하려면 I-4 에 더해 **ΔIR(M − E)(2배) > 0**(점추정)이어야 한다.
- **승률은 바에 없다.** 참고로만 적는다. 승률 > 50% 인데 손익비 < 1 이면 "승자를 일찍 자르는 구조" 경고를 붙인다.
- 보고만(veto 아님): 1배 비용 숫자, 연도별 IC·EV·IR, 체결 수, 회전, 추정·실현 비용, KOSPI 대비, 실현 대 사전 능동위험,
  `factor_attribution` 특이 몫, 시드별 IC, 진단 S·R·L·P 의 IC(전부)와 L·P 북, ΔIR 블록 부트스트랩(평균 블록 3, 10,000회), N1 학습 널(§8).

**판정(기계적, MAJOR-3·4):**

| 판정 | 조건 | 다음 |
|---|---|---|
| **전진 후보** | 2단계 진입 + P-1~P-6 전부 통과 | 전진 모의 팔. 라벨 "재사용 창 — 알파 주장 불가, 전진만이 증거" + HAC t·문턱 값 |
| **판단 불가(검정력)** | 2단계 진입 + P-2~P-6 통과, **P-1 만** 실패 | 전진 팔을 열지 않는다. B 규약대로 검정력 부족으로 기록한다 |
| 채택 불가 | 2단계 진입 뒤 P-2~P-6 중 하나라도 실패(P-1 동반 여부 무관) | 실패한 바 번호를 붙인다(P-6 이면 "기존 PEAD 대비 이득 없음"). 기각이라 쓰지 않는다 |
| 채택 불가(예측력 없음) | 2단계 진입 실패 | 2단계를 열지 않는다 |

- 후보 선택: 둘 다 전진 후보면 M 이 I-4 와 ΔIR(M − E) > 0 을 통과할 때만 M 이다. 아니면 **E**(정보가 선형이면 단순한 쪽). 하나만 통과하면 그 후보다.
- **HAC t 를 게이트로 두지 않는 이유:** 4년·48스텝에서 문턱 3.37 을 넘으려면 순 IR ≥ 1.7 이 필요하다. 넓은 N 의 문턱 3.54 면 1.8 이다.
  그러면 이 실험은 IC ≈ 0.08 미만인 참 엣지를 전부 떨어뜨리는 장치가 된다. 게다가 재사용 창이라 통과해도 알파를 주장할 수 없다.

### 8. VOID (하나라도 해당하면 판정하지 않는다)

- 북 OOS 결정일 < 40, IC OOS 격자일 < 160, 또는 격자일 U(t) 크기 중앙값 < 150.
- **0단계 관문 실패**(라벨을 계산하기 전에 실행하고 커밋한다):
  - (a) 절단 재계산 동일성. 무작위 결정일 5개에서 데이터를 그날까지 잘라 다시 낸 피처가 전체 패널의 피처와 비트 단위로 같아야 한다.
  - (b) 피처별 U(t) 커버리지. 중앙값이 F7 ≥ 25%, F1 은 2020~ 격자일에서 ≥ 70%, 나머지 ≥ 80% 여야 한다.
    못 미치면 **라벨 계산 전에** 정정 ML-n 으로 피처를 빼고 공개한다.
  - (c) 폐지 종목의 피처 결측률이 상장 종목보다 20%p 넘게 높은 피처가 있으면 같은 처리다.
- 하네스 패리티 실패. 유니버스·신호를 주입하도록 일반화한 하네스가 B 상수에서 `B.json` 의 O·R 스텝 수익을 1e-10 안에서 재현해야 한다.
- 최적화 `optimal` 비율 < 95%, 또는 λ 맞춤 실패(solver·gap·down 원인, PO-8) > 10%.
- **N1 누출 카나리아.** 학습 라벨을 날짜 안에서 섞어 M 을 다시 학습한다(20회, E 는 학습이 없어 해당 없다).
  20회 OOS 평균 IC 의 평균이 M 의 N2 널 95 백분위를 넘으면 VOID 다. 학습 경로(행 정렬·퍼지·rank 변환)가 라벨 밖의 구조를 새게 한다는 뜻이다.
- 같은 시드로 다시 돌린 결과가 비트 단위로 다르다.
- 실행일에 quant-airflow `check_data_quality` 의 조정주가 검사가 실패한다.
- **두 관문의 한계(MINOR d — VOID 가 아니라 공개 사항):**
  - N1 은 라벨을 섞으므로 "피처가 미래와 연결된" 누출을 잡지 못한다. 그런 누출은 섞기와 함께 사라진다. 그것은 절단 동일성(a)과 알게 된 날 테스트의 몫이다.
  - (a) 는 지금 DB 의 이력을 자를 뿐이라, **원천이 나중에 고친 값**은 잡지 못한다. 예: 2026-10 에 백필한 `naver_investor_trend`, 정정된 리포트 목표가.
    이 위험은 판정문 한계 절에 적는다.

### 정정 ML-1 (2026-11-02, 구현 고정 — 어떤 단계도 실행하기 전)

**공개: 결과를 보지 않았다.** 이 정정을 쓸 때까지 라벨·수익·피처 값·커버리지·모델 출력을 하나도 계산하지 않았다. 본 것은 코드(core·B 하네스)와 표 메타 숫자뿐이다:
`naver_research_reports.prev_goal_price` 는 88,804행 전부 NULL·0, `goal_price` NULL·0 은 11,292행, 같은 (종목, 증권사, 작성일) 묶음 177개, 작성일 2008-01-04~. `naver_investor_trend` 2008-01-02~. `earnings_disclosures.period` 는 `YYYYQn`. 이 표 메타는 2024 이후 날짜의 MAX 를 포함하지만 값은 아니다(기존 §1 예외 없음).
또 `python -m collectors.data_checks` 를 오늘 한 번 돌렸다(§8, 8건 통과 — 조정주가 카나리아는 가격 사건 몇 칸의 수익률을 찍지만 이 연구 입력이 아니다).

사전등록이 정하지 않은 곳을 **더 유리한 쪽을 볼 수 없는 지금** 고정한다. 바·피처·구간·하이퍼파라미터는 그대로다.

1. **U(t).** "시총 상위 400위"는 v4 추정 유니버스(core `build_risk_model` 의 반환 종목과 같은 식 — 0단계에서 비트 대조) **안** 순위이고, ADV ≥ 50억은 독립 조건이다(교집합). §2 의 "모두 만족"·"예상 약 300종목"을 따른다. (B 처럼 유동성 집합 안에서 순위를 매기면 거의 항상 400 이라 그 문장과 어긋난다.)
2. **F7.** `prev_goal_price` 가 비어 있으므로 "직전 목표가"는 표 이력에서 만든다: 목표가 > 0 인 리포트만, 같은 (종목, 증권사) 의 더 이른 작성일(표 처음부터). 같은 (종목, 증권사, 작성일) 은 `research_id` 가 큰 하나로 접는다. "90일"은 **달력일**이고, t 에서 쓰는 리포트는 write_date ∈ [date(t) − 90일, date(t)) 이다(다음 거래일부터 사용과 같다). 평균은 동일가중.
3. **F2.** "최근 분기" = t 까지 알게 된 분기 중 가장 늦은 분기(`YYYYQn` 순서). 나이 = t − k, k = 그 분기 첫 공시일 다음 거래일(그날 값 0), 120 으로 자른다. 알게 된 공시가 없으면 NaN.
4. **F4·F5·F6·F8·F9 의 결측 규칙.** F4: 창 안 유한 종가 ≥ 126. F5·F8: 창 20일 안 관측 ≥ 15 이면 있는 날만 합, 주식수 ≤ 0·NaN 이면 NaN. F6: 보유율은 최대 5거래일 앞으로 채운 값의 차분(수준 값이라서). F9: ADV5 관측 ≥ 3, ADV60 관측 ≥ 30, 값이 0 이면 NaN. F3: 양 끝 종가가 있어야 한다. 종가는 이음매 가드 뒤의 종가다(B 와 같다).
5. **F1.** 정기보고서 접수일이 없는 분기는 행 자체를 뺀다(c0 `yoy_signal(end=…, fallback=False)`). 그래서 접수일 있는 직전 분기가 as-of 로 남을 수 있고, 2019-02-28 전에는 NaN 이다. 값을 avail_date 로 되돌리지 않는 것이 MINOR f 의 뜻이다.
6. **F10~F15 동점.** c0 `exposures` 는 마스크 안 결측을 0 으로 채운다. 그 값을 그대로 rank-gauss 하고 동점은 평균 순위다.
7. **학습 가중.** §5 "날짜마다 가중이 같다" = 행 가중 w = n̄ / n_t (날짜마다 합이 같고 평균 1). LightGBM 은 `weight` 로, 릿지(L)는 β = (XᵀWX + α·n·I)⁻¹XᵀWy 로 넣는다. y 는 rank-gauss 다. 학습 행은 U(t) ∧ y 유한 ∧ t+1 거래량 > 0 이다. rank-gauss 는 그 행 안에서 낸다.
8. **라벨.** "창 안 폐지" = `delisted_stocks.last_trade_date` 의 열이 [t+1, t+21) 안이다. t+1 에 행이 없으면(거래량 NaN) 진입 불가로 뺀다. 창에 가격 행이 하나도 없고 창 안 폐지도 아니면 NaN. 거래량은 로더와 같은 표(`daily_bars_adjusted.volume`, core `load_daily_bars`)다.
9. **IC 날짜 집합.** 후보마다 실제 신호에서 유효 종목 ≥ 100 인 격자일로 고정하고, 그 후보의 N2 널도 같은 날에서 잰다(값 다중집합이 같으므로 유효 개수 차이는 y 결측 위치에서만 난다). N3 결합은 자기 유효 종목 ≥ 100 인 날이다. ICIR 의 sd 는 ddof=1. 95 백분위는 `np.quantile`(선형 보간).
10. **N2 채움 자리.** 그날 채움이 필요한 자리 수가 남은 값 수보다 많으면(예측 NaN 이 있는 후보 E·P·R) 채움 자리를 무작위로 골라 남은 값을 넣고, 나머지는 NaN 이다 — 그래야 유한 개수와 값 다중집합이 실제와 같다(§7). π 는 후보 사이에 같다(같은 `ML-N2` 키). 진단 S·R·L·P 에도 같은 N2 를 돌려 보고만 한다.
11. **N1 순서.** N1 은 라벨과 M 의 N2 가 있어야 하므로 0단계가 아니라 1단계 실행 안에서 판정 앞에 평가한다(§8 은 N1 을 0단계 (a)(b)(c) 와 따로 적었다). 섞기 키는 `keyed_rng("ML-N1", r, t)` 다(같은 r 이면 폴드가 달라도 같은 날은 같은 섞기).
12. **결정성(§8).** M·S 전 폴드·전 시드를 다른 작업자에서 한 번 더 맞춰 예측 바이트를 비교한다.
13. **0단계 관문 기준.** (b) 나머지 피처는 IC 격자 전체(2019-08~), F1 은 2020~ IC 격자일의 중앙값이다. (c) "폐지 종목" = `delisted_stocks` 에 있는 종목(언제 폐지됐든), U(t) 행을 IC 격자 전체에서 합산한다. (a) 결정일은 IC 격자에서 `keyed_rng("ML-S0-trunc")` 로 5개, 비교는 U(t)·원 피처(잘린 패널의 모든 종목)·rank-gauss 다.
14. **check_data_quality(§8).** `daily_finalize` 는 화~토에만 돌아 PR #24 뒤 실행 기록이 아직 없다. 실행일에 `python -m collectors.data_checks`(읽기 전용)를 직접 돌려 출력을 결과에 남긴다.
15. **의존성(DESIGN §1 과 다름).** core 핀을 0.8.0 으로 올리지 않고 `--with krx-quant-core @ portfolio-layer@13c56a7`(B 와 같은 ref)로 돌린다. LightGBM 은 `ml` extra 에 4.7.0 으로 고정한다. 핀 올리기는 2단계 패리티(S2-0) 때 다시 정한다.
16. **린트 규칙 이름(DESIGN §3 과 다름).** (h) 는 이미 `orphan-verdict` 라, 새 규칙은 (j) 로 둔다. 내용은 같다.

### 정정 ML-2 (2026-11-02, 0단계 1회차 실패 뒤 — 라벨 전)

**공개: 0단계를 한 번 돌렸고 관문 (a) 가 실패했다**(`stage0_run1_failed.{json,md}`, 그대로 보관). 그때 본 것은 U(t) 크기, 피처 커버리지, 폐지 대 상장 결측률, 그리고 어긋난 종목 4개(180400·015540·222810·263540)의 실적 행과 YoY 값이다. **라벨(u·y)·수익·모델 출력은 아직 계산하지 않았다.** (b)(c)·v4 유니버스 대조·표 지문은 통과했다.
