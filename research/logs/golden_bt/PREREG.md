# 골든 임박 자리 포지션 최적화 백테스트 — 사전등록 (결과 보기 전 확정 — 2026-11-15)

**사용자 요청(2026-11-15):** "골든 나올 거 같으면 포지션 잡는 최적화 해봐 백테해." 선행: `research/logs/golden_hmm/RESULTS.md` 판정(8b85628) — 골든 확률은 이평선 산수(q0)로 잘 맞는다(2009~16 k=10 AUC 0.986, p≥0.8 예측 96.5% → 실제 96.9%), HMM 은 더한 것 없음. 이 등록은 **수익** 가설: 골든 임박 자리에 확률 기반으로 들어가면 같은 자리·같은 날 무작위보다 버는가.
**상태:** 2017~2023 이 셋업(EPS↑ ∧ 0 < 격차 ≤ 5%)의 수익은 미조회. 2009~16 은 교차 라벨을 봤다(수익 미조회). 2024~ 오염.

## 정의
- **사전 후보(풀):** 유니버스(위생 ∧ ADV20 ≥ 10억 ∧ 상장 252일) ∧ EPS↑(as-of) ∧ MA50 < MA200 ∧ 0 < 1 − MA50/MA200 ≤ 0.05 ∧ 종가 > MA50(구조 손절 거리 d = 1 − MA50/종가 ∈ (0, 0.15]). 정지일 종가 NaN.
- **확률:** P_g = q0 무작위 경로(ma_quad 경험 라이브러리, M=200)의 "k=10 봉 안 MA50 > MA200" 비율. P_d = 보유 중(골든 뒤) "k=10 봉 안 MA50 < MA200" 비율. 같은 함수(`ma_quad.cross_probs`).
- **체결:** t 종가 판정 → t+1 시가. 상한가 시가 매수 불가, 정지일 매매 불가(매도는 다음 가능일). 비용 `korea.cost_rt`, 판정 2배.
- **진입:** 풀 ∧ P_g ≥ θ_in. 순위 = P_g 내림차순. 슬롯 20.
- **비중(유전자 sizing):** "eq" = min(5%, 0.25%/d) / "prob" = 그 값 × P_g (확률이 커지면 다음 판정일에 목표 비중까지 추가 매수 — 불타기, 상한 5%).
- **손절:** 종가 < 진입 판정일 MA50(고정, 올리지 않음) → 다음 시가. 손실 한도는 비중으로(0.25%).
- **청산(유전자 exit):** "dead_p" = 골든 뒤 P_d ≥ θ_d → 다음 시가 / "ma200" = 골든 뒤 종가 < MA200 → 다음 시가. 골든 전 P_g < θ_out → 다음 시가(예측 붕괴). 시간 손절·본전 스톱 없음.
- **메뉴:** θ_in {0.3, 0.5, 0.7, 0.9} × θ_out {0.1, 0.2} × sizing {eq, prob} × exit {dead_p(θ_d 0.5·0.7), ma200} = 48.

## 공개
높은 P_g 자리는 기각된 `minervini_prop`(정배열 뒤 돌파, OOS −0.029R)와 이웃이다. 이 계열(MA 교차) 세 번째 시도, 같은 자료에 autoresearch 280·GA 세대 → DSR. 2017~23 접촉: HMM 학습(라벨 없음), ma_quad β 진단(겹치는 후보의 k ≤ 10 수익). 2009~16 접촉: 교차 라벨, leader_M·P 수익.
**사전 예상:** 주 시험 통과 15%, 재현까지 7%.

## 정정 GB-1 (결과 전, 2026-11-15 — 구현 스모크(모양·시간만) 뒤, 성과 미조회)
- **정지일이 이평선 창에 낀 보유 종목:** 확률이 NaN 인 결정일에는 골든 전 = 보유(손절만), 골든 뒤 = MA200 이탈 대체 청산(정지일을 건너뛴 최근 유효 종가 200개 평균). 골든 판정도 같은 정지일 건너뛴 MA50·MA200 으로 한다. 해당 거래 수·대체 청산 수를 보고.
- **폴드 밖 자산:** 폴드별 연도 구간만 잇지 않고, 모든 폴드 밖 거래의 (비중 × 일수익, 청산일 비용 포함) 합으로 일별 포트폴리오 수익을 만든다 — 해를 넘긴 보유도 자기 설정대로 계속 기여. 총노출 최대·평균 보고. 바 ④⑤⑦·팩터 회귀는 이 계열로.
- **구현 판단 기록(실행기 RULINGS):** 비중 손절 거리 = 체결 시가 기준, prob 불타기는 골든 전에만 증액, 널 ② = 슬롯 제약 없는 거래 단위, 바 ④ = OLS·NW t 둘 다 > 2, DSR N = 362, 재현 창 비용 = cost_rt, 2024~ 미사용.

## 정정 GB-2 (결과 전, 2026-11-15 — 실행 전 리뷰 뒤, 성과 미조회)
- **널 ② 비중(리뷰 C1):** prob 비중일 때 무작위 진입의 비중 배수는 그 종목 자신의 P_g 가 아니라 **짝이 되는 전략 거래의 진입 P_g** 를 쓴다(크기는 같고 고른 종목만 다르게). 무작위 쪽 추가 매수는 같은 배수 경로로 맞춘다. 자기 P_g 를 쓰면 풀 대부분의 낮은 P_g 때문에 널 R 이 작아져 바 ① 문턱이 낮아진다.
- **불타기 정의(리뷰 I1):** 추가 매수는 **원가 비중**(Σ 매수 금액 ÷ 진입 때 자산) < 기준 비중 × P_g(t) 일 때만, 그 차이만큼. 시가 평가 비중으로 비교하면 가격 하락만으로 사게 되어 물타기가 된다(사용자 원칙 위반).
- **폐지 청산(리뷰 I2):** 엔진은 그대로(마지막 유한 종가). `delist` 사유 거래 수·R 합을 보고 열로 내고, 스웜 검증에서 원 DB 의 정리매매 유무를 확인한다.
- **기록(리뷰 I3·Minor):** RULINGS 의 nan_prob 문구를 GB-1 대로 고치고 PREREG 인용에 GB-1·GB-2 커밋을 넣는다. 합산 연속 자산은 폴드 장부가 겹쳐 총노출 > 1 일 수 있다 — 절대 연복리는 계좌 하나의 숫자가 아님을 MD 에 적는다.
