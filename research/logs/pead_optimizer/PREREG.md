### 0. 배경과 순서

- krx-quant-core PR #19(`portfolio-layer`, HEAD `d5c1533`)가 팩터 위험모델·제약 최적화·제곱근 충격 비용을 만들었다
  (설계 `docs/superpowers/specs/2026-11-01-portfolio-layer-design.md`). 그 설계 §5 가 이 실험을 "연구 적용(swing-it)"으로
  넘겼다. 이 저장소가 통과시킨 유일한 알파는 확산형 PEAD 다(`docs/alpha-research.md` §3.1·§4.1). 확산형 엣지의 북 품질은
  신호보다 **구성(위험·비용)**에서 갈린다는 것이 가설이다.
- 그런데 위험모델 v3 의 바이어스 통과는 **표본 안**이다. 같은 창(2019-07~2023-10, 월말 52회)에서 두 번 고친 뒤 통과했고,
  리뷰(같은 설계 §6)는 세 가지를 짚었다. (M1) D=0 모델(특이위험 없음)도 8개 바를 모두 통과한다. (M2) 사후 진단에서
  업종 순수 포트 G55 1.293·G25 0.796, 고변동 십분위 0.798 이 나왔다. (M3) 2020 을 빼면 바 밖으로 나간다.
  과소예측된 업종이 있으면 최적화기는 그쪽으로 쏠린다. 그래서 **A(위험모델 재판정)가 관문이고, A 를 통과해야 B 를 돌린다.**
- 이 연구가 주장하는 것은 "어느 **구성**으로 PEAD 를 들고 갈지"뿐이다. PEAD 자체의 알파 주장은 하지 않는다.
  메타 세대 3(fcs `research/logs/sepa_explore/META_GEN3.md`)에서 분산 PEAD 의 시총가중 코스피 대비 팩터 알파는
  t 1.5~2.0 으로, 보정 문턱 2.67 에 못 미쳤다. 그 판정은 이 문서가 다시 열지 않는다.

`START="2024-01-01"`·`END="2026-09-11"` 두 줄만 바꾼다. 입력은 지금처럼 `load_risk_inputs("2019-01-02", END)` 로 읽어
팩터 수익 이력을 v3 와 같은 방식(첫 WICS 날부터 누적)으로 만든다. 평가는 asof ≥ 2024-01-31 만 한다. 위의 어느 값이든
바꾸면 그것은 v4 이고, 이 사전등록의 대상이 아니다.

**실행 순서(커밋 단위):**
- **R0 재현(판정 아님).** 같은 커밋으로 구창(2019-07~2023-10)을 다시 돌려 설계 §6 v3 열(무작위 0.974·시총 1.002·…)을
  ±0.003 안에서 재현한다. 0.01 넘게 어긋나면 DB 가 바뀐 것이다(주식수 `knowledge_date` 보정 등). 그때는 원인을 적고
  멈춘다 — 다른 모델을 재판정하게 되기 때문이다.
- **A0 보정(실현 수익을 보기 전).** asof 마다 v3 모델만으로 21일 수익을 모의한다: `r = X f + u`, f ~ N(0, 21F),
  u ~ N(0, 21·diag D). 500회 반복하고, 포트 구성은 실현 실행과 같은 시드로 고정한다. 여기서 두 가지를 낸다.
  (i) `h` = 맞는 모델이 **1차 묶음**(아래 A-1~A-3, 11개)을 전부 통과할 확률이 0.90 이 되는 공통 반폭 |b−1| ≤ h.
  (ii) 같은 모의 수익을 D=0 예측(√(21·wᵀXFXᵀw))으로 쟀을 때 전지(1차 묶음 + A-4·A-5)가 실패할 확률 `P_fail(D=0)`.
  A0 출력은 h·P_fail 과 실현 시 쓸 밴드다. 이것을 결과보다 먼저 커밋한다. 실현 수익(asof+1 이후 `R`)은 이 단계 코드에서
  읽지 않는다(코드로 분리한다). 참고로 해석적 근사는 T=31 에서 표준오차 1/√(2T)=0.127 이고, 11개 묶음에서 10% 가족오류면
  h≈0.30~0.33 이다.
- **A1 실현.** 바이어스 = z(실현/예측 표준편차)의 표준편차(`bias_statistic`, ddof=1, 무작위 포트는 평균)다.

**합격 바 (전부 충족해야 A 통과):**

전진 A(§3)로 넘어간다.

**보고만 하는 것(바 아님):** 연도별(2024·2025·2026-1~7월) 값, 2026-07 급락(−40.9%/27거래일) 달을 뺀 값, 종목별 특이 z

**미리 적는 검정력 한계:** h≈0.3 이면 G55 1.29 정도의 과소예측은 이 창에서 통과할 수 있다. 이 창이 잡는 것은 ±30% 대 오차까지다.
B 의 실현 위험 바(B-6)가 그 나머지를 본다.

**A 를 반증하는 것:** A-1~A-5 중 하나라도 실패하면 A 는 실패다. A 가 실패하면 원인(업종 공분산 반감기·NW, 특이분산
수축 공간·중심)을 고친 v4 를 만들고, v4 는 전진으로만 판정한다. B 는 v4 가 통과할 때까지 열지 않는다.

### 2. 단계 B — 같은 PEAD 신호, 현행 순위 북 대 최적화 북 (A 통과 때만)

**구간과 봉인:** 최적화 북에는 위험모델이 필요하고, 위험모델은 WICS 2019-01-02 + 번인 6개월 때문에 **2019-07-31** 부터만
만들 수 있다. 그래서 2017~2018 은 최적화 북으로 돌릴 수 없다. 평가(OOS)는 **2020-01~2023-12 이고 연 단위 폴드 4개**다
(= 진화 폴드 1~4, CLAUDE.md 설계 창 2017~2023 안). 2019-08~12 는 두 북 모두 예열 구간이다(초기 구축 비용은 평가에서 뺀다).
IC 학습에는 2017-01~ 를 쓴다. **2024-01 이후 데이터는 단계 B 의 어떤 계산에도 쓰지 않는다.**
한계: v3 는 이 구간(2019-07~2023-10)에서 바이어스를 보고 두 번 고친 모델이다. 위험 예측 품질이 표본 안에서 유리하다.
이 창의 결과는 "설계 선택 증거"이고 확인이 아니다. 확인은 전진(§3)뿐이다.

**유니버스(두 북 공통, 시점 정합):** `storage.read_prices` 정문을 쓰고 상장폐지를 포함한다. 보유 중 폐지되면 마지막 관측
종가로 청산한다(`delisting_exit=True` 와 같은 뜻). 리밸런스일 t 의 적격 조건은 셋이다. ① 직전 20거래일 평균
`trade_value` ≥ 20,000 백만원(200억). ② ① 안에서 시총 순위 21~100위. 시총은 risk_inputs 의 원 종가 × as-of 주식수다.
③ 신호 유한 ∧ t 의 위험모델에 있음(WICS·스타일·D 유한). ③ 때문에 빠지는 적격 종목 비율을 매 리밸런스 보고한다.
평균이 5% 를 넘으면 두 북 모두 같은 집합을 쓰므로 판정은 유지하되 그 사실을 적는다.

**신호(두 북 같음):** 분기 순이익 YoY 다. `earnings_yoy_panel(read_earnings(all_versions=True), …, knowledge_col="knowledge_date")`
의 `yoy` 를 쓰되, 알게 된 날은 CLAUDE.md 실적 as-of 규칙 = max(`avail_date`, 정기보고서 `rcept_dt`) **다음 거래일**이다
(fcs `read_earnings(with_known=True)`). main 의 `sw-pead` 경로는 `avail_date` 만 써서 18% 가 미래 정보다. 두 북 모두 위
규칙으로 다시 계산하므로 순위 북 숫자는 `docs/pead-strategy.md` 발표치와 다를 수 있다. 신선도 필터는 없다(`fresh_days=0`).

**현행 순위 북 R(현직):** `recommend_holdings` 기본 = `docs/pead-strategy.md` "최소 배포 형태" 다. 스태거드 3트랜치이고,
`horizon=60`·`step=20` 이다. 트랜치마다 적격 유니버스의 YoY 상위 `top_n=10` 을 동일가중으로 담는다. 목표 비중 = 활성
트랜치 3개 동일가중 벡터의 평균이다(종목 최대 10%).

**최적화 북 O:** krx-quant-core `portfolio.optimize`(`d5c1533`)를 같은 리밸런스일에 한 번 푼다.
- **α 지도(정확히):** z_i = Φ⁻¹((순위_i − 0.5)/n). 적격 유니버스 안 YoY 오름차순 순위이고, 동률은 평균 순위다.
  α_i = IC_k · √(H·D_i) · z_i 이고 H = 60(신호 지평)이다. D_i 는 t 의 위험모델 일간 특이분산이다(Grinold α = IC·ω·z).
  Σ 도 같은 지평 H·Σ_daily 로 맞춘다. 비용은 리밸런스 1회분이다(상각 없음).
- **IC_k(워크포워드):** 폴드 k 시작일보다 60거래일 앞까지(퍼지) 2017-01-02 부터 누적한 일별 순위 IC 의 평균이다
  (적격 유니버스, 60일 앞 수익, 기존 `rank_ic` 와 같은 정의). 범위는 [0, 0.10] 으로 자른다. 0 이면 그 폴드의 O 는 R 과 같은
  위험의 무알파 북이 된다(그대로 둔다).
- **능동위험:** 벤치 b = 적격 유니버스 동일가중(R 의 기존 벤치와 같다)이다. 목적함수 αᵀw − (λ/2)(w−b)ᵀΣ(w−b) 는
  α' = α + λΣb 로 넣어 정확히 만든다(core 를 고치지 않는다).
- **λ(위험 맞춤, 수익을 보지 않는다):** 리밸런스마다 O 의 사전 능동위험 √((w−b)ᵀΣ(w−b)) 가 같은 날 R 의 목표 비중의
  사전 능동위험과 ±2% 안에서 같아지도록 λ 를 정한다. 탐색은 로그 공간 이분법이고 범위는 [1e-2, 1e5], 최대 40회다.
  닿지 않으면 가장 가까운 λ 를 쓰고, 그 횟수를 보고한다. 같은 예측 위험에서 어느 구성이 PEAD 를 더 담는지를 비교한다.
- **제약:** 롱온리, `budget=1`, 현금 없음. `max_weight=0.10`(R 의 최대와 같다). `sector_band=0.10`(WICS 섹터별
  |Σw_g − b_g| ≤ 10%p). `max_turnover`: Σ|Δw| ≤ 2/3(R 이 한 스텝에 트랜치 1/3 을 통째 바꿀 때의 상한). `max_participation=0.05`
  (|Δw_i|·AUM ≤ 5%·ADV20). `no_trade`: t+1 거래량 0 또는 가격 없음. 베타·스타일 제약은 없다(능동위험 항이 맡는다).
- **AUM:** 3억원(CLAUDE.md 자본 1~3억). 이 규모에서 참여율·충격은 거의 묶이지 않는다. 용량은 민감도(100억)로 본다.
- `status != "optimal"` 이면 core 규약대로 거래하지 않는다(`w = w_prev`). 그 횟수를 보고한다.

**회계(두 북 같은 하네스):** 리밸런스 격자는 t_k = (2019-08-01 이후 첫 거래일) + 20k 거래일이다. R 의 트랜치용 과거
격자는 같은 간격으로 앞으로 연장한다. 결정은 t_k 종가까지의 정보로 하고, **체결은 t_k+1 종가**에 한다(진입 t+1).
스텝 사이에는 매수 보유로 비중이 표류하고, 다음 리밸런스 회전율은 표류한 비중 대비로 잰다. R 을 이 하네스로 다시
회계하면, 트랜치를 매 스텝 동일가중으로 되돌리는 거래도 비용으로 잡힌다(기존 엔진은 그것을 공짜로 본다).
**패리티 검사(실행 전 필수):** 하네스를 지연 0·무비용으로 돌리면 R 의 구간 `book` 이
`staggered_tranche_backtest(horizon=60, step=20, top_n=10, adv_floor=20000, cap_rank=(20,100), delisting_exit=True)` 와
1e-10 안에서 같아야 한다. 다르면 하네스 버그다.

**비용(정가):** 수수료는 core `DEFAULT_COMMISSION_RATE` 0.015% 이고 매수·매도 양쪽이다(할인·면제 없음). 매도세는
`costs.tax.sell_tax_rate`(체결일·시장별 — 2019-06-03·2021·2023 단계)다. 반스프레드는 KOSPI 5bp·KOSDAQ 15bp 이고, core
`DEFAULT_*_SLIPPAGE_PCT` 와 같다. 충격은 `sqrt_impact_bp` 의 y=1, σ = t 의 63일 일간 변동성, ADV = 20일 평균 거래대금(원,
×1e6)이다. **1배**는 이대로다. **2배**는 수수료·매도세·반스프레드·y 를 전부 2배로 한다. 판정은 2배다(CLAUDE.md).
최적화기는 비용 1배 가정으로 풀고, 사후 회계만 1·2배로 한다(2배를 미리 알면 덜 거래하는 쪽이 유리해진다).

**지표:** 스텝 능동수익 a_k = 북 순수익 − b 수익(20거래일)이다.
- **1차 지표 = 순 IR(2배)** = mean(a)/sd(a)·√(252/20). OOS 2020~2023 전체 스텝으로 잰다.
- 기대값 EV = mean(a)(스텝당, 연율 병기)다. 손익비 = mean(a | a>0) / |mean(a | a<0)| 이다.
- 종목 보유 구간(비중 > 0 이 이어진 구간) 단위로 순기여 분포를 낸다(R-분포 모양, 왜도, 상위 5·20 구간 제거).
- 절대 순수익·Sharpe·MDD, 연도별, 체결 수·평균 보유 종목 수·회전율·추정/실현 비용, 사전 대비 실현 능동위험,
  `factor_attribution` 의 특이 몫, KOSPI 대비, 팩터 회귀 알파(HAC t)를 같이 낸다. 승률은 참고로만 적고 판정에 쓰지 않는다.

**널(같은 메뉴의 무작위 설정):** O 와 같은 제약·같은 λ 맞춤·같은 비용으로 α 만 바꾼 널이다. 날짜마다 z 를 적격 종목
사이에서 무작위로 섞어 200회 돌린다(시드 고정). 위험모델의 구조적 기울기(저특이변동·업종 밴드)만으로 생기는 IR 을 잰다.

**판정 규칙 — "최적화 북 채택"은 아래 전부 (아니면 현직 R 유지, 동률은 현직):**

| # | 바 |
|---|---|
| B-1 | ΔIR = IR(O) − IR(R) (2배) > 0, 짝지은 정상 블록 부트스트랩(평균 블록 3스텝 = H/step, 10,000회, 시드 고정)에서 P(ΔIR > 0) ≥ 0.90 |
| B-2 | ΔEV ≥ 0 (2배) — 같은 예측 위험에서 기대값이 줄지 않는다 |
| B-3 | 폴드(2020·2021·2022·2023) 중 3개 이상에서 ΔIR > 0 (2배) |
| B-4 | 1배에서도 ΔIR > 0 |
| B-5 | O 의 순 EV(2배)가 상위 5 보유 구간을 빼도 > 0 |
| B-6 | 실현 능동위험 sd(a_O) ≤ 1.25 × sd(a_R) — 모델 오차를 파먹어 숨은 위험을 지지 않는다(A 의 검정력 한계 보완) |
| B-7 | IR(O) (2배) > 섞은-α 널 200회의 95 백분위 |
| B-8 | 손익비(O) ≥ 0.9 × 손익비(R) (2배) — 회전율·밴드가 승자를 일찍 자르지 않는다 |

**VOID:** 최적화 `optimal` 비율이 95% 미만이거나, 패리티 검사가 실패하거나, OOS 스텝이 40 미만이면 VOID 다.
**PEAD 북 자격(채택과 별개로 적는다):** 두 북 모두 팩터 회귀 알파 HAC t 가 원장 N 으로 깎은 문턱(t-haircut)을 못 넘으면
"구성은 정했지만 PEAD 는 팩터 노출이지 알파가 아니다"라고 적는다(메타 세대 3 과 같은 기준). 전진 팔도 그렇게 라벨한다.

**B 를 반증하는 것:** B-1~B-8 중 하나라도 실패하면 "최적화 북 채택" 가설은 기각이고 현직을 유지한다. B-7 만 실패하면
개선은 PEAD 가 아니라 위험모델 기울기에서 온 것이다. B-6 만 실패하면 같은 예측 위험이 실현에서는 더 컸다는 뜻이고,
최적화기가 모델 오차를 이용한 것이다. 기각된 구성을 같은 2020~2023 데이터로 파라미터만 바꿔 다시 돌리지 않는다.
다음은 전진뿐이다.

**사전 예상(정직하게):** 스텝 약 48개, 두 능동 계열의 상관이 0.6 근처이면 ΔIR 의 표준오차는 약 0.45 다. B-1 은
ΔIR ≳ 0.6 이어야 넘는다. 가장 가능성 높은 결과는 "판단 불가(표본 부족) → 현직 유지"이고, A 통과 확률은 반반이다.
