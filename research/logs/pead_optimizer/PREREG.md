### 0. 배경과 순서

- krx-quant-core PR #19(`portfolio-layer`, HEAD `d5c1533`)가 팩터 위험모델·제약 최적화·제곱근 충격 비용을 만들었다
  (설계 `docs/superpowers/specs/2026-11-01-portfolio-layer-design.md`). 그 설계 §5 가 이 실험을 "연구 적용(swing-it)"으로
  넘겼다. 이 저장소가 통과시킨 유일한 알파는 확산형 PEAD 다(`docs/alpha-research.md` §3.1·§4.1). 가설은 확산형 엣지의
  북 품질이 신호보다 **구성(위험·비용)**에서 갈린다는 것이다.
- 그런데 위험모델 v3 의 바이어스 통과는 **표본 안**이다. 같은 창(2019-07~2023-10, 월말 52회)에서 두 번 고친 뒤 통과했다.
  설계 §6 의 리뷰가 짚은 것은 셋이다. (M1) D=0 모델(특이위험 없음)도 8개 바를 모두 통과한다. (M2) 사후 진단에서 업종
  순수 포트 G55 1.293·G25 0.796, 고변동 십분위 0.798 이 나왔다. (M3) 2020 을 빼면 바 밖이다. 과소예측된 업종이 있으면
  최적화기는 그쪽으로 쏠린다. 그래서 **A(위험모델 재판정)가 관문이고, A 를 통과해야 B 를 돌린다.**
- **B 는 능동위험만 본다.** B 는 `budget=1` 롱온리이고, 위험모델의 `market` 열은 전 종목 1 이다. 그래서 두 북과 벤치의
  시장 노출은 같고, B 에서 시장 요인은 상쇄된다. A 의 1차 바도 그에 맞춰 **능동 포트(w − b)**로 정한다. 시장 수준
  대상(시총가중·롱온리 무작위)은 국면(2024~26 지수 자체의 꼬리)에 지배되므로 보고만 한다.
- 이 연구가 주장하는 것은 "어느 **구성**으로 PEAD 를 들고 갈지"뿐이다. PEAD 자체의 알파 주장은 하지 않는다.
  메타 세대 3(fcs `research/logs/sepa_explore/META_GEN3.md`)에서 분산 PEAD 의 시총가중 코스피 대비 팩터 알파는
  t 1.5~2.0 으로, 보정 문턱 2.67 에 못 미쳤다. 이 문서는 그 판정을 다시 열지 않는다.

     모두 ≥ 0.8 인 최소 T 를 전진 A 의 판정 시점으로 고정한다(§3).
- **A0 신창 보정(실현 수익을 보기 전, 신창 모델 예측만):**
  - asof 마다 v3 모델로 21일 수익을 1,000회 모의한다. r = X f + u 이고, f 는 21F 를 공분산으로 하는 다변량 t_{ν_f}
    (분산 1 로 맞춤), u 는 종목마다 독립인 t_{ν_u}·√(21 D_i) 다. 포트 구성은 실현 실행과 같은 시드로 고정한다.
  - **목표별 밴드:** SE_j = 맞는 모델에서 대상 j 바이어스의 모의 표준편차, h_j = c·SE_j 다. 공통 c 는 맞는 모델이 1차 묶음
    **전체**(S1~S6·S*·P5·P50·P10B·HV·SM·OB + IP·IE 묶음 규칙)를 통과할 확률이 0.90 이 되게 정한다. 가족오류 10% 에
    A-4·A-5 를 포함한다는 뜻이다. S* 의 문턱은 같은 c 로 모의 분포에서 정한다.
  - **탐지확률:** 진짜 D 를 D×0, D×0.5, D×2 로 바꿔 모의하고 v3 예측으로 잴 때 전지가 실패할 확률을 각각 낸다. D×0 은
    "특이위험이 없는 세상인데 모델은 D 를 예측"하는 경우이고, 이와 대칭인 "D=0 으로 예측" 검정은 A-6 에서 한다.
    추가로 v3 의 D 대신 D=0 으로 예측했을 때 전지의 실패 확률도 낸다.
  - **VOID:** max_j h_j > 0.35 이거나, 위 네 탐지확률 중 하나라도 < 0.8 이면 VOID 다.
  - A0 출력(ν, c, h_j, 탐지확률)을 커밋한 뒤에 A1 을 돌린다. 이 단계 코드는 asof+1 이후 `R` 을 읽지 않는다(코드로 분리).
- **A1 신창 실현.** 바이어스 = z(실현/예측 표준편차)의 표준편차다(`bias_statistic`, ddof=1, 다수 포트는 평균).

**합격 바 (전부 충족해야 A 통과):**

| # | 대상 | 바 |
|---|---|---|
| A-1 | S1~S6 각각, 그리고 합동 S* | \|b_j − 1\| ≤ h_j, \|S*\| ≤ 문턱(A0) |
| A-2 | P5·P50·P10B (능동) | 각각 \|b_j − 1\| ≤ h_j |
| A-3 | HV·SM (능동) | 각각 \|b_j − 1\| ≤ h_j |
| A-4 | IP_g (G 개) | h_g 밖이 ⌊0.2G⌋(=2)개 이하, 1.5·h_g 밖은 0개 |
| A-5 | IE_g (능동, G 개) | A-4 와 같은 규칙 |
| A-6 | **D=0 검정력(실현).** 같은 실현 수익을 D=0 예측으로 잰 P5 | b(D=0) > 1 + h_P5 — D=0 이 떨어져야 한다. 아니면 VOID |
| A-7 | **OB 최적화 바이어스** | \|b_OB − 1\| ≤ h_OB |

**미리 적는 검정력 한계:** 31회로는 h_j 보다 작은 오차를 못 잡는다. A 통과가 말하는 것은 "능동위험 예측이 ±h_j 안"까지다.
B 의 실현 위험 바(B-NI-3)가 그 나머지를 본다.

**A 를 반증하는 것:** A-1~A-5·A-7 중 하나라도 실패하면 A 는 실패다(A-6 실패는 VOID). A 가 실패하면 원인(업종
공분산 반감기·NW, 특이분산 수축 공간·중심, 최적화 바이어스 보정)을 고친 v4 를 만들고, v4 는 전진으로만 판정한다.
B 는 그때까지 열지 않는다.

### 2. 단계 B — 같은 PEAD 신호, 현행 순위 북 대 최적화 북 (A 통과 때만)

**구간과 봉인:**
- 최적화 북에는 위험모델이 필요하다. 위험모델은 WICS 2019-01-02 + 번인 6개월 때문에 **2019-07-31** 부터만 만들 수 있어서,
  2017~2018 은 최적화 북으로 돌릴 수 없다.
- 평가(OOS)는 **2020-01~2023-12, 연 단위 폴드 4개**다(진화 폴드 1~4, CLAUDE.md 설계 창 2017~2023 안). 2019-08~12 는
  예열 구간이고, 첫 구축 비용은 두 북 모두 평가에서 뺀다.
- IC 학습에는 2017-01 이후를 쓴다. **2024-01 이후 데이터는 B 의 어떤 계산에도 쓰지 않는다.**
- 한계: v3 는 이 구간(2019-07~2023-10)에서 바이어스를 보고 고친 모델이라 위험 예측이 표본 안에서 유리하다.
  B 의 결과는 "설계 선택 증거"다. 확인은 전진(§3)뿐이다.
- GUARDRAILS §2 는 "2020/21 은 TRAIN 내부 → 클린 아님"이라고 적는다. 여기서는 IC 를 폴드마다 누적·퍼지로 학습하므로
  2020·2021 폴드도 그 폴드의 IC 학습 구간과 겹치지 않는다. 그래도 PEAD 신호 자체가 2016~2026 연구로 골라졌다는 점에서
  어느 폴드도 신호 선택에 대해 깨끗하지 않다. 폴드별 결과를 적을 때 이 문장을 같이 쓴다.

**공유 적격 마스크(두 북·널·패리티가 같은 함수 하나를 쓴다):** `eligible(t)` 은 두 단계다.
- M0(t) = ① 신호 유한 ∧ ② 직전 20거래일 평균 `trade_value` ≥ 20,000 백만원(200억) ∧ ③ t 의 위험모델 종목 집합 U_t 안.
  ADV 는 core `backtest.crosssectional._trailing_adv` 와 같은 정의다. 그 함수를 부르거나, 바이트 동일을 테스트로 고정한다.
- eligible(t) = M0(t) 안에서 시총 순위 21~100위. 시총은 risk_inputs 의 원 종가 × as-of 주식수다.
- 매 리밸런스, ③ 때문에 빠지는 ①∧② 종목 비율을 보고한다.
- **패리티 검사(실행 전 필수):** 신호를 M0 밖에서 NaN 으로 바꾼 패널을
  `staggered_tranche_backtest(top_n=10, cap_rank=(20,100), horizon=60, step=20, adv_floor=20000, delisting_exit=True)`
  에 같은 시총 배열과 함께 넘긴다. 그 함수는 유한 신호 ∧ ADV 종목 안에서 시총 순위를 매기므로 같은 21~100위 집합이 나온다.
  하네스를 지연 0·무비용으로 돌린 순위 북 구간 `book` 이 이 결과와 1e-10 안에서 같아야 한다. 기간은 2019-08~2023-12 이다.

**신호(두 북 같음):**
- 분기 순이익 YoY = `earnings_yoy_panel(read_earnings(all_versions=True), …, knowledge_col="knowledge_date")` 의 `yoy`.
- 알게 된 날은 CLAUDE.md 실적 as-of 규칙 = max(`avail_date`, 정기보고서 `rcept_dt`) **다음 거래일**이다
  (fcs `read_earnings(with_known=True)`). **2018Q3 이전은 정기보고서 날짜가 없어 `avail_date` 로만 잡는다** — IC 학습 앞부분과
  2019 예열의 일부 신호가 여기에 해당한다(18% 미래 정보 위험이 남는다).
- main `sw-pead` 경로는 `avail_date` 만 쓰므로, 순위 북 숫자는 `docs/pead-strategy.md` 발표치와 다를 수 있다.
- `fresh_days=0`.

**현행 순위 북 R(현직):** `recommend_holdings` 기본 = `docs/pead-strategy.md` "최소 배포 형태"다. 스태거드 3트랜치,
`horizon=60`·`step=20` 이고, 트랜치마다 eligible(t) 의 YoY 상위 `top_n=10` 을 동일가중으로 담는다. 목표 비중은 활성
트랜치 3개 동일가중 벡터의 평균이다(종목 최대 10%).

**최적화 북 O:** krx-quant-core `portfolio.optimize`(`d5c1533`)를 같은 리밸런스일에 한 번 푼다.
- **α 지도(정확히):**
  - z_i = Φ⁻¹((순위_i − 0.5)/n). 순위는 eligible(t) 안 YoY 오름차순이고, 동률은 평균 순위다.
  - α_i = IC_k · √(H·D_i) · z_i, H = 60(신호 지평). D_i 는 t 의 위험모델 일간 특이분산이다(Grinold α = IC·ω·z).
  - Σ 도 같은 지평 H·Σ_daily 로 맞춘다. 비용은 리밸런스 1회분이다.
- **IC_k(워크포워드):** 2017-01-02 부터 폴드 k 시작일 **62거래일** 앞(60일 앞 수익 + 체결 지연 1 + 여유 1)까지 누적한
  일별 순위 IC 의 평균이다(eligible 정의, 60일 앞 수익, 기존 `rank_ic` 와 같은 정의). [0, 0.10] 으로 자른다.
- **능동위험:** b = eligible(t) 동일가중. α' = α + λΣb 로 목적함수 αᵀw − (λ/2)(w−b)ᵀΣ(w−b) 를 정확히 만든다.
- **λ(위험 맞춤, 수익을 보지 않는다):** 리밸런스마다 O 의 사전 능동위험이 같은 날 R 목표 비중의 사전 능동위험과 ±2% 안에서
  같아지게 정한다. 탐색은 로그 공간 이분법, 범위 [1e-2, 1e5], 최대 40회다. 맞추지 못한 횟수를 보고한다.
- **제약:**
  - 롱온리, `budget=1`, 현금 없음.
  - `max_weight=0.10`, `sector_band=0.10`(WICS 섹터별 |Σw_g − b_g| ≤ 10%p).
  - `max_turnover`: Σ|Δw| ≤ 2/3.
  - `max_participation=0.05`(|Δw_i|·AUM ≤ 5%·ADV20).
  - `no_trade`: t+1 거래량 0 또는 가격 없음.
  - 베타·스타일 제약은 없다.
- **첫 리밸런스(구축):** 회전율 상한 없이 푼다. 구축 비용은 평가에서 뺀다.
- **적격에서 빠진 보유 종목:** 문제 안에 남기고 z=0(α=0)·`no_buy` 로 둔다. 회전율 상한 안에서 줄여 나간다. 위험모델에서도
  빠진 종목(X·D 없음)은 문제에 넣을 수 없으므로 t+1 에 강제 매도한다. R 도 같은 날 같은 종목을 판다.
- **AUM:** 3억원(CLAUDE.md 자본 1~3억). 용량은 민감도(100억)로 본다.
- `status != "optimal"` 이면 거래하지 않고(`w = w_prev`) 그 횟수를 보고한다.

**회계(두 북 같은 하네스):**
- 격자 t_k = (2019-08-01 이후 첫 거래일) + 20k 거래일. R 의 트랜치용 과거 격자는 같은 간격으로 앞으로 연장한다.
- 결정은 t_k 종가까지의 정보로 하고, **체결은 t_k+1 종가**에 한다.
- 스텝 사이에는 매수 보유로 비중이 표류한다. 회전율은 표류한 비중 대비로 잰다. R 의 트랜치 재동일가중 거래도 비용으로 잡는다.
- **폐지:** 마지막 관측 종가로 청산한다(`delisting_exit=True` 와 같은 뜻). 대금은 현금(수익 0)으로 두고, 다음 리밸런스에서
  `budget=1` 로 재투자한다. 두 북 같다.

**비용(정가):**

**지표:** 스텝 능동수익 a_k = 북 순수익 − b 수익(20거래일).

  절댓값). 구간 분포(왜도, 상위 5·20 구간 제거).

  `factor_attribution` 특이 몫, KOSPI 대비, 팩터 회귀 알파(HAC t). 승률은 참고로만 적는다.

이력을 받으므로 신호가 바뀌는 시점은 그대로 남는다. 적격 마스크는 진짜 신호로 계산한 `eligible(t)` 를 그대로 쓰고,
순열 값이 NaN 인 적격 종목은 z=0 으로 둔다(그 비율을 보고한다). O 와 R 각각에 대해 같은 π 로 200회 돌린다(시드 고정).

  O 가 정상일 때의 오탈락은 B-NI-4 에서 가장 크다(신호 세기에 달렸다). 결합 통과 확률은 결과 보고 때 같은 순열·부트스트랩
  표본으로 다시 추정해 적는다.
- **보고만(veto 아님):** 폴드별 ΔIR(2020·2021·2022·2023 — 위 GUARDRAILS §2 주석과 함께), 스텝 손익비·보유 구간 손익비,
  상위 5 구간 제거 EV, ΔIR 의 블록 부트스트랩 분포(평균 블록 3스텝, 10,000회).
- **VOID:** 최적화 `optimal` 비율 < 95%, 패리티 검사 실패, OOS 스텝 < 40, λ 맞춤 실패 > 10% 중 하나라도 해당하면 VOID 다.

  PEAD 는 팩터 노출"이라고 적고, 전진 팔도 그렇게 라벨한다.

**사전 예상:** A 통과는 반반 이하다(1차 묶음이 능동 포트로 바뀌어 더 엄격해졌다). A 가 통과하면 B-NI 통과는 약 0.5 다.

### PO-1.1 [C-1] A0 모의에 공통 분산 충격을 넣고, 부트스트랩 SE 와 구창 전지를 더한다

2판 A0 는 u 를 종목마다 독립으로 뽑았다. 그러면 횡단면 공통 분산 충격 s_t 가 빠진다. 다수 포트 평균 대상
(P5·P50·P10B 각 100개, OB 200개, HV·SM·IE)의 SE 가 2.5~3.5 배 작게 나온다. 합성 모의에서 독립 SE 는 0.015 였고,
혼합 CV 0.4·0.6 에서는 0.039·0.052 였다.

**모의 생성식(A0·C0 공통):**
- r = X f + u.
- f 는 21F 를 공분산으로 하는 다변량 t_{ν_f} 이고 분산 1 로 맞춘다(2판 그대로).
- u_it = s_t · √(21·D_i) · ε_it. ε_it 는 종목·날짜마다 독립인 t_{ν_u} 이고 분산 1 로 맞춘다.
- s_t² 는 asof 마다 모든 종목이 공유하는 평균 1 로그정규 혼합이고, f 와 독립이다. CV 는 CV_s 다.

**C0 가 재는 것 (구창 실현만):**
1. **실현 특이 z.** asof a 마다 e_ia = Σ_{d=a+1}^{a+21} u_id 를 낸다. u_id 는 같은 노출·업종·마스크로 돌린 `factor_returns`
   일별 잔차다. 대상은 U_a 안에서 21일 잔차가 모두 유한한 종목이다. z_ia = e_ia / √(21·D_ia).
2. **CV_s.** m_a = mean_i z_ia², ŝ_a² = m_a / mean_a(m_a) 로 둔다.
   CV_s² = Var_a(ŝ_a²) − mean_a(v_a / N_a) / mean_a(m_a)² 이고, 0 아래면 0 으로 둔다.
   v_a 는 그 달 z_ia² 의 횡단면 분산, N_a 는 종목 수다. 빼는 항은 유한 N 표본잡음이다. 잔차 횡단면 상관은 보정하지 않으므로
   CV_s 는 약간 크게 나온다.
3. **ν_u** 는 z_ia / ŝ_a 를 모아서 잰다(2판 식 ν = 4 + 6/max(κ_ex, 0.2), [4.5, 30]).
4. **ν_f** 는 S1~S6·IP_g 의 21일 z 를 모아서 잰다. 대상마다 자기 표준편차로 나눈 뒤에 모은다. 꼬리 모양을 재려는 것이지
   대상 사이 바이어스 차이를 재려는 것이 아니다. 나누기 전 값도 보고한다. **P50 은 뺀다**(3판에서 능동 포트라 특이위험
   지배다). 초과첨도는 `scipy.stats.kurtosis(fisher=True, bias=False)` 로 잰다.
5. **SE_j^boot.** 대상 j 의 구창 실현 z 계열(52개월)을 원형 블록 부트스트랩으로 다시 뽑는다. 길이는 판정 T(신창 31, 전진은
   각 T)이고, 블록 길이 L ∈ {3, 6}, 2,000회다. 다수 포트 대상은 월 열을 함께 뽑는다. SE_j^boot = max_L sd(b_j*) 다.
   S* 는 부트스트랩한 b_k* 로 S* 를 다시 계산해 잰다.

**밴드(2판 h_j = c·SE_j 를 대체한다 — 비대칭, 모의 분위로 정한다):**
- 맞는 모델에서 모의한 b_j 의 중앙값 m_j 를 밴드 중심으로 쓴다. 공통 주변 수준은 α 다.
- 기본 밴드 = [Q_j(α/2), Q_j(1−α/2)] 이다. Q_j 는 b_j 의 모의 분위다.
- 확대 계수 κ_j = max(1, SE_j^boot / SE_j^sim) 이다. SE_j^sim 은 모의 b_j 의 표준편차다.
- 최종 밴드 = [m_j − κ_j·(m_j − Q_j(α/2)), m_j + κ_j·(Q_j(1−α/2) − m_j)] 이다. 반폭 h_j^−·h_j^+ 를 내고, h_j = max(h_j^−, h_j^+) 로 둔다.
  VOID 바(max_j h_j ≤ 0.35)는 이 h_j 로 본다. 대상은 IP_g·IE_g 를 포함한 1차 묶음 전부다.
- **S\*** = mean_k (b_k − m_k) / SE_k^sim 이다(k = 스타일 6개). 바는 |S*| ≤ κ_S*·Q_{|S*|}(1−α) 다.
- **IP·IE 묶음 규칙:** 최종 밴드 밖이 ⌊0.2G⌋개 이하이고, 반폭을 1.5 배로 늘린 밴드 밖은 0개다.
- α 는 맞는 모델 모의에서 1차 묶음 **전체**(A-1~A-5·A-7)를 통과할 확률이 0.90 이 되게 이분법으로 정한다. 이때 κ=1 로
  둔다. κ_j > 1 로 넓히면 그 확률은 0.90 이상이 된다. 2판의 공통 c 는 이 α 로 바뀐다. 2판 "S* 의 문턱은 같은 c 로"도 위 식으로 바뀐다.

**C0 에 더하는 것 — 구창 전지(보고만, 단 STOP 규칙이 있다):**
- 구창 52회에서 1차 묶음 전체(A-1~A-7, OB 포함)의 실현값을 낸다.
- 같은 절차로 구창 모델 구조(T=52)의 밴드를 모의해 낸다. 이것이 구창 h_j 다.
- **STOP:** v3 가 구창에서도(표본 안에서도) 2판 전지 바 중 하나라도 못 넘으면 신창(A0·A1)을 돌리지 않는다. A-6 의 D=0
  검정력이 구창에서 VOID 인 경우도 같다. 그때는 보고하고 멈춘다. 다음 경로(v4 설계 또는 전진 A)는 사용자가 정한다.

### PO-1.4 [M-3] 패리티를 정의된 모드로 나누고, 실제 규칙 차이는 사건 목록으로 보고한다

`staggered_tranche_backtest`(core `crosssectional.py`)의 동작은 넷이다. 트랜치를 결성일 종목 목록으로 들고(221행 `book`),

  - 위험모델 이탈 강제 매도는 끄고, 현금도 없다. 벤치 = eligible(t) 의 nanmean 이다.

### PO-2.1 [M1] 이음매 가드 — 수익률 셀을 버린다

1. **판정.** 종목 i, 거래일 d(직전 거래일 d⁻)의 수익 셀마다

### PO-2.2 [M2] CV_s — 강건 추정과 재표집 구간

- PO-1.1-2 의 평균 기반 식은 버린다(이 꼬리에서 90% 구간이 [0, 0.33]).
- **1차: 중앙값-z² CV.** asof a 마다 m_a = median_i z_ia², ŝ_a² = m_a / mean_a(m_a).
  CV_s² = Var_a(ŝ_a², ddof=1) − mean_a(Var*(m_a)) / mean_a(m_a)², 0 아래면 0. Var*(m_a) 는 그 달 종목을 복원 추출(200회,
  `keyed_rng("cvmed", a)`)한 m_a 의 분산이다(유한 N 표본잡음).
- **확인: 윈저화(±5) 반분 공분산.** asof 마다 종목을 무작위로 반씩 나눈다(`keyed_rng("split", a)`). 반마다 m^h_a = mean clip(z, −5, 5)²,
  ŝ^h = m^h / mean_a(m^h) 로 두고 CV² = Cov_a(ŝ^1, ŝ^2)(ddof=1), 0 아래면 0. 두 반의 표본잡음은 독립이라 공분산에서 빠진다.
- **구간:** 두 추정 모두 asof 를 원형 블록 부트스트랩(블록 3, 10,000회)해서 5·50·95% 를 낸다. 표본잡음 항은 고른 달의 값을 쓴다.
- 모의에는 **1차 점추정**을 쓴다. 1차의 95% 상단으로 관문을 한 번 더 돌린 값을 보고만 한다.
- ν_u 는 z_ia / ŝ_a(1차의 ŝ)를 모아서 PO-1.1-3 식으로 잰다. ν_f 는 PO-1.1-4 그대로(가드 뒤 값).

### PO-2.3 단계 A — 1차 대상 하나, 보조 하나

- **1차 A-OB21:** PO-1.6 의 OB 그대로다. 월말 asof, 포트 200개, α_i = √(21·D_i)·ε_p,i(새 표준정규), Σ = 21·Σ_daily, 벤치 b_B,
  롱온리·`budget=1`·`max_weight 0.10`·`sector_band 0.10`·w_prev=0, λ 는 사전 21일 능동위험이 σ_target ±2% 가 되게 정한다.
  통계량은 b_OB21 = mean_p sd_a(z_pa)(ddof=1), z = 21일 실현 능동수익 / 사전 21일 능동위험.
- **보조 A-OB5:** 같은 포트(같은 asof 에서 만든 w_p,a)를 asof 뒤 겹치지 않는 5거래일 구간 4개 [a+1+5k, a+5+5k](k=0..3)로 잰다.
  예측은 같은 asof 모델의 √(5·(w−b)ᵀΣ(w−b)) 다(사전). 21번째 날은 쓰지 않는다. b_OB5 = mean_p sd(z_p,a,k)(T×4 개, ddof=1).
  주간으로 다시 최적화하지는 않는다 — "주간"은 월간 포트를 주 단위로 재는 것이다.
- **A 통과 = 둘 다 밴드 안.** 밴드는 PO-1.1 의 비대칭 모의 분위 + 부트스트랩 확대(κ)다. 공통 주변 수준 α 는 맞는 모델에서
  두 검정을 **모두** 통과할 확률이 0.90 이 되게 정한다(κ=1 로 정하고, κ>1 로 넓히면 그 확률은 0.90 이상). **가족오류 10% 는 이 두
  검정에만 쓴다.**
- **보고만(바 아님):** S1~S6·S*·P5·P50·P10B·HV·SM·IP_g·IE_g, 시장 수준 대상(PO-1 그대로), A-6(D=0 대조), 그리고
  **QLIKE·DM:** 같은 OB 포트에서 L = z² − ln z² − 1 을 asof 마다 포트 평균한다. v3 와 "시장+업종 전용 모델"(`build_risk_model`
  에 스타일 노출 없이, 나머지 인자 같음)의 차 d_a 에 HAC t(Newey-West lag 2, 양쪽)를 건다.
- PO-1 의 VOID 집합(D×0·D×0.5·D×2·D=0 예측·F×0.7·F×1.5)과 max h ≤ 0.35 바, T_fwd 는 **폐기**한다. 아래 관문이 대신한다.
  OB 성공 < 90%(PO-1.6) VOID 는 남긴다.

### PO-2.4 검정력 관문 — 신창을 쓰기 전에 구창 모의로 잰다

- **구조:** 가드를 켠 구창 52개 월말의 v3 모델과 OB 포트(가드 뒤 σ_target 으로 다시 푼 것). 판정 길이는 신창과 같은 **T = 31**
  (주간 124)이다. 모의 반복 r 마다 시작 달 o_r = r mod 52 를 두고 (o_r + t) mod 52 (t = 0..30)의 구조를 쓴다(52개 구조를 고르게 쓴다).
- **반복 수:** 10,000(N_SIM). 부트스트랩 SE 도 10,000회다.
- **생성식(PO-1.1 을 주간과 맞게 쪼갠다).** 한 달 21일을 5·5·5·5·1 일 블록 5개로 나눈다.
  - f_k = chol(ℓ_k·F)·g_k · √((ν_f − 2)/χ_f), g_k ~ N(0, I). χ_f ~ χ²_{ν_f} 는 그 달 블록이 **공유**한다.
  - u_ik = s · √(ℓ_k·D_i) · e_ik · √((ν_u − 2)/χ_i), e_ik ~ N(0,1). χ_i ~ χ²_{ν_u} 는 종목·달마다 하나다. s² 는 그 달의
    평균 1 로그정규(CV = CV_s, PO-2.2 1차)이고 블록이 공유한다.
  - 그래서 21일 합은 PO-1.1 과 같은 다변량 t_{ν_f}·t_{ν_u} 이고, 주간 블록도 주변이 t 이며 달 안에서 척도를 공유한다.
  - **공통 난수:** 시나리오끼리 같은 난수를 쓴다(`keyed_rng("po2-sim", 달, 반복 묶음)`). C0 도 실제로 그렇게 했다(PO-2.6 MINOR).
- **시나리오:** 맞는 모델, **F×1.5**(진짜 f 를 √1.5 배), **업종 g ×1.69**(진짜 f_g 를 1.3 배, 업종마다 하나씩 10개). 보고만:
  F×0.7, D×0.5, D×2.
- **탐지확률 = 그 세계에서 1차 A-OB21 이 최종 밴드 밖일 확률.** 업종은 10개 업종 평균을 쓴다(어느 업종이 틀렸는지 모를 때의 탐지확률).
  최솟값과 업종별 값, 보조·가족(둘 중 하나 실패) 탐지확률은 보고만 한다.
- **밴드 업종 제약의 효과(보고만):** OB 의 업종 능동 노출 |Y_g| 분포, 사전 능동분산 중 업종 요인 몫, 업종 ×1.69 세계의 b_OB21 중앙값
  이동. 같은 OB 를 `sector_band` 없이 다시 풀어(같은 α 난수·같은 λ 규칙) 같은 세 값을 낸다. 밴드가 업종 과소예측을 이용하지 못하게
  막는지를 보는 것이다. 관문 판정에는 쓰지 않는다.
- **h** = 1차 최종 밴드 반폭 max(h⁻, h⁺)를 보고한다(바 아님).
- **관문 규칙(기계적으로 적용한다):**
  - 탐지(F×1.5) ≥ 0.8 **이고** 탐지(업종 ×1.69 평균) ≥ 0.8 이고 구창 OB 성공 ≥ 90% → **신창을 한 번 쓴다.** A0(신창 모델 예측만으로
    α·밴드)를 커밋한 뒤 A1(실현)을 돌리고, PO-2.3 의 두 검정으로만 판정한다.
  - 하나라도 아니면 → **A 를 공식적으로 건너뛴다("단계 A 생략 — 검정력 부족").** 신창은 이 연구에서 쓰지 않는다(A0·A1 없음).
    B 는 §2·PO-1 대로 열되 판정문 첫 줄에 "**위험모델 미검증**"을 쓴다. 전진 팔의 위험 점검은 PO-2.5 로 바꾼다.
  - 1차 CV_s 95% 상단으로 돌린 관문 값은 보고만 하고 규칙에 쓰지 않는다.

### PO-2.5 A 를 건너뛸 때 — 전진 O 팔의 주간 위험 점검과 안전 중단

§3 전진 B 의 "O 의 실현/사전 능동위험 > 1.5(K ≥ 12) 이면 멈춘다"를 아래로 바꾼다(A 를 건너뛴 경우. A 를 돌렸으면 §3 그대로).
- **주:** O 팔 첫 구축 체결일 다음 거래일부터 겹치지 않는 5거래일. 주 시작일 종가의 O 보유 비중 h_w(표류 반영)와 벤치 비중 b_w
  (직전 리밸런스 eligible 동일가중, 표류 반영)를 쓴다.
- **실현:** a_w = Σ_i (h_w,i − b_w,i)·R_i,w. R_i,w 는 주 시작 종가 → 5거래일 뒤 종가 수익(정규장 가격 경로)이다. 주 안의 매매는 넣지
  않는다(고정 보유 수익). 폐지는 마지막 종가, 결측은 0. 비용은 넣지 않는다.
- **사전:** σ_w = √(5·(h_w − b_w)ᵀΣ_t(h_w − b_w)). Σ_t 는 주 시작일 t 까지의 데이터로 만든 v3 모델(고정값 PO-1 그대로)이다.
  모델을 못 만든 주는 건너뛰고 수를 적는다.
- **통계량:** z_w = a_w / σ_w, RR_K = sd(z_1..z_K, ddof=1)(누적 창).
- **중단 규칙:** K ≥ 26 인 매주 RR_K 를 보고, **RR_K > 1.5** 이면 그 주에 O 팔을 멈춘다(새 매매 없음, 장부에 중단 기록, 원인 분석을
  적는다). R 팔은 계속한다. 같은 팔 이름으로 다시 시작하지 않는다 — 다시 하려면 새 팔·새 사전등록이다. 1.5 는 고정이다.
- **보고만:** 관문 모의의 OB 포트 하나(반복마다 p = r mod 200)를 39개월(156주)로 돌려, 위 규칙의 거짓 중단 확률(맞는 모델)과
  F×1.5·D×2·업종 ×1.69 세계의 중단 확률·중단 주 중앙값을 낸다.

### PO-3.5 위험모델 v4 — 특이위험 변동성 국면 보정(VRA) + 수축 강도 (구창 표본 안 튜닝)

- **왜 D 인가.**
  - OB 사전 능동분산의 팩터 몫은 중앙 0.040(PO-2)이고, O 는 0.063(리뷰)이다. 과소예측은 특이위험 쪽에서 온다.
  - OB 는 α_i = √(21·D̂_i)·ε_i 라서, 제약이 느슨하면 w_i − b_i ∝ ε_i / √D̂_i 다. 그러면 실현/사전 분산비는 ≈ 종목 평균 D_i / D̂_i 다.
  - D̂ 에 잡음이나 국면 지연이 있으면 Jensen 부등식 때문에 이 비는 1 보다 크다. 특이위험 판 최적화 바이어스다.
  - 무작위 포트(P5 0.957)는 Σ D_i / Σ D̂_i 를 재므로 같은 모델에서도 반대로(과대예측으로) 나올 수 있다.

    - 하루 앞 특이분산 예측 D̂_{i,t−1} 은 `specific_var_history` 로 낸다. 같은 `spec_half_life`·`spec_shrink`·`n_groups` 를 쓰고, 규모 그룹은 날짜별 log 시총이다.
    - 이것으로 특이수익을 표준화한다: z_it = u_it / √D̂_{i,t−1}.
    - B_t² = 시총(t−1) 가중 횡단면 평균 z_it² 다.
    - λ_S² = B_t² 의 지수가중 평균(반감기 h, asof 까지)이다. 그 뒤 D ← D·λ_S² 다. X·F 는 그대로다.

  - L 이 (최소 + 0.002) 안인 칸이 여럿이면 다음 순서로 고른다.
    1. v3 와 다른 손잡이 수가 적은 칸(VRA 켬 1, shrink ≠ 0.3 이면 1).
    2. h 가 긴 칸(끔 = 무한대).
    3. |shrink − 0.3| 이 작은 칸.
    4. shrink 가 작은 칸.
  - 그 칸이 v4 다. (끔, 0.3) 이 뽑히면 v4 = v3 이고, 아래 검정을 같은 절차로 v3 에 한다.
- **보고만(선택에 쓰지 않는다):**
  - 칸마다 OB21·OB5·L·σ_target·OB 성공·λ_S²(같은 shrink 의 VRA 끔 칸 대비 D 비, asof 분포).
  - v3·v4 의 P5·P50·P10B·HV·SM·S1~S6·IP·IE 구창 실현 바이어스. D 를 올리면 무작위 포트의 과대예측이 커질 수 있으므로 공개용이다.
  - OB 사전 팩터 몫(PO-3.4).
- **다중검정.** 12칸은 구창 표본 안 튜닝이고 시행이 아니다. 그래서 v4 의 구창 OB 값은 선택 뒤 값이라 증거가 아니다.
  위험모델 판정 누적은 v1~v3 구창 3회, v4 구창 튜닝 12칸, v4 신창 1회다.

### PO-3.6 v4 신창 검정 — "D·최적화 바이어스 검정" (사전등록, 신창 전)

- **라벨(판정문 첫 줄):** "D·최적화 바이어스 검정 — F·업종은 O 에 무관(사전 몫 약 6%), 검정 안 함".
  시장 수준·F·업종 대상은 보고만이다. PO-1.5 의 시장 문장도 그대로 쓴다.
- **대상과 입력.**

  - σ_target 은 **v4 구창 값으로 고정**한다. 신창에서 다시 정하지 않는다.
  - α 난수는 `keyed_rng("OB-new", n)` 이고, n 은 신창 asof 순번 0..30 이다.
- **밴드(신창 전에 숫자로 고정).**
  - PO-2.4 생성식으로 v4 구창 구조를 모의한다. 10,000회, T=31(주간 124), 블록 [5,5,5,5,1], 공통 난수다.

  - κ 는 v4 구창 실현 z 의 원형 블록 부트스트랩이다(L ∈ {3, 6}, 10,000회, 최대).
  - α 는 맞는 모델에서 두 검정을 동시에 통과할 확률이 0.90 이 되게 정한다(κ=1).
  - 밴드 숫자는 v4 결과 커밋(`PO3.json`)에 적고, 그 뒤 바꾸지 않는다.
- **통과 = A-OB21·A-OB5 둘 다 밴드 안.**
- **탐지확률(신창 전에 기록).**
  - 진짜 D 를 ×1.5 와 ×0.67 로 바꾼 두 세계에서 A 가 실패할 확률(둘 중 하나라도 밴드 밖)이다.
  - **둘 다 ≥ 0.8 이어야 한다. 하나라도 못 미치면 VOID 다.** VOID 면 신창을 쓰지 않고 v4 는 전진으로만 판정한다.
  - 1차 OB21 단독 탐지도 같이 적는다. 보고만: D×0.5·D×2·F×1.5.
- **그 밖의 VOID:** 신창 OB 성공 < 90%.
- **결과 가지.**
  - **통과** → B 를 §2·PO-1 대로 연다. 위험모델은 v4 다. B 판정문 첫 줄에 "위험모델 v4 — D·최적화 바이어스만 신창 OB 로 검증, F·업종 미검증"을 쓴다.
  - **실패** → v4 실패다. 고친 v5 는 전진으로만 판정한다. B 는 역사 구간(2020~2023)에서 열지 않는다.
  - **VOID(위 탐지 또는 OB 성공)** → v4 를 전진 A 로 판정한다. 같은 두 검정·같은 밴드를 쓰고, 정규장 경로를 배선한 뒤 월말로 쌓아 T=31 에서 본다.
    B 는 전진 A 통과 뒤에만 연다.
- **보고만(신창):**
  - v4 의 S1~S6·P5·P50·P10B·HV·SM·IP·IE·시장 수준 대상.
  - 연도별 값, 2026-07 을 뺀 값, NaN→0 셀 수.
  - OB 사전 팩터 몫(PO-3.4 경보).
  - 같은 신창 OB 포트를 v3 로 잰 OB21·OB5. 비교용이고 판정이 아니다.

  전진 O 팔의 트립와이어(PO-3.4)는 남는다.
