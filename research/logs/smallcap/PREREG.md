## 2. 가설과 경제적 근거 (데이터 전)

**후보 1개: 거래대금 충격·가격 무변동 사건(High-Volume No-Move, HVNM).** 소외주에 큰 거래가 터졌는데 값이 안 움직인 날 산다.

- **근거.** 거래량 충격은 종목의 가시성을 높여 수요를 넓히고 이후 수익이 높다(Gervais·Kaniel·Mingelgrin 2001, 소형주에서 강함). Merton(1987) 투자자 인지 가설, Hong·Lim·Stein(2000) 소외 종목의 느린 정보 확산과 같은 방향이다.
- **왜 이 대역에서 안 사라지나.** ADV 20억 미만이면 1,000억 펀드의 1% 포지션(10억)을 참여율 10% 로 5일 넘게 쌓아야 한다. 벤치마크·종목 수 의무도 안 맞고 공매도 물량도 거의 없다. 우리 주문 1,500만원은 들어간다. 이것이 "기관이 아니라서 있는 자유도"의 전부다.
- **왜 사건형인가.** 이득이 소수 구간에 몰린다는 교훈(B·S2)상 달력 리밸런스는 그 구간을 맞히느냐의 문제가 된다. 사건은 진입이 시간에 흩어지고 회전이 낮아 소형주 비용에 맞다.
- **왜 무변동인가.** 돌파·leader 계열(`indep30` 에서 기각, 거래대금 종목군 leader_M 포함)을 다시 돌리지 않는다. 상한가 추격이 아니라 체결 불가 문제도 작다.
- **이 가설이 틀릴 이유(미리 적음).** 큰 거래가 CB 전환·블록딜 매물 소화일 수 있다(일봉으로 구별 불가). 개인 주도 시장의 관심 매수는 되돌림을 낳는다(Barber·Odean 2008). 비용 허들(§5 예시 2.9~5.3%)이 높다. **사전 기대: 통과 가능성은 낮다.** 닫혀도 좋은 질문이다.
- **계보 공개.** fcs 에서 거래대금 배수(`s_vmult`)·반전일 거래대금 확인이 돌파·반전의 보조 거르개로 쓰인 적은 있다. 가격 무변동 사건 자체는 판정한 적 없다(grep). 2020~23 에서 가져온 파라미터는 없다.

## 3. 유니버스 (1단계)

- **U(t):** 보통주(코드 끝 0), 이름으로 스팩·리츠·ETF류 제외, `close_src≠pre_listing`, 거래량 > 0, **ADV20(t−20..t−1) ∈ [3억, 20억)**. 시총은 쓰지 않는다 — 폐지 종목 시총은 수정가라 믿을 수 없다. 기관 보유 비중은 없으므로 "기관이 못 온다"는 **용량으로 근사한 것**이지 측정이 아니다.
- **폐지 종목 거래대금:** v2 값은 수정가×거래량 근사다. ADV·체결 한도는 `naver_investor_trend` 원 종가×거래량을 쓰고 없으면 v2 로 돌아간다(2단계 대조).
- **주문 대 ADV.** AUM 3억 × 최대 5% = 주문 1,500만원.

## 4. 규칙 (config 1개)

| 항목 | 값 |
|---|---|
| 사건(t 종가 후 판정) | t ∈ U(t) ∧ TV(t) > max TV(t−50..t−1) ∧ \|r(t)\| ≤ σ63(t−1) ∧ 전일 거래량 > 0 ∧ `factor` 변경일 아님 ∧ 일간 σ 관측 ≥ 63 |
| 진입 | t+1 **정규장 종가**(단일가). 시장·국면 조건 없음 |
| 체결 가능 | t+1 거래대금 × 5% ≥ 1,500만원 ∧ t+1 종가가 상한 근처 아님(전일 대비 ±15% 시대 ≥ +14%, ±30% 시대 ≥ +29% 면 **미체결·재시도 없음**, 기회비용 그대로 진다) |
| 사이징 | 고정 1,500만원(복리 없음), 동시 20슬롯, 추가매수 없음. 손실 한도는 비중으로(5%) — 손절 폭을 좁히지 않는다 |
| 슬롯 경쟁 | TV(t)/ADV20(t) 큰 순, 넘치면 버림(대기 없음). 현금 수익 0 |
| 보유 중 새 사건 | 무시 |
| 청산 | **종가 < 직전 50거래일 최저 종가**이면 다음날 종가 매도. 시간 손절·이익 잠금·본전 이동·% 손절 없음 |
| 매도 체결 | 하한 근처(≤ −14%·≤ −29%)면 못 판다. 풀린 날 **그날 저가**에 판다. 체결일 거래대금 5% 를 넘으면 나눠 판다(날마다 5% 만큼 종가) |

**파라미터 출처.** 50일 = GKM 의 형성 창(1+49일), 청산 창도 일부러 같게. σ 1배 = 무차원 단위. 63일 = 기존 비용 모델의 σ 창. 3억·20억·5%·1,500만원 = §2·§3 의 용량 산수. 어느 것도 수익 데이터에서 고르지 않았다.

**시장 대조는 분리한다.** 이 규칙에 국면 스위치는 없다. 현금·타이밍은 별도 질문이다. 노출 맞춘 대조는 §7 B7 로 본다.

## 7. 합격 바 (승률 바 없음)

**4단계 입구 관문 — 탐색 절반, 슬롯 없는 사건 전수, §4 청산 그대로.**

- 사건 < 300 → VOID. 고정 20·60일 수익은 라벨.
- 실패 → 4단계 fail, **잠금 절반을 열지 않고 닫는다.** 순위 IC 는 쓰지 않는다(S2: 순위 .041 이 평균 .014 였고 롱온리 북은 평균만 번다).

| B5 | 능동 기대값 > 같은 메뉴 무작위 널 300 의 95 백분위. 널 = U(t) 안 무작위 날·같은 월별 사건 수, 같은 청산·슬롯·비용 |
| B6 | 능동 기대값 > 지속성 보존 널 300 의 95 백분위. 널 = 종목별 사건 달력 원형 이동(군집·종목·횟수 보존, 이동한 날이 U(t) 밖이면 버림) |
| B7 | 북 순수익 > 같은 날 같은 노출을 보유 종목의 시장별 슬롯 비중대로 101·001 지수에 건 대조(GUARDRAILS 노출 맞춘 시장) |
| B8 | 월수익 알파 HAC(Newey-West 3) t > 2, 시장 + U(t) 동일가중 회귀. 다중검정 문턱은 라벨 |
| B9 | 2009~12·2013~16-08 두 구간 모두 B2 양수. 연도별은 보고 |
| 체결 | 체결 ≥ 200, 온전한 해마다 ≥ 15. 미달 → **VOID**(판단 불가) |

- **합격** → 새 사전등록으로 전진 페이퍼 팔 하나. 실매매 아님. 10단계 안 적음.
- **불합격·VOID** → `fail` 기록, 닫는다. 규칙·대역·창을 바꿔 이 표본을 다시 찾지 않는다. 다른 이름으로 다시 시작하지 않는다.

**민감도(라벨, 승자 선택 금지, 합격 바 아님).** 비용 1배·폴백 1.5배, 청산 20·100일, TV 창 20·100일, |r| ≤ 2σ, ADV 대역 1.5~3억 추가·7.5~20억만, 폐지 −100%, t+1 시가 진입, 탐색 절반 북. 각 설정을 `record_trial` 로 세고 N 에 더한다.

**다중검정 라벨.** N = 전 원장 합을 실행 때 다시 센다. 2026-11-02: main 73줄, ML 15, fcs 33,149줄(GA 설정 포함, main 과 겹침 있음), autoresearch 288·combined 38 평가. 좁은 N(이 연구)은 1 + 민감도 수. 둘 다 `gate_report` 의 t-haircut·DSR 로 보고한다. 판정기가 아니라 숫자다.

## 9. 우리 데이터로 불가능한 것

- **2009~2016 실제 호가·체결 대기.** 호가는 2026-08-24~, U 대역 12% 만. 스프레드는 근사고, 상한 근처 체결 가능성·종가 단일가 물량은 일봉으로 모른다.
- **시간외 대량매매 분리.** 일봉 거래대금에 블록딜이 섞이는지 구별 못 한다 — 이 규칙의 핵심 약점이다. 전진은 분봉 09:00~15:32 합으로 잰다(그래서 과거와 정의가 다르다).
- **관리종목·투자경고·단기과열·저유동성 단일가 이력.** 없다. 거르지 못한다.
- **기관 보유·커버리지 이력.** 없다. 대역은 용량 근사다. 폐지 시총·수급도 신뢰 불가.
- **이전상장 시점의 시장 구분.** 현재 스냅샷뿐이다.
- **전진의 제약.** v2 는 매일 갱신되지 않는다. 일봉은 09-14 뒤 애프터마켓 포함이다. 전진 신호는 분봉(U 대역 91%, 없으면 거래 안 함), 종가는 `regular_close`(T+1 지연)·분봉 15:30~15:32 로 만들어야 한다. main `read_prices` 는 못 한다.
