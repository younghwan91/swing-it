사용자 방향(2026-10-09): "스캘핑·데이트레이딩은 변변치 않았다. 직장인에게 맞는 건 정보·차트·뉴스·수급·펀더멘털을
통합하고 ML 을 쓸 시간이 있는 스윙이다. 뼈대는 미너비니, 수급·뉴스·PEAD 로 확신을 올리고 한국 시장에 최적화하라."

## 1. 지금까지의 결과가 이 설계를 정한다

| 무엇 | 결과 | 이 설계에 주는 교훈 |
|---|---|---|
| PEAD(YoY 크기 랭킹, 분산·저회전) | **유일 통과**(rank-IC t 5.4, 생존편향 보정 후 Sh 1.49) | 정보는 사건의 *크기*에 있다. 드리프트는 느리다(~60일) |
| 미너비니 돌파(기술 단독, 7% 손절 + **10일 시간청산**) | 기각 — OOS −0.029R, 랜덤 널(+0.078) 아래 | 원전 SEPA 의 1/3(기술)만 시험했다. 실적 다리가 없었고 청산이 원전이 아니었다 |
| PEAD 집중(10% 손절 + 10일 캡) | 기각 | 짧은 캡이 드리프트를 자른다(pead_refinement 와 같은 교훈) |
| 눌림목·개인 역발상·수급 가속·공시 촉매 *존재* | 전부 기각 | 가격·수급 단독, 사건의 존재만으로는 엣지 없음 |
| 멀티-알파 북(IDX/PEAD/MNV) | MNV 슬리브는 단독 Sh 0.53·t 1.43, 가치는 무상관 | 미너비니는 **breadth 국면 + 분산(≤5%/종목)** 일 때만 북에 기여 |
| 국면 스위칭(지수 MA200) | NO-GO(시장중립 북엔 무의미) | 롱온리 단일 종목 매매엔 다른 이야기 — 별도 사전등록 대상 아님(뼈대의 일부로 고정) |
| LLM 뉴스 지속성 | 86일 표본에서 one_off < multi_quarter < structural 순서. 장기 검증(스윙 2호) 판정 진행 중 | 판정된 기사가 2025-09 부터만 있다 → 뉴스 층은 **기술(記述)만**, 판정 불가 |
| 외국인 수급 | 전 지평 최대 초과(+21%p@1년, MULTI_ALPHA 부록), 기관은 단기 역 | 수급은 *확인* 층으로, 외국인을 따로 본다 |
| 롱온리 vs 2024~26 대형주 강세 | 촉매 지수헤지 −2.0%, PEAD 2026 −66%p | **지수 헤지 수익을 1차 지표**로 |
| 비용 | 왕복 41.5bp(세 20 + 수수료 3 + 스프레드 18.5) | 2배 스트레스 필수 |

**왜 "기각된 정의의 재탐색" 이 아닌가.** 미너비니의 SEPA 는 추세 템플릿 + 상대강도 + **실적 성장·가속** + 촉매 + VCP 돌파,
그리고 "손절은 짧게, 승자는 추세가 꺾일 때까지" 다. 이 레포가 기각한 것은 그중 기술 조건 + 10일 시간청산이다.
이번 가설은 (1) 실적 다리(PEAD 의 메커니즘)를 필수로 붙이고 (2) 청산을 원전대로(하드 손절 + 50일선 이탈, 최대 60거래일)
바꾼 **다른 정의**다. 파라미터는 원전(미너비니·오닐) 수치로 고정하고 탐색하지 않는다. 기존 미너비니 시행은 다중검정 N 에 1회로 넣는다.

## 2. 경제적 근거 (백테스트 전)

과소반응(PEAD): 실적 서프라이즈는 시장에 수 주~수 개월에 걸쳐 반영된다. 추세 템플릿·RS 는 그 반영이 *이미 시작돼 가격이 확인해 준*
종목을 고른다(오닐/미너비니의 "leader"). 외국인·기관의 매집은 정보 있는 자금이 아직 들어오는 중이라는 확인이고(Sias 2004, 수요 지속),
LLM 지속성 판정은 이익이 일회성인지 여러 분기인지에 대한 사전 정보다. 교집합 = "드리프트가 시작됐고, 이익이 지속되며, 정보 있는 자금이
아직 사는 중" 인 종목. 한국 고유 마찰(개인 비중이 높은 코스닥의 테마 과열, 갭 꼬리, 가격제한폭)은 진입·분산 규칙으로 다룬다.

## 3. 구조 — 뼈대(필수) + 확신 층(가산)

```
유니버스(한국 위생) ─► 뼈대 S: 국면 OK ∧ 추세 템플릿 ∧ RS≥70 ∧ 피벗 돌파
                         └─► 판정 config  = S ∧ E(실적 다리)                       ← 사전등록 1개
                         └─► 확신 점수     = E + F(수급) + K(섹터 주도) [+ N(뉴스)] ← 단조성만 기술
                         └─► ML 메타라벨   = S 이벤트 위 분류기(purged WF)          ← 도전자, 판정 아님
```

- **유니버스(한국 위생):** 보통주만(우선주·스팩·ETF/ETN·리츠 제외), ADV20 ≥ 200억원, 가격 ≥ 1,000원, 상장 252거래일 이상,
  상장폐지 종목 포함(정문 `read_prices`), 분할조정 가격.
- **뼈대 S(원전 수치):** close > MA50 > MA150 > MA200, MA200 > MA200[t−20], close ≥ 0.75×252일고, close ≥ 1.30×252일저,
  RS(3/6/9/12M 가중, 2:1:1:1) 횡단면 백분위 ≥ 70, 돌파 = close > 직전 50일 최고 고가 ∧ 거래량 ≥ 1.5×50일 평균.
  국면 = 그 종목 시장(KOSPI/KOSDAQ) breadth(MA50 위 종목 비율) > 50%.
- **E 실적 다리(오닐 C):** 그날 알려진 최신 분기(정정 반영 이중 시간축) 순이익 YoY ≥ +25% ∧ 당기 순이익 > 0 ∧ 공시 후 ≤ 90일.
- **F 수급:** 외국인+기관 20일 순매수 / 20일 거래량 > 0 ∧ 외국인 20일 순매수 > 0. 2017~2023 은 약 650종목만 있다 → F 는 수급이 알려진 행에서만 정의(NaN ≠ 0).
- **K 섹터 주도:** 종목 섹터의 60일 수익률이 섹터 횡단면 상위 1/3.
- **N 뉴스(2025-09+ 만):** 진입 전 60일 안에 subject∈{main,partial} ∧ direction=+1 ∧ persistence∈{multi_quarter,structural}
  ∧ freshness=new ∧ reports_price_move=false 기사 ≥ 1. 시점: first_seen_at(KST) 15:30 이후는 다음 거래일.
- **진입/청산(한국):** 신호 t 종가 → t+1 시가. t+1 시가가 피벗(돌파 고가)×1.05 초과면 추격 금지(원전 5% 규칙),
  상한가 시가면 체결 불가로 버림. 하드 손절 −8%(장중 저가 터치 → 손절가 체결, 갭이면 시가), 종가 < MA50 → 다음날 시가 청산,
  최대 60거래일. 같은 종목은 보유 중 재진입 없음.

## 4. 판정 지표 (주 → 부)

1. **정합 대조 alpha(주):** 같은 날 × ADV 분위 × 5일 수익 분위 × 시장 무작위 종목을 같은 진입/청산 규칙으로(대조 풀 = 유니버스 전체).
2. **층 기여 alpha:** S ∧ E 트레이드 vs 같은 날 S ∧ ¬E 트레이드(실적 다리가 뼈대 위에 무엇을 더하나).
3. 지수 헤지(비용 차감) 평균 + 날짜 군집 부트스트랩 CI. 비용 41.5bp 와 83bp.
4. `prop_gate` 배터리(폴드·손안댄창·R 분포·취약성·DSR, 원장 N).
5. 연도별·월별 부호.
