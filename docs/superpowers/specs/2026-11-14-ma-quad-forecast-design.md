## 3. 접근 (사용자 선택: A 2차식 외삽 신호 + 무작위 기준, ML 제외)

| | 무엇 | 역할 |
|---|---|---|
| **A (차수 2)** | 최근 N일 로그 종가에 2차식, k일 외삽, 자기 예측 오차 라이브러리로 밴드 | **신호** |
| **B1 (차수 1)** | 같은 절차, 직선 | 기준 — "직선보다 정교한가" |
| **B0 (차수 0)** | 같은 절차, 중심선 = 마지막 종가(추세 없음) | 기준 — 화면의 **"랜덤 기준"** |
| C ML 예측 | — | 제외(사용자 동의, main `ml_forecast` 닫힘) |

세 예측기는 **차수만 다르고** 나머지(σ_t, 라이브러리 기간·모집단·갱신, 경로 수, 시드)는 같다 — 리뷰 M1: 처음 안(종목 자기 250일 블록 부트스트랩)은 드리프트·변동성 척도·오차 모양이 함께 달라
"A − B = 곡률 정보"가 성립하지 않았다. 처음 안은 버린다.

**설계 결정(내 판단):** 2차식은 이평선이 아니라 **가격**에 맞추고, 이평선은 "알려진 과거 종가 + 외삽 종가"로 산수 계산한다.
k=5 이면 120선 96%, 60선 92%, 20선 75% 가 이미 확정이라 장기선 밴드는 저절로 좁다.

## 4. 신호 정의

모든 계산은 t 일 정규장 종가까지의 자료만 쓴다. 차수 q ∈ {0, 1, 2} 공통.

1. **중심선:** 종목별로 s = −N+1 … 0 의 로그 종가 y 에 최소제곱 q차식, ŷ(1…k)(롤링 합 닫힌 꼴; q=0 은 ŷ ≡ y(0)).
2. **오차 라이브러리:** 원점 u 마다 z(u) = (y(u+h) − ŷ_u(h))_{h=1..k} / σ_u, σ_u = u 까지 60일 로그 수익 표준편차.
   - 모집단: 위생(보통주·원 종가 ≥ 1,000원) ∧ 20일 거래대금 ≥ 10억 ∧ 이력 ≥ N + 60일인 **모든** 종목-일(정배열 여부 무관; 상장 252일 조건은 라이브러리에 걸지 않는다 — 내 판단, 준비 구간을 줄인다).
   - t 일에 쓰는 원점: u ∈ [t − 3년, t − k] ∩ 자료 시작 이후(t 에 이미 실현된 것만). 원점 날짜가 **120 거래일 이상** 쌓여야 그날 신호가 정의된다(그 전은 신호 없음 — 결과가 아니라 자료 시작일로 정해진다).
   - 매월 첫 거래일 갱신, (q, N, k) 조합마다 따로.
3. **경로:** M = 200개 z 를 라이브러리에서 뽑아 y(t+h) = ŷ(h) + σ_t·z_h. 경로마다 MA_w(t+h) = (창 안의 알려진 종가 합 + 경로 종가 합) / w.
   시드: (종목, 월) 결정적 시드 → 같은 달 안에서는 같은 라이브러리 색인을 쓴다(공통 난수, 날마다 P 가 몬테카를로 잡음으로 흔들리지 않게 — 리뷰 M5). 표본 종목-일에서 M = 1,000 민감도를 보고.
4. **확률:**
   - P_align(k) = t+k 에 **정배열(MA5 > MA20 > MA60 > MA120)** 인 경로 비율.
   - 쌍(5/20·20/60·60/120)별 P_up(pair, k) = t+k 에 단기선 > 장기선인 경로 비율(지금 이미 위에 있는 쌍도 같은 식).
     지금 아래에 있는 쌍만 **첫 교차일 분포**(크로스 시점 예측)를 낸다.
   - 보유 중: P_dead(pair, k) = t+k 까지 단기선이 장기선 아래로 한 번이라도 내려가는 경로 비율.
   - 밴드 표시 = 경로의 10·50·90 백분위(가격·각 이평선).
5. **주봉:** 완성된 주만(그 주 마지막 거래일 종가; 진행 중인 주는 버린다 — 내 판단). 쌍 5/20·20/60 주. N_w = N 주, k_w = ⌈k/5⌉ 주, 주봉 라이브러리는 같은 규약을 주 단위로(3년 = 156주, 최소 26주).
   주봉 값은 금요일(그 주 마지막 거래일)에만 바뀐다. 주봉은 겹침에만 쓰고 관문 0 판정에는 넣지 않는다(보고만).
6. **겹침:** 일봉 3쌍 + 주봉 2쌍 중 P_up ≥ 0.5 인 쌍의 수(0~5).
7. **이평선 묶음 하단:** min(MA20, MA60, MA120)(MA5 는 가격에 붙어 있어 뺀다 — 내 판단). 손절 거리 d = 1 − 묶음 하단 / 종가.

## 5. 관문 0 — 확률 보정 (매매 시뮬 없음, 사용자 동의 2026-11-14)

**질문:** "70% 라고 하면 실제로 70% 가 정배열이 되는가, 그리고 기준 예측기보다 나은가."
경험 라이브러리라 주변 보정은 구조상 거의 맞는다. 하지만 라이브러리(전체 종목-일)와 평가(후보 부분집합)가 달라 **조건부 보정은 보장되지 않는다** → 표는 유지한다.

- **판정 모집단:** 2017-01-02 ~ 2023-12-31, **사전 후보** = 유니버스 ∧ EPS 상승 ∧ t 에 정배열 아님 ∧ 0 < d ≤ 10%(매매가 일어나는 곳 — 리뷰 M2). 정배열 아닌 전체 종목-일은 보고만.
- 격자: N ∈ {10, 15, 20, 30, 40} × k ∈ {3, 5, 7, 10} = 20칸.
- **칸 합격(전부):**
  1. 보정: P_A ≥ 0.5 구간(0.5·0.6·0.7·0.8·0.9 경계 5구간)에서 n ≥ 300 인 구간마다 |예측 − 실현| ≤ 5pp, 전체 ECE ≤ 2pp 그리고 ECE ≤ 기준율의 20%.
  2. 기술: BSS = 1 − Brier(A) / Brier(비교 대상) ≥ **0.01** 이고, 월 군집 부트스트랩(2,000회, 시드 고정) 95% 하한 > 0. 분기 블록은 민감도로 보고.
  3. 연도: 7개 연도 중 ≥ 5 에서 BSS > 0.
- **비교 대상:** B0(무작위 기준) 대비만 판정(§14 사용자 결정 (나)). B1 대비는 보고.
- **관문 합격:** 20칸 중 ≥ 12칸 합격 **그리고** 합격 칸 가운데 격자 이웃(N 또는 k 한 칸 차이)으로 이어진 덩어리 하나가 ≥ 8칸(고원 — 같은 데이터의 이웃이라 12칸은 독립 증거가 아니라 강건성 조건이다).
- **관문 0 은 통과/기각만 정한다.** 관문 1 메뉴는 20칸 전부다(리뷰 C1: 2017~2023 전체 라벨로 메뉴를 좁히면 2020~23 시험 폴드 정보가 샌다).
- 보고 열: 칸별 신뢰도 표(10구간 전체), 해상도(P ≥ 0.5 구간 실현율 A vs B0 vs B1), 쌍별 P_up 표, 주봉 표, 연도별 BSS.
- 불합격이면 "2차식 외삽은 기준 예측기보다 정배열을 더 잘 예측하지 못한다"로 기록하고 **백테스트를 하지 않는다.** 다른 함수꼴(3차·지수 평활)로 바꿔 다시 돌리지 않는다(낚시) — 하려면 새 사전등록.
- 사전 예상(등록에 적을 것): 보정 통과 85%, B0 대비 기술 통과 40%(관문 0 통과 ≈ 35%), B1 대비 25%(보고)(한국 단기 반전 경향 때문에 곡률 외삽이 음의 기술일 수 있다).

## 6. 관문 1 — 백테스트 (관문 0 통과 시에만, 2017-10 ~ 2023-12)

### 체결 규약 (사용자 결정: 붕괴 즉시 청산, 유예 없음)
- 모든 판정은 t 일 정규장 종가로 하고 **체결은 t+1 시가**(데몬 흐름: 08:00 판정 → 09:00 주문과 같다). 손절도 종가 이탈 판정 → 다음 날 시가(갭은 그대로 맞는다).
- 보고 열로 "t 종가 체결" 민감도를 같이 낸다(판정은 t+1 시가).
- 진입 시가 재확인: d_fill = 1 − 손절선 / t+1 시가. d_fill ≤ 0(시가가 손절선 아래)이면 사지 않는다. d_fill > 10%(갭 상승)이면 사지 않는다. 비중은 d_fill 로 계산.
- 상한가 시가 매수 불가·정지일 체결 불가·정지일 매도 금지는 leader21 엔진 규약 + 정정 30-1. 2023-01-25 호가 개편 반영.

### 진입
- 후보: §5 사전 후보 ∧ P_align(k) ≥ θ_in ∧ 겹침 ≥ o_min. d 하한은 두지 않는다 — 구조선 손절이고, 결과를 본 뒤 하한을 정하지 않기 위해 **d 구간(<3% · 3~6% · 6~10%)별 R·털기율을 보고**한다(리뷰 M5).
- 후보 > 빈 슬롯이면 P_align(A) − P_align(B0) 큰 순.
- 비중: leader_P 와 같다 — min(5%, 0.25% / d_fill), 슬롯 20, 종목당 최대 5%, 불타기 없음(내 판단: 첫 시험은 신호만).
- 재진입: 청산 체결 다음 날부터 다시 후보가 되면 살 수 있다(쿨다운 없음 — leader21 규약 그대로).

### 청산 (세 갈래 + 두 시도)
- **① 저손실(뚫지 못함):** 종가 < 진입일 손절선(진입 판정일의 묶음 하단) → 다음 날 시가. 손절선은 고정, 올리지 않는다. 보유 내내 유효.
- **③ 예측 붕괴(사용자 결정 (a), 즉시):** 아직 정배열이 실현되기 전에 P_align(k) < θ_out 인 날 → 다음 날 시가, 유예·확인 기간 없음. θ_out < θ_in.
  가격 수준과 무관한 조건 청산이다. 본전 스톱·N일 시간 청산은 채택하지 않음.
- **② 정배열 실현 뒤 보유:** 종가 기준 정배열이 한 번 나면 ③ 은 꺼지고 아래 둘 중 하나로 청산. **두 방식은 시도 2건으로 따로 기록**(TRIALS.jsonl).
  - **X-dead:** P_dead(쌍, k) ≥ θ_dead 인 날 → 다음 날 시가. 쌍 ∈ {5/20, 20/60}(진입 조합과 같을 필요 없음 — 사용자).
  - **X-mnv:** 미너비니 매도(MINERVINI_RULES.md:37 근사) — +2R(R = d_fill) 장중 절반 매도 + 나머지 본전, MA50 종가 이탈(MA50 ≥ 진입가 뒤부터) → 다음 날 시가,
    급등 매도 = 5일 +25% ∨ 당일 +15% 이고 +3R 위일 때 그날 종가. ① 손절 유지, **max_hold 없음·chase 없음·시간 손절 없음**
    (`minervini_exits.simulate_minervini` 기본값 `max_hold=120`·`chase=0.05`·`stop_floor/cap`·장중 수축 저점 손절은 쓰지 않는다 — 재사용하면 코드 수정, 아니면 이식).
    2R 본전은 사용자 원칙("본전 이동 금지")과 부딪힌다. 사용자가 "미너비니 터는 방식"을 허용해 이 시도에만 넣고, **전진 팔로 갈 때 본전 요소를 사용자에게 다시 확인**한다.
    d 가 작으면 2R 이 +2~6% 라 털기와 겹칠 수 있다 — 표시.
- 최대 보유 기간 없음(시간 손절 금지). 구간 끝은 data_end 평가.
