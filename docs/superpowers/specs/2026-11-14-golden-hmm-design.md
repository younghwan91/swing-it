# MA50 → MA200 골든 확률 — 국면 전환(HMM) 경로 모형 설계 (2026-11-14)

선행: `docs/superpowers/specs/2026-11-14-ma-quad-forecast-design.md` 의 관문 0 기각(`research/logs/ma_quad/RESULTS.md` 판정, e11419b) —
외삽 추세는 다음 k봉 수익에 정보가 없었고(β≈0), 정배열 확률의 날카로움은 이평선 산수(무작위 기준 q0 가 보정됨)에서 나왔다.

## 1. 사용자 의도 (2026-11-14 대화)
- 목표는 하나: **MA50 이 MA200 을 넘는가(골든)** 를 아주 짧게(약 10봉 안) 예측. 50·200 바로 아래 자리는 손익비가 좋은 자리라는 가설, 펀더멘털이 어느 정도 받치면 상승률이 크다는 가설.
- **모든 결정은 확률 기반**, 고정 문턱을 하나씩 붙이지 않는다. 최소 HMM 수준의 확률 모형. 확률이 커지면 비중도 커진다.
- 피처는 **한 번에 하나씩**(상대 거래량 등), 넣더라도 고정값 아님. "샘플 충분하다."
- 시간대는 봉 단위(일봉 먼저; 시·분봉은 데이터가 2025-08~ 라 전진 전용).

## 2. 모형 (1단계)
- **국면 전환 랜덤워크:** 가우시안 HMM, 관측 x_t = [z_t = r_t/σ_t (60봉 표준화 로그 수익), g_t = log(MA50/MA200), Δ5 g_t]. 상태 수 S ∈ {1..5} 는 학습 창 BIC 로 고른다(고정 아님). S = 1 이 곧 단일 국면 랜덤워크 = 내포된 널.
- **확률:** t 까지 순방향 필터로 상태 사후확률 → 전이행렬로 상태 경로 M = 200 개 → 상태별 z 주변분포(평균·분산)에서 수익 → 가격 경로 → **MA50·MA200 은 알려진 과거 종가 + 경로 종가로 산수 계산** → P_golden(k) = k 봉 안에 MA50 > MA200 이 한 번이라도 되는 경로 비율. 같은 방식으로 P_dead(k).
- **비교 기준(관문 판정):** ma_quad 의 q0(무조건 경험 오차 라이브러리 무작위 경로 — 2017~23 에서 보정 확인됨). 보고: S = 1 가우시안.
- **학습:** 유니버스 전 종목 수열 풀링(라벨 미사용 — 수익·이평선만). 관문 0 용 모형은 2017~2023 으로 학습하고 2009~2016 에 적용(시간 역방향 표본 밖, 라벨 미사용이라 누출 없음 — 공개). 관문 1 은 해마다 과거로만 재학습(워크포워드).

## 3. 결정(관문 1, 관문 0 통과 시) — 고정 문턱 없음
- 기대값 EV_t = P_golden·W̄ − (1 − P_golden)·L̄ − 비용(2배), W̄·L̄ = 학습 창 거래의 평균 이익·손실(R 단위).
- 비중 ∝ max(EV_t, 0) (분수 켈리, 상한 종목당 5%, 위험 자산 0.25%/손절 거리). 확률이 커지면 비중이 저절로 늘고(불타기), EV ≤ 0 이면 0.
- 청산: EV < 0 또는 P_dead 기반 EV 가 음수 → 다음 봉 시가. 구조 손절 = 진입 때 min(MA50, MA200) 하단 종가 이탈(고정, 올리지 않음). 시간 손절 없음.
- 비교: 같은 자리(사전 후보) 무작위 진입 널 — "자리 자체의 손익비" 와 "확률의 기여" 를 가른다.

## 4. 사전 후보(사건)
유니버스(위생 ∧ ADV20 ≥ 10억 ∧ 상장 252일) ∧ EPS↑(netinc > 0 ∧ > 전년 같은 분기, as-of) ∧ MA50 < MA200 ∧ 격차 1 − MA50/MA200 ≤ 5%. 정지일 종가 NaN(ma_quad MQ-2 와 같음).

## 5. 관문
- **관문 0 (확률, 2009-01 ~ 2016-08 한 번, 수익 미조회):** k ∈ {5, 10, 15} 봉. 칸 합격 = ma_quad 와 같은 바(P ≥ 0.5 구간 n ≥ 300 마다 |예측 − 실현| ≤ 5pp, ECE ≤ 2pp ∧ ≤ 기준율 20%, BSS(대 q0) ≥ 0.01 ∧ 월 군집 95% 하한 > 0, 연도 ≥ 6/8 양수). 관문 합격 = k = 10 포함 2/3 칸.
  라벨 끝 = 2016-08-31(t + k 가 넘는 사건 제외). 데이터 규약 = indep30(폐지 포함 v2, dart_doc 실적, 2015-06-15 전 상한 1.14).
- **관문 1 (백테스트, 2017-10 ~ 2023-12 워크포워드 폴드 2020~23):** §3 결정, 비용 2배, 널(같은 자리 무작위 진입 · 같은 메뉴 무작위 설정), 손익비·기대값·체결 수·상위 5 제거·팩터 알파 NW·노출 맞춘 시장. 체결 < 100 VOID.
- **관문 2:** 전진 모의매매(새 장부). 그 뒤 실거래 데몬.
- **피처 추가(2단계~):** 한 번에 하나(상대 거래량 = 5봉/50봉 평균 거래량 → 관측 차원 추가). 남기는 조건 = 다음 표본 밖 구간에서 로그우도 ∧ BSS 개선. 각 추가는 새 사전등록 문단.

## 6. 반목표
보정 안 된 확률로 비중 키우기 / 2017~23 확률 결과를 보고 모형 구조 바꾸기 / 피처 여러 개 동시 투입 / 시간 손절·본전 스톱.

## 7. 위험(미리 적음)
50·200 격차는 겹치는 평균 때문에 기계적 관성이 있다 — HMM 이 그것만 배우면 q0 와 같은 정보라 못 이긴다. ma_quad 에서 외삽 추세 β ≈ 0 → 국면 정보도 작을 가능성이 크다. 사전 예상: 관문 0 통과 25%.
